2024 年高考数学全国一卷（新高考Ⅰ卷）第 11 题研究报告

研究对象：丝带曲线（笛卡尔卵形线型）多选题　·　研究视角：高中数学教师教研

一、试题呈现

设计一条美丽的丝带，其造型可以看作图中的曲线 \(C\) 的一部分。已知 \(C\) 过坐标原点 \(O\)，且 \(C\) 上的点满足：横坐标大于 \(-2\)；到点 \(F(2,0)\) 的距离与到定直线 \(x=a\ (a<0)\) 的距离之积为 \(4\)。则

选项内容
A\(a=-2\)
B点 \((2\sqrt{2},0)\) 在 \(C\) 上
C\(C\) 在第一象限的点的纵坐标的最大值为 \(1\)
D当点 \((x_{0},y_{0})\) 在 \(C\) 上时，\(y_{0}\leqslant\dfrac{4}{x_{0}+2}\)
参考答案：A、B、D（C 错误）。本题为多项选择题，全部选对得 6 分，部分选对得部分分，有选错得 0 分。

三、必备知识点

  • 曲线与方程：由几何条件建立动点方程；"点在曲线上 ⇔ 坐标满足方程"是判定 B、C 的基础。
  • 两点间距离公式与点到直线距离公式：\(d(M,F)=\sqrt{(x-2)^{2}+y^{2}}\)，到直线 \(x=a\) 的距离为 \(|x-a|\)。
  • 待定系数/代入求参：利用曲线过原点 \(O(0,0)\) 代入，唯一确定 \(a=-2\)（判 A）。
  • 不等式性质：由 \(\sqrt{(x-2)^{2}+y^{2}}\geqslant |y|\) 直接推出 D，无需求最值。
  • 函数最值（导数/单调性）：将第一象限纵坐标平方视为 \(x\) 的函数，用导数或特例法判断最大值是否等于 1（判 C）。
  • 特例法（举反例）：要证 C 错，只需举出一个第一象限点使 \(y>1\) 即可，比严格求最值更省时。
  • 对称性：方程只含 \(y^{2}\)，曲线关于 \(x\) 轴对称，利于整体把握形状。

六、命题思路

  • 情境美学化、去模板化：以"设计一条美丽的丝带"为情境，弱化了传统解析几何的"直线与圆锥曲线联立"套路，转向"依定义建方程、据方程研性质"。
  • 新定义曲线（笛卡尔卵形线型）：以"到定点与到定直线的距离之积为常数"定义曲线，既贴近圆锥曲线"到定点与定直线距离之比为常数"的经典定义，又做了变式，考查迁移能力。
  • 四选项异质、综合区分：A 考"求参"、B 考"点在曲线上"、C 考"最值/反例"、D 考"不等式放缩"，四个考点层层递进，覆盖曲线与方程的完整研究链条。
  • C 是精心设计的陷阱：学生易凭直觉或粗略估算认为第一象限最高点是 \((2,1)\)（确实 \((2,1)\) 在曲线上且 \(y=1\)），从而误判 C 正确；实则曲线在 \(x\approx1.67\) 处纵坐标略高于 1。
  • 区分度良好：能否正确排除 C、并用放缩简洁证明 D，是区分中上水平与顶尖水平考生的关键。

七、解析思路与完整解答

7.1 建立曲线方程并判定 A

设 \(M(x,y)\) 为 \(C\) 上任意一点，则

\[d(M,F)=\sqrt{(x-2)^{2}+y^{2}},\qquad d(M,\,x=a)=|x-a|.\]

由题意 \(\sqrt{(x-2)^{2}+y^{2}}\cdot |x-a|=4\)，且 \(x>-2\)。

因 \(C\) 过原点 \(O(0,0)\)，代入得

\[\sqrt{(0-2)^{2}+0}\cdot |0-a|=2\cdot(-a)=4\quad(\text{因 }a<0,\ |a|=-a),\]

故 \(-a=2\)，即 \(a=-2\)。A 正确。

于是点到直线的距离化为 \(|x+2|\)，结合 \(x>-2\) 得 \(|x+2|=x+2\)，曲线方程为

\[\sqrt{(x-2)^{2}+y^{2}}\,(x+2)=4,\qquad x>-2.\]

即

\[y^{2}=\frac{16}{(x+2)^{2}}-(x-2)^{2}.\tag{1}\]

7.2 判定 B

检验点 \((2\sqrt{2},0)\)：代入 (1) 右端，

\[\frac{16}{(2\sqrt{2}+2)^{2}}-(2\sqrt{2}-2)^{2} =\frac{16}{4(\sqrt{2}+1)^{2}}-4(\sqrt{2}-1)^{2}.\]

其中 \((\sqrt{2}+1)^{2}=3+2\sqrt{2}\)，故第一项 \(\dfrac{4}{3+2\sqrt{2}}=4(3-2\sqrt{2})=12-8\sqrt{2}\)；第二项 \(4(3-2\sqrt{2})=12-8\sqrt{2}\)。两者相等，右端为 \(0\)，即 \(y^{2}=0\)。

故 \((2\sqrt{2},0)\) 满足曲线方程，B 正确。（注：它正是第一象限弧与 \(x\) 轴的右端交点。）

7.3 判定 C（错误）

举反例（特例法）：取第一象限点 \(x=\dfrac{3}{2}\)，由 (1) 得

\[y^{2}=\frac{16}{\left(\frac{7}{2}\right)^{2}}-\left(-\frac{1}{2}\right)^{2} =\frac{64}{49}-\frac{1}{4}=\frac{256-49}{196}=\frac{207}{196}>1.\]

故 \(y=\dfrac{\sqrt{207}}{14}\approx1.028>1\)，即存在第一象限点其纵坐标大于 1，因此"纵坐标最大值为 1"不成立。C 错误。

补充（精确最大值）：在第一象限 \(x\in(0,2\sqrt{2})\) 上，令 \(f(x)=\dfrac{16}{(x+2)^{2}}-(x-2)^{2}\)。求导

\[f'(x)=-\frac{32}{(x+2)^{3}}-2(x-2).\]

令 \(f'(x)=0\)，即 \(\dfrac{16}{(x+2)^{3}}=2-x\)，整理为 \((x+2)^{3}(2-x)=16\)。除 \(x=0\)（对应原点，\(y=0\)）外，另一根约为 \(x\approx1.672\)，此时 \(y_{\max}\approx1.048>1\)。进一步可算得 \(y_{\max}^{2}=-2(u-2)(u-4)\)（其中 \(u=x+2\) 满足 \(u^{3}(4-u)=16\)），确严格大于 1。

7.4 判定 D

由曲线方程 \(\sqrt{(x-2)^{2}+y^{2}}\,(x+2)=4\) 且 \(x+2>0\)，得

\[\sqrt{(x-2)^{2}+y^{2}}=\frac{4}{x+2}.\]

由于 \((x-2)^{2}\geqslant0\)，有 \(\sqrt{(x-2)^{2}+y^{2}}\geqslant\sqrt{y^{2}}=|y|\)，于是

\[\frac{4}{x+2}\geqslant |y|\geqslant y.\]

即对任意曲线上的点 \((x_{0},y_{0})\)，恒有 \(y_{0}\leqslant\dfrac{4}{x_{0}+2}\)（当 \(y_{0}<0\) 时更显然成立）。D 正确。

综上，正确选项为 A、B、D。

易错提醒：判定 C 时，若仅注意到点 \((2,1)\) 在曲线上（代入 (1)：\(16/16-0=1\)，确有 \(y=1\)），便草率认定"最大值=1"，就会误选 C。必须意识到曲线在 \((2,1)\) 附近仍向上鼓起，最高点位于 \(x\approx1.67\) 处。考场上用"举反例"最稳妥：只要找到一个 \(y>1\) 的第一象限点即可否决 C。

八、解答技巧

  • 先求方程再判性质：拿到"曲线与方程"类题，第一步务必把几何语言译成代数方程（本题关键是 \(x>-2\Rightarrow |x+2|=x+2\) 去掉绝对值）。
  • 原点是天然的"求参钥匙"：A 这类"确定参数"选项，直接代入已知过点最快捷。
  • B 用代入检验：判断点是否在曲线上，只需代坐标验方程，配合有理化化简。
  • C 用反例而非硬求最值：多选题只需证伪，取 \(x=3/2\) 即可见 \(y^{2}=207/196>1\)，比完整求导省时；若想求精确最值，再上导数。
  • D 用放缩秒杀：\(\sqrt{(x-2)^{2}+y^{2}}\geqslant|y|\) 一步到位，无需展开，体现"不等式性质"的威力。
  • 数形结合辅助：由对称性（只含 \(y^{2}\)）与几个关键点 \((0,0),(2,1),(2\sqrt{2},0)\) 大致描出丝带形状，有助于预判最值位置。

九、未来命题趋势

  • 曲线与方程重回压轴多选：在圆锥曲线大题前置、模块整合背景下，以"新定义曲线"考查建方程与研性质，成为多选压轴的高频形态。
  • 定义变式化：在经典圆锥曲线定义（到定点/定直线距离之比为常数）基础上，做"积/和/差为常数""到两点/点到线"等变式，考查迁移。
  • 四选项异质综合：一道题内同时覆盖求参、点在曲线、最值、不等式、对称性等多个子考点，强调研究的完整性。
  • 陷阱选项（如 C）常态化：用"看似端点最值"误导学生，考查严谨性与反例意识。
  • 轻联立、重分析：弱化传统联立运算，强化对方程结构的理解与不等式放缩，呼应"反套路、考素养"导向。
  • 情境更贴近应用与美学：丝带、光路、轨迹设计等生活/工程情境将持续出现。

十、学生解答的最大障碍与典型失误

  • 误判 C 为正确：最普遍错误。被 \((2,1)\) 这一"看起来像顶点"的点误导，未验证曲线在该点附近是否更高，从而漏掉对 C 的反例检验。
  • 绝对值处理错误：未利用 \(x>-2\) 将 \(|x+2|\) 化为 \(x+2\)，导致方程带绝对值、后续判定 B、D 受阻。
  • 建方程不严谨：把"距离之积"误写成"距离之和"或比例，得到错误曲线方程。
  • 最值求错或不敢用反例：硬求导时算错 \(f'(x)\)，或没想到用特例法快速否决 C，在考场上耗费过多时间。
  • D 想复杂：试图代入 (1) 配方求上界，而未用 \(\sqrt{(x-2)^{2}+y^{2}}\geqslant|y|\) 一步放缩，容易出错或漏掉 \(y<0\) 情形。
  • 多选策略失误：因 C 拿不准而连带漏选 B 或 D，损失部分分。

十一、互联网评价与讨论综述

本题作为 2024 新高考Ⅰ卷多选题压轴之一，网络教研资料充分，主流共识如下：

  • 答案高度一致：腾讯 ima 知识库、教习网、优途升学网等多家解析均给出参考答案 ABD，与本文独立推导吻合。
  • 标准解析思路统一：① 将原点代入曲线方程求 \(a=-2\)（判 A）；② 化简得方程后代入 \((2\sqrt{2},0)\) 检验（判 B）；③ 利用特例法（取某 \(x\) 使 \(y>1\)）判定 C 错；④ 由 \(\sqrt{(x-2)^{2}+y^{2}}\geqslant|y|\) 结合方程放缩判 D 正确。
  • 对 C 的讨论最集中：几乎所有评析都强调 C 是"易错陷阱"，指出很多考生凭直觉选了 C；正确做法是用反例或求真正最大值（约 1.05）来否决。
  • 教学评价：普遍认为本题"形在美学、实在方程"，是检验学生是否真正掌握"由几何条件建方程、据方程研性质"全流程的优质题，区分度好、导向正。

十二、教学启示

  • 强化"曲线与方程"全流程训练：从建系、设点、列式、化简到据方程研性质，形成闭环，避免只会联立不会建方程。
  • 狠抓绝对值与隐含条件：遇到"横坐标大于某值"要立即转化为去绝对值、定定义域，这是本题建模的第一道关。
  • 培养反例意识：多选题的"错误项"往往用举反例最快否决，训练学生"先试特殊值、再决定是否硬算"。
  • 不等式放缩要敏感：遇到 \(\sqrt{A^{2}+B^{2}}\) 类结构，自然联想 \(\geqslant|A|,|B|\)，用于快速证明 D 类结论。
  • 数形结合预判：动手前先用对称性、关键点粗略勾勒曲线形状，帮助定位最值与陷阱。
  • 规范多选策略：对拿不准的选项宁可观望，确保已确认项得分；对 C 类陷阱要"宁可信其错，举反例验证"。
