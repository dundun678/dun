研究对象：三次函数 f(x)=2x³-3ax²+1 的性质判定（多选）　·　题型定位：多项选择题（压轴多选）　·　研究视角：高中数学教师教研

一、试题呈现

题目（2024 年新课标Ⅱ卷·第 11 题，多项选择题，6 分）。设函数 \(f(x)=2x^{3}-3ax^{2}+1\)，则

  • 当 \(a>1\) 时，\(f(x)\) 有三个零点
  • 当 \(a<0\) 时，\(x=0\) 是 \(f(x)\) 的极大值点
  • 存在 \(a,b\)，使得 \(x=b\) 为曲线 \(y=f(x)\) 的对称轴
  • 存在 \(a\)，使得点 \((1,f(1))\) 为曲线 \(y=f(x)\) 的对称中心
官方答案：A、D（本题为多项选择题，全部选对得 6 分，部分选对得部分分，有选错得 0 分）。

三、必备知识点

  • 导数与单调性、极值：由 \(f'(x)=6x(x-a)\) 得驻点 \(x=0\) 与 \(x=a\)，\(a\) 的符号决定二者谁是极大、谁是极小。
  • 零点个数判定：结合极值点位置、极值符号与两端极限（\(x\to\pm\infty\) 时 \(2x^{3}\) 主导），用零点存在定理判定零点个数。
  • 三次函数的拐点与对称中心：三次函数 \(y=px^{3}+qx^{2}+rx+s\) 的对称中心横坐标为 \(x=-\dfrac{q}{3p}\)（即二阶导零点、拐点）。
  • 函数对称性的代数判定：轴对称需 \(f(b+t)=f(b-t)\) 对所有 \(t\) 恒成立；中心对称需 \(f(h+t)+f(h-t)=2f(h)\) 恒成立。
  • 分类讨论：按 \(a\) 与 \(0\)、\(a\) 与 \(1\) 的大小关系分别讨论极值类型与零点个数。

六、命题思路

  • 多选压轴、综合覆盖：一道题同时考查零点、极值、轴对称、中心对称，覆盖面广、思维跨度大。
  • 选项分层设陷阱：B 利用“\(a<0\) 时极值类型反转”设错；C 考查“三次函数不存在竖直对称轴”的常识；D 考查“对称中心横坐标可调”。
  • 区分度设计：A、D 正确，B、C 为典型错选；能否全对取决于导数与对称性功底，有效区分尖子生。
  • 弱化套路、强调本质：不考复杂积分或含参不等式，而考对函数整体性质的深刻理解。
  • 存在性问题：C、D 均为“存在性”判断，呼应新课标对探究能力与代数论证的强调。

七、解析思路与完整解答

先求导并标准化：

\[ f'(x)=6x^{2}-6ax=6x(x-a),\qquad f''(x)=12x-6a \]

驻点为 \(x=0\) 与 \(x=a\)；极值类型随 \(a\) 的符号翻转，需分类讨论。

7.1 选项 A：当 \(a>1\) 时，\(f(x)\) 有三个零点

因 \(a>1>0\)，驻点顺序为 \(0<a\)。由 \(f'\) 的符号：

区间\((-\infty,0)\)\((0,a)\)\((a,+\infty)\)
\(f'(x)=6x(x-a)\) 符号\(+\)\(-\)\(+\)
单调性增减增

故 \(x=0\) 为极大值点、\(x=a\) 为极小值点。计算极值：

\[ f(0)=1>0,\qquad f(a)=2a^{3}-3a\cdot a^{2}+1=1-a^{3}<0\quad (a>1) \]

又因三次项系数 \(2>0\)，有 \(\lim\limits_{x\to-\infty}f(x)=-\infty\)、\(\lim\limits_{x\to+\infty}f(x)=+\infty\)。由零点存在定理：

  • 在 \((-\infty,0)\)：从 \(-\infty\) 增至 \(f(0)=1>0\)，恰有 1 个零点；
  • 在 \((0,a)\)：从 \(1\) 减至 \(1-a^{3}<0\)，恰有 1 个零点；
  • 在 \((a,+\infty)\)：从 \(1-a^{3}<0\) 增至 \(+\infty\)，恰有 1 个零点。

共 3 个零点。选项 A 正确。

7.2 选项 B：当 \(a<0\) 时，\(x=0\) 是 \(f(x)\) 的极大值点

当 \(a<0\) 时，驻点顺序为 \(a<0\)。由 \(f'\) 符号知 \(x=a\) 为极大、\(x=0\) 为极小；亦可由二阶导 \(f''(0)=-6a>0\)（因 \(a<0\)）判定 \(x=0\) 为极小值点。B 称其为极大值点，错误。

7.3 选项 C：存在 \(a,b\)，使得 \(x=b\) 为对称轴

若 \(x=b\) 为对称轴，则对任意 \(t\) 有 \(f(b+t)=f(b-t)\)。作差：

\[ f(b+t)-f(b-t)=2\big[(b+t)^{3}-(b-t)^{3}\big]-3a\big[(b+t)^{2}-(b-t)^{2}\big] \]

\[ =2(6b^{2}t+2t^{3})-3a(4bt)=4t^{3}+12b(b-a)t \]

要使上式对一切 \(t\) 恒为 \(0\)，必须 \(t^{3}\) 的系数 \(4=0\)，矛盾。故任何三次函数都不可能关于某条竖直直线对称，选项 C 错误。（本质：奇次多项式不能关于竖直线偶对称。）

7.4 选项 D：存在 \(a\)，使得 \((1,f(1))\) 为对称中心

三次函数必有唯一对称中心，其横坐标为二阶导零点：

\[ f''(x)=12x-6a=0\ \Longrightarrow\ x=\frac{a}{2} \]

即对称中心为 \(\big(\frac{a}{2},f(\frac{a}{2})\big)\)。令 \(\frac{a}{2}=1\)，得 \(a=2\)，故存在 \(a=2\) 使 \((1,f(1))\) 为对称中心，选项 D 正确。

验证：取 \(a=2\)，\(f(x)=2x^{3}-6x^{2}+1\)，\(f(1)=-3\)。对任意 \(t\)：

\[ f(1+t)+f(1-t)=\big[-3-6t+2t^{3}\big]+\big[-3+6t-2t^{3}\big]=-6=2f(1) \]

满足中心对称定义，对称中心确为 \((1,-3)\)。

7.5 结论

正确选项为 A、D。

八、解答技巧

  • 求导标准化：一眼写出 \(f'(x)=6x(x-a)\)，驻点固定为 \(0\) 与 \(a\)，不必每次重算。
  • 零点判定三要素：极值点位置、极值符号、两端极限，三者齐备再用零点存在定理。
  • 极值类型随 \(a\) 翻转：记住 \(a>0\) 时 \(0\) 为极大、\(a\) 为极小；\(a<0\) 时相反——B 正是利用此反转设错。
  • 三次函数无竖直对称轴：奇次多项式不可能关于竖直线偶对称，C 直接判错，省时。
  • 对称中心 = 拐点：横坐标由 \(f''(x)=0\) 得 \(x=\frac{a}{2}\)，要让对称中心过指定横坐标，只需令 \(\frac{a}{2}=\) 该值反求 \(a\)。
  • 多选策略：部分选对得部分分，错选得 0 分，确定性不足时宁可少选。

九、未来命题趋势

  • 多选压轴稳定：导数与函数性质的综合多选仍是新高考压轴多选的常驻题型。
  • 对称性与导数交融：轴对称、中心对称的代数判定与导数（拐点）的结合会更频繁出现。
  • 存在性问题升温：以“存在 \(a\) 使……”为外壳，考查设参、恒等、系数比较等代数论证。
  • 零点与参数范围：由零点个数反求参数范围，或将“几个零点”作为条件设问。
  • 衔接高等数学：拐点、曲率、泰勒展开前置概念可能以更隐蔽方式进入压轴题。
  • 弱化套路、强化本质：继续减少机械套模板，强调对函数整体性质的真正理解。

十、学生解答的最大障碍与典型失误

  • 极值类型判断错：\(a<0\) 时把 \(x=0\) 误判为极大，踩中 B 的陷阱。
  • 零点个数漏判：未结合极值符号与两端极限，或误以为“\(a>0\) 就三个零点”（实则须 \(a>1\)）。
  • 对称轴认知偏差：以为三次函数也可能有对称轴，缺乏“奇次多项式不能偶对称”的意识。
  • 对称中心记错：把对称中心横坐标写成 \(a\) 而非 \(\frac{a}{2}\)，或不会用拐点结论反求参数。
  • 多选策略失误：漏选 D、或错选 B、C，导致部分失分甚至 0 分。

十一、互联网评价与讨论综述

本题为 2024 年新课标Ⅱ卷真题，公开解析众多，共识与亮点如下：

  • 答案共识：教习网、腾讯 ima 知识库、心标教育等多家一致给出答案 AD。
  • 主流解析：以 \(f'(x)=6x(x-a)\) 为起点，用极值符号判零点（A），用 \(a<0\) 时极值翻转否定 B，用二项式恒等式反证无对称轴（C），用拐点横坐标 \(\frac{a}{2}\) 肯定 D。
  • 亮点一（C 的代数反证）：教习网给出“设 \(x=b\) 为对称轴则 \(f(b+t)\equiv f(b-t)\)，展开后 \(t^{3}\) 系数无法抵消”的严格证法，极具教学价值。
  • 亮点二（D 的拐点结论）：多处解析直接引用“任何三次函数的对称中心横坐标即 \(f''(x)=0\) 的根”，令 \(\frac{a}{2}=1\) 得 \(a=2\)，简洁漂亮。
  • 讨论焦点：一线教师普遍认为本题是“导数与函数性质”综合的典型压轴多选，B、C 为学生常见错选，是区分尖子生的关键。

十二、教学启示

  • 固化标准处理：让学生熟记 \(f(x)=2x^{3}-3ax^{2}+1\) 类问题的驻点 \(0,a\) 与极值类型随 \(a\) 符号翻转的规律。
  • 讲清分类讨论：强调 \(a\) 的符号（及 \(a\) 与 \(1\) 的大小）对结论的决定作用，培养分类意识。
  • 补充一般结论：给出“奇次多项式无竖直对称轴”“三次函数对称中心 = 拐点（\(f''(x)=0\) 处）”等可迁移结论。
  • 训练代数证伪：用恒等式/系数比较法证明“不存在”，提升严谨论证能力。
  • 强化多选策略：明确“部分选对得部分分、错选 0 分”，引导学生权衡确定性与风险。
  • 设计变式：可改对称中心点为 \((2,f(2))\)、改变系数、或将“有几个零点”转为“求 \(a\) 的范围”等。
