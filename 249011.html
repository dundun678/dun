2024 年九省联考数学第 11 题研究报告

研究对象：抽象函数多选题（f(x+y)+f(x)f(y)=4xy）　·　研究视角：高中数学教师教研

一、试题呈现

已知函数 \(f(x)\) 的定义域为 \(\mathbf{R}\)，且 \(f\left(\frac12\right)\neq 0\)，若 \(f(x+y)+f(x)f(y)=4xy\)，则

A. \(f\left(-\frac12\right)=0\)
B. \(f\left(\frac12\right)=-2\)
C. 函数 \(f\left(x-\frac12\right)\) 是偶函数
D. 函数 \(f\left(x+\frac12\right)\) 是减函数

题源：2024 年 1 月普通高等学校招生全国统一考试适应性测试（九省联考 / 新高考 19 题结构首演）数学试卷，多选题第 11 题（多选压轴），6 分。官方答案：A、B、D。

三、必备知识点

  • 抽象函数的赋值法：对含任意 \(x,y\) 的函数方程，通过赋特殊值（如 \(x=0,y=\frac12\)、\(x=\frac12,y=-\frac12\)、\(y=-\frac12\)）逐步求出关键函数值与函数表达式，是本题的破题主线。
  • 利用非零条件排除：条件 \(f\left(\frac12\right)\neq 0\) 是关键"开关"，用于从 \(f\left(\frac12\right)(1+f(0))=0\) 中推出 \(f(0)=-1\)，避免 \(f\equiv 0\) 的平凡解。
  • 函数奇偶性的判定：通过表达式 \(f\left(x-\frac12\right)=-2x\) 判断其为奇函数（而非偶函数），识破 C 的陷阱。
  • 函数单调性的判定：由 \(f\left(x+\frac12\right)=-2x-2\)（一次函数，斜率 \(-2<0\)）判定其为减函数。
  • 换元与表达式还原：由 \(f\left(x-\frac12\right)=-2x\) 令 \(t=x-\frac12\) 还原出 \(f(t)=-2t-1\)，进而求出任意函数值。

六、命题思路

第 11 题是九省联考多选题的压轴，集中体现了新高考"抽象函数新考点"的命题导向：

  • 抽象函数入题：不给出解析式，仅给函数方程与定义域，考查学生对函数本质的理解，符合近年"反套路、重素养"的命题趋势。
  • 赋值法为天然入口：题目设计使得"赋特殊值"能逐步解锁全部信息，区分"会用赋值法"与"面对抽象函数无从下手"的两类考生。
  • 选项分层设计：A、B 考查具体函数值（易），C、D 考查平移后的奇偶性/单调性（难且设陷阱）——C 故意把奇函数说成偶函数，D 考查一次函数单调性的判定，区分度高。
  • 非零条件作"密钥"：\(f\left(\frac12\right)\neq 0\) 是排除平凡解、确定 \(f(0)\) 的关键，考查学生对"条件如何用"的敏感性。
  • 与整体结构呼应：多选题缩为 3 道（第 9–11 题），第 11 题承载"压轴区分"，思维量向小解答题靠拢。

七、解析思路与完整解答

7.1 解题思路概述

函数方程 \(f(x+y)+f(x)f(y)=4xy\) 对一切实数 \(x,y\) 成立。求解抽象函数的标准武器是赋值法：通过给 \(x,y\) 赋特殊值，逐步求出 \(f(0)\)、\(f\left(-\frac12\right)\)、乃至 \(f(x)\) 的整体表达式，再逐选项判定。

7.2 求 \(f(0)\)

令 \(x=0,\;y=\frac12\)，代入方程：

\(f\left(\frac12\right)+f(0)\,f\left(\frac12\right)=4\cdot 0\cdot \frac12=0\)，

即 \(f\left(\frac12\right)\bigl(1+f(0)\bigr)=0\)。由已知 \(f\left(\frac12\right)\neq 0\)，得

\(1+f(0)=0\quad\Rightarrow\quad f(0)=-1\)。
若忽略 \(f\left(\frac12\right)\neq 0\) 这一条件，会遗漏对平凡解的排除；该条件是确定 \(f(0)\) 的"密钥"。

7.3 判定选项 A（求 \(f\left(-\frac12\right)\)）

令 \(x=\frac12,\;y=-\frac12\)，代入方程：

\(f(0)+f\left(\frac12\right)f\left(-\frac12\right)=4\cdot\frac12\cdot\left(-\frac12\right)=-1\)。

代入 \(f(0)=-1\) 并移项：

\(-1+f\left(\frac12\right)f\left(-\frac12\right)=-1\;\Rightarrow\;f\left(\frac12\right)f\left(-\frac12\right)=0\)。

因 \(f\left(\frac12\right)\neq 0\)，故 \(f\left(-\frac12\right)=0\)。A 正确。

7.4 求整体表达式（关键一步）

令 \(y=-\frac12\)，代入方程（此时 \(x\) 仍为任意实数）：

\(f\left(x-\frac12\right)+f(x)\,f\left(-\frac12\right)=4x\cdot\left(-\frac12\right)=-2x\)。

由已得 \(f\left(-\frac12\right)=0\)，第二项消失，得

\(f\left(x-\frac12\right)=-2x\)。

令 \(t=x-\frac12\)（即 \(x=t+\frac12\)），代入右端：

\(f(t)=-2\left(t+\frac12\right)=-2t-1\)。

即对任意实数 \(x\)，

\(f(x)=-2x-1\)。

可代回原方程验证：\(f(x+y)+f(x)f(y)=-2(x+y)-1+(-2x-1)(-2y-1)=-2x-2y-1+4xy+2x+2y+1=4xy\)，恒成立，表达式正确。

7.5 判定选项 B、C、D

  • B：\(f\left(\frac12\right)=-2\cdot\frac12-1=-2\)。B 正确。
  • C：由 \(f\left(x-\frac12\right)=-2x\)，记 \(g(x)=f\left(x-\frac12\right)=-2x\)。则 \(g(-x)=2x=-g(x)\)，为奇函数，并非偶函数。C 错误（陷阱）。
  • D：\(f\left(x+\frac12\right)=-2\left(x+\frac12\right)-1=-2x-2\)。这是一次函数，斜率 \(-2<0\)，在 \(\mathbf{R}\) 上严格递减。D 正确。

7.6 结论

正确选项为 \(\boxed{\text{A、B、D}}\)（C 为错误选项）。

八、解答技巧

  • 赋值顺序有讲究：先赋 \((0,\frac12)\) 求 \(f(0)\) → 再赋 \((\frac12,-\frac12)\) 求 \(f(-\frac12)\) → 最后令 \(y=-\frac12\) 得平移式。这是"由点及线、由特殊到一般"的赋值阶梯。
  • 善用非零条件：见到 \(f(a)\neq 0\) 这类条件，第一时间想"它能在哪个乘积式中做除数/排除因子"，本题正是用它排除 \(f\equiv 0\) 并确定 \(f(0)\)。
  • 平移变换判性质：求得 \(f\left(x-\frac12\right)=-2x\) 后，C、D 直接化为"\(-2x\) 的奇偶性"与"\(-2x-2\) 的单调性"，无需再回到原方程。
  • 识破奇偶陷阱：C 把"奇函数"说成"偶函数"，是命题人常用的反向设障；判定时务必写出 \(g(-x)\) 而非凭感觉。
  • 表达式务必代回验证：推导出 \(f(x)=-2x-1\) 后，代回原方程确认恒成立，可稳妥排除计算错误。

九、未来命题趋势

  • 抽象函数成为高频考点：以函数方程（含加法型、乘法型、复合型）为背景的抽象函数题，在多选题压轴与解答题中占比上升。
  • 赋值法仍是核心武器：命题将继续以"给方程不给解析式"的方式，考查学生用特殊值解锁整体性质的能力。
  • 选项设陷阱常态化：如本题 C 把奇说偶，未来更可能出现"性质反向表述""定义域/值域偷换"等干扰项，要求学生逐项严谨验证。
  • 与函数性质深度融合：抽象函数题将更紧密地结合奇偶性、单调性、周期性、对称性综合考查，单一性质判断越来越少。
  • 非零/边界条件作"密钥"：类似 \(f(a)\neq 0\)、\(x>0\) 等限定条件将成为区分"会否用条件"的关键设计。
  • 多选压轴解答题化：新结构下多选仅 3 道，第 11 题思维量向小解答题靠拢，可能出现"多步推导才能判定全选"的格局。

十、学生解答的最大障碍与典型失误

  • 不会用赋值法：面对无解析式的抽象函数，很多学生"不知从何下手"，缺乏"赋特殊值"的意识。
  • 忽略 \(f\left(\frac12\right)\neq 0\) 条件：导致无法确定 \(f(0)\)，或误判存在平凡解，后续推导全盘皆错。
  • 漏选 D / 误选 C：C 把奇函数说成偶函数，是高频误选；D 的一次函数单调性若未写出表达式也容易漏判。
  • 选项验证不彻底：只算出自认为对的项，未对四个选项逐一判定，多选易丢"部分分"。
  • 混淆平移对奇偶性的影响：以为"原函数线性即偶/奇"而忽略 \(f\left(x-\frac12\right)\) 与 \(f(x)\) 的奇偶性差异。
  • 表达式求错或漏验证：换元还原 \(f(t)=-2t-1\) 时符号出错（如写成 \(-2t+1\)），导致 B、D 全错。

十一、互联网评价与讨论综述

九省联考作为新高考 19 题结构的"首演"，第 11 题（抽象函数多选题）是一线教师与自媒体讨论的热点之一：

  • 解法高度统一为赋值法：学科网、原创力文档、Fiddie 数学杂谈（Scribd 转载）等来源均给出"赋 \((0,\frac12)\) 求 \(f(0)\) → 赋 \((\frac12,-\frac12)\) 求 \(f(-\frac12)\) → 令 \(y=-\frac12\) 得平移式 → 还原 \(f(x)=-2x-1\)"的标准路径，答案一致为 ABD。
  • 教学共识：教师普遍将本题视为"抽象函数赋值法"的标杆例题，强调"非零条件是密钥""平移变换判定奇偶/单调"的解题范式，并提醒学生警惕 C 的奇偶陷阱。
  • 命题评价：评析文章（如《新高考数学填空压轴题赏析》同类专栏）指出，本题与第 14 题共同体现了九省联考"小切口、深思维、重素养"的命题导向，抽象函数正式回归压轴位置。
  • 分歧 / 存疑点：个别早期流传解析在相邻题（如第 12、13 题）上有笔误，但第 11 题的答案 ABD 与解析在各权威来源间高度一致，无误。

十二、教学启示

  • 系统训练赋值法：把"赋 \(0\)、赋对称点、令某变量为某常数"作为抽象函数专题的固定操作清单，形成肌肉记忆。
  • 强化"条件敏感性"：专门训练学生识别 \(f(a)\neq 0\)、\(x>0\) 等"密钥条件"并主动用于排除或确定参数。
  • 平移变换专项：讲清 \(f(x-a)\) 与 \(f(x)\) 在奇偶性/单调性上的关系，结合本题 C、D 选项破除"线性即偶"的错觉。
  • 多选题策略训练：要求"逐项独立判定、宁缺毋滥"，明确"部分选对得部分分、有错得 0 分"的得分规则，避免盲目求全。
  • 表达式必验证习惯：推导出函数解析式后，强制代回原方程检验，把"算对"变成可自愈的流程。
  • 适度拓展：在赋值法之外，可补充"构造辅助函数（如令 \(g(x)=f(x)+1\)）"等进阶视角，拓宽抽象函数解题视野。
