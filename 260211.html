2026 年高考数学全国二卷第 11 题研究报告

研究对象：抛物线与等边三角形综合（多选压轴）　·　研究视角：高中数学教师教研

一、试题呈现

已知抛物线 \(E:y^{2}=8x\)，斜率为 \(k\)（\(k>0\)）的直线 \(l\) 过点 \((-1,0)\)，若点 \(A\) 在抛物线 \(E\) 上，\(B,C\) 两点在直线 \(l\) 上，且 \(\triangle ABC\) 为等边三角形，则下列判断正确的是（　）

选项内容
A抛物线 \(E\) 的准线方程为 \(x=-2\)
B当直线 \(l\) 与抛物线 \(E\) 无交点时，\(k>\sqrt{2}\)
C若 \(l\) 与 \(E\) 相交于唯一一点 \(B\)，则抛物线 \(E\) 的焦点在直线 \(AB\) 上
D当 \(k=2\) 时，\(\triangle ABC\) 面积的最小值为 \(\dfrac{\sqrt{3}}{15}\)
答案：A, B, D

三、必备知识点

  • 抛物线基本量：由 \(y^{2}=8x=2px\) 得 \(p=4\)，焦点 \(F(2,0)\)，准线 \(x=-2\)。
  • 直线与抛物线联立：将 \(y=k(x+1)\) 代入 \(y^{2}=8x\)，化为关于 \(x\)（或 \(y\)）的二次方程，用判别式 \(\Delta\) 判定交点个数。
  • 点到直线的距离：点 \(A(x_{0},y_{0})\) 到直线 \(Ax+By+C=0\) 的距离 \(d=\dfrac{|Ax_{0}+By_{0}+C|}{\sqrt{A^{2}+B^{2}}}\)。
  • 等边三角形的几何关系：若以 \(BC\) 为底且 \(BC\subset l\)，则点 \(A\) 到 \(l\) 的距离即等边三角形的高 \(h\)，边长 \(a=\dfrac{2h}{\sqrt{3}}\)，面积 \(S=\dfrac{h^{2}}{\sqrt{3}}\)。
  • 两直线夹角公式（反证法用）：\(\tan\theta=\left|\dfrac{k_{2}-k_{1}}{1+k_{1}k_{2}}\right|\)，用于判断焦点是否落在 \(AB\) 上。

六、命题思路

  • 多选递进：A 考查抛物线基本量（送分），B 考查联立判别式（位置关系），C 设置"焦点在 AB 上"的陷阱需反证，D 考查距离最值（综合），层层递进、区分度好。
  • 几何与代数融合：既可用纯代数（判别式、距离公式）一路算，也可借几何直观（等边三角形高、平行线间距离）简化。
  • 去套路化：不直接问"求最值"，而是嵌在等边三角形约束中，须先完成"空间（平面）问题→点到直线距离"的转化。
  • 反例辨析：C 选项似是而非，须验证角度而非凭直觉，考查严谨推理。

七、解析思路与完整解答

7.1 选项 A：准线方程

由 \(y^{2}=8x=2px\) 得 \(p=4\)，准线方程为 \(x=-\dfrac{p}{2}=-2\)。

A 正确。

7.2 选项 B：直线 \(l\) 与抛物线无交点的条件

直线 \(l:y=k(x+1)\)。代入 \(y^{2}=8x\)：

\(k^{2}(x+1)^{2}=8x\;\Rightarrow\;k^{2}x^{2}+(2k^{2}-8)x+k^{2}=0.\)

判别式

\(\Delta=(2k^{2}-8)^{2}-4k^{4}=64-32k^{2}.\)

无公共点 \(\Leftrightarrow \Delta<0 \Leftrightarrow 64<32k^{2}\Leftrightarrow k^{2}>2\)。又 \(k>0\)，故 \(k>\sqrt{2}\)。

B 正确。
等价消元：由 \(x=\dfrac{y}{k}-1\) 代入 \(y^{2}=8x\) 得 \(ky^{2}-8y+8k=0\)，\(\Delta=64-32k^{2}\)，结论相同。

7.3 选项 C：焦点是否在直线 \(AB\) 上（反证）

\(l\) 与 \(E\) 有唯一公共点 \(\Leftrightarrow\) 相切 \(\Leftrightarrow \Delta=0\Leftrightarrow k=\sqrt{2}\)（\(k>0\)）。

切点 \(B\)：代入 \(k=\sqrt{2}\) 于 \(ky^{2}-8y+8k=0\)，得 \(y=2\sqrt{2}\)（二重根），\(x=\dfrac{y^{2}}{8}=1\)，故 \(B(1,2\sqrt{2})\)。焦点 \(F(2,0)\)。

此时直线 \(BC\) 即切线 \(l\)，斜率 \(k_{BC}=\sqrt{2}\)。若焦点 \(F\) 在直线 \(AB\) 上，则直线 \(AB\) 与 \(BF\) 重合，斜率 \(k_{BF}=\dfrac{0-2\sqrt{2}}{2-1}=-2\sqrt{2}\)。

直线 \(BF\) 与 \(BC\) 的夹角 \(\theta\) 满足

\(\tan\theta=\left|\frac{k_{BC}-k_{BF}}{1+k_{BC}k_{BF}}\right|=\left|\frac{\sqrt{2}-(-2\sqrt{2})}{1+\sqrt{2}\cdot(-2\sqrt{2})}\right|=\left|\frac{3\sqrt{2}}{1-4}\right|=\sqrt{2}.\)

而 \(\tan 60^{\circ}=\sqrt{3}\neq\sqrt{2}\)，故 \(\theta\neq 60^{\circ}\)，与 \(\triangle ABC\) 为等边三角形（\(\angle ABC=60^{\circ}\)）矛盾。

C 错误（焦点不在直线 \(AB\) 上）。

7.4 选项 D：\(\triangle ABC\) 面积的最小值

当 \(k=2\) 时，直线 \(l:y=2x+2\)，即 \(2x-y+2=0\)。设 \(A\left(\dfrac{t^{2}}{8},\,t\right)\) 在抛物线上，则点 \(A\) 到 \(l\) 的距离

\(d=\frac{\left|2\cdot\dfrac{t^{2}}{8}-t+2\right|}{\sqrt{2^{2}+(-1)^{2}}}=\frac{\left|\dfrac{t^{2}}{4}-t+2\right|}{\sqrt{5}}=\frac{\left|\dfrac{(t-2)^{2}}{4}+1\right|}{\sqrt{5}}\ge\frac{1}{\sqrt{5}}.\)

等号在 \(t=2\)（即 \(A\left(\frac{1}{2},2\right)\)）时成立。该距离即等边三角形的高 \(h\)，故面积

\(S=\frac{h^{2}}{\sqrt{3}}=\frac{d^{2}}{\sqrt{3}}\ge\frac{\left(\frac{1}{\sqrt{5}}\right)^{2}}{\sqrt{3}}=\frac{1}{5\sqrt{3}}=\frac{\sqrt{3}}{15}.\)
D 正确（最小面积为 \(\dfrac{\sqrt{3}}{15}\)）。
另法（平行线距离）：与 \(l\) 平行且斜率为 \(2\) 的抛物线切线为 \(y=2x+1\)，两平行线间距恰为 \(\dfrac{1}{\sqrt{5}}\)，即 \(d_{\min}\)，结论一致。

八、解答技巧

  • A 秒杀：认准 \(y^{2}=2px\) 标准形式，直接写准线。
  • B 判别式：联立后只需算 \(\Delta\)，注意"无交点"对应 \(\Delta<0\) 且结合 \(k>0\) 开方。
  • C 反证最稳：不正面求 \(A\)，而是假设焦点在 \(AB\) 上推出 \(\angle ABC\) 的正切为 \(\sqrt{2}\neq\sqrt{3}\)，矛盾即可判假；也可用向量夹角余弦 \(\cos\angle PBF\neq\frac{1}{2}\) 证伪。
  • D 转化法：把"等边三角形面积最小"转化为"抛物线上点到定直线距离最小"，再用二次函数配方（或平行线距离）求最值，避免求具体顶点。

九、未来命题趋势

  1. 多选题压轴继续以"圆锥曲线 + 几何图形（三角、圆、多边形）"综合为主。
  2. 设问呈"基础性质→位置关系→反例辨析→最值"递进，考查完整思维链。
  3. 重几何直观与代数运算并重，"多想少算"导向明显（D 用距离转化即典型）。
  4. 反证/排除类选项增多，抑制"凭感觉选"，强化严谨推理。
  5. 最值问题偏好"动点在曲线上、约束几何图形"的模型，常归约为距离或函数最值。
  6. 抛物线仍是新高考Ⅱ卷高频载体，与定点、定直线、对称性结合紧密。

十、学生解答的最大障碍与典型失误

  • 选项 B 中"无交点"误用 \(\Delta\le0\) 或忘记 \(k>0\) 取错根号方向。
  • 选项 C 凭"相切 + 对称"直觉误判为真，未做角度/向量验证。
  • 选项 D 不会把等边三角形面积转化为点到直线距离，陷入求具体 \(A,B,C\) 坐标的复杂运算。
  • 距离公式分母为 \(\sqrt{A^{2}+B^{2}}\) 时漏算或代错系数。
  • 多选题策略失误：怕错选得 0 分而不敢选满，或漏选 D。

十一、互联网评价与讨论综述

  • 21 世纪教育网（详细解析）给出标准判定：A 准线、B 联立得 \(\Delta=64-32k^{2}\) 无交点即 \(k>\sqrt{2}\)、C 切线 \(k=\sqrt{2}\) 切点 \(B(1,2\sqrt{2})\) 用夹角证伪、D 距离最小值得 \(\dfrac{\sqrt{3}}{15}\)，答案 ABD。
  • 教习网《2026 全国Ⅱ卷含解析》与 今日头条逐题答案均确认第 11 题答案为 ABD。
  • 共识：本题四选项分层清晰，A/B 为基础分，C 为易错陷阱，D 为能力分；网络回忆版在选项文字（如把直线过点写成 \((1,0)\)、把 D 值写成 \(\frac{\sqrt{3}}{2}\) 等）存在讹误，但以"直线过 \((-1,0)\)、\(A\) 在抛物线上、\(B,C\) 在直线上、答案 ABD、D 值为 \(\frac{\sqrt{3}}{15}\)"为准（与官方卷一致）。

十二、教学启示

  • 夯实抛物线基本量（\(p\)、焦点、准线）的即时辨认训练。
  • 强化"联立→判别式"判定交点个数的熟练度，明确"相切/无交/两交"的 \(\Delta\) 边界。
  • 训练反证与几何验证意识：对"某点是否在直线上"类选项，优先用斜率/夹角/向量余弦快速证伪。
  • 培养几何转化能力：把"动图形最值"归约为"曲线上点到定直线距离最值"，善用二次函数配方或平行切线法。
  • 多选题讲策略：先稳拿基础项，再用严谨推理确认陷阱项与综合项，避免保守漏选。
