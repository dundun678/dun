节1.1 集合的概念与表示2 小节 · 12 知识点
小节1.1.1 集合的概念6 条知识点
定义概念

集合是具有某种特定性质的对象的总体；组成集合的对象称为元素。

定义定义

一般地，把一些能确定的、不同的对象看成一个整体，就说这个整体是由这些对象的全体构成的集合（set）。

性质表示符号

元素（element）$a \in A$ 表示属于（belongs to），$a \notin A$ 表示不属于；集合常用大写字母 $A,B,C,\dots$ 表示，元素用小写 $a,b,c,\dots$。常用数集：$\mathbb{N}$ 自然数集（natural numbers），$\mathbb{N}^*$ 或 $\mathbb{N}_+$ 正整数集，$\mathbb{Z}$ 整数集（integers），$\mathbb{Q}$ 有理数集（rational numbers），$\mathbb{R}$ 实数集（real numbers）。

术语中英术语

set 集合 / element 元素 / belongs to 属于 / natural number 自然数 / integer 整数 / rational number 有理数 / real number 实数。

方法定理 / 公式 / 方法

元素的三大特性——确定性（definiteness）、互异性（distinctness，元素互不相同）、无序性（disorder，集合与元素排列顺序无关）。

性质关系 / 转化

元素与集合是"属于/不属于"（$\in/\notin$）关系，区别于集合与集合的包含关系（$\subseteq$）。

小节1.1.2 集合的表示法6 条知识点
定义概念

用确定的方式把集合中的元素表示出来。

定义定义

列举法（roster method）——把集合的元素一一列举，写在大括号内 $\{a,b,c\}$；描述法（set-builder notation）——“$\{x \in A \mid p(x)\}$”，即满足条件 $p(x)$ 的元素 $x$ 的全体。

性质表示符号

$\{a,b,c\}$；$\{x \mid p(x)\}$；区间记号 $[a,b],(a,b),[a,b),(a,b],(-\infty,a]$ 等。

术语中英术语

roster method 列举法 / set-builder notation 描述法 / Venn diagram 维恩图。

方法定理 / 公式 / 方法

同一集合的列举法与描述法可互化；有限集（finite set）与无限集（infinite set）。

性质关系 / 转化

集合的表示服务于后续的运算；描述法便于表达具有共同属性的元素。

节1.2 集合的基本关系2 小节 · 12 知识点
小节1.2.1 子集6 条知识点
定义概念

一个集合的所有元素都是另一个集合的元素，则前者含于后者。

定义定义

若 $\forall x \in A$ 都有 $x \in B$，则称 $A$ 是 $B$ 的子集（subset），记作 $A \subseteq B$（或 $B \supseteq A$）。

性质表示符号

$A \subseteq B$（$A$ is contained in $B$）；$A \subsetneqq B$ 或 $A \subset B$ 真子集（proper subset）；$\varnothing$ 空集（empty set，不含任何元素的集合）。

术语中英术语

subset 子集 / proper subset 真子集 / empty set 空集。

方法定理 / 公式 / 方法

(1) 反身性 $A \subseteq A$；(2) 传递性 $A \subseteq B$ 且 $B \subseteq C \Rightarrow A \subseteq C$；(3) $\varnothing \subseteq A$（空集是任一集合的子集）；(4) $A \subseteq B$ 且 $B \subseteq A \Leftrightarrow A = B$。

性质关系 / 转化

子集关系是集合间最基本的包含关系；真子集是 "$A \subseteq B$ 且 $A \neq B$"。

小节1.2.2 集合相等6 条知识点
定义概念

两个集合含有完全相同的元素。

定义定义

若 $A \subseteq B$ 且 $B \subseteq A$，则称集合 $A$ 与 $B$ 相等，记作 $A = B$。

性质表示符号

$A = B$。

术语中英术语

equality of sets 集合相等。

方法定理 / 公式 / 方法

判定两集合相等的方法是"互相包含"。

性质关系 / 转化

相等是子集关系的特例（双向包含）。

节1.3 集合的基本运算2 小节 · 12 知识点
小节1.3.1 交集与并集6 条知识点
定义概念

由公共元素构成交集，由全部元素构成并集。

定义定义

交集 $A \cap B = \{x \mid x \in A \text{ 且 } x \in B\}$；并集 $A \cup B = \{x \mid x \in A \text{ 或 } x \in B\}$。

性质表示符号

$\cap$（intersection 交），$\cup$（union 并）；$A \cap B,\; A \cup B$。

术语中英术语

intersection 交集 / union 并集。

方法定理 / 公式 / 方法

交换律 $A \cap B = B \cap A,\; A \cup B = B \cup A$；结合律 $(A \cap B) \cap C = A \cap (B \cap C),\; (A \cup B) \cup C = A \cup (B \cup C)$；分配律 $A \cap (B \cup C) = (A \cap B) \cup (A \cap C),\; A \cup (B \cap C) = (A \cup B) \cap (A \cap C)$；幂等律 $A \cap A = A,\; A \cup A = A$。

性质关系 / 转化

交集取"公共部分"，并集取"合并"；与子集关系：$A \subseteq B \Leftrightarrow A \cap B = A \Leftrightarrow A \cup B = B$。

小节1.3.2 全集与补集6 条知识点
定义概念

相对一个给定集合（全集），取不属于某子集的元素构成补集。

定义定义

全集（universal set）$U$ 是所研究问题涉及的全体元素；补集 $\complement_U A = \{x \mid x \in U \text{ 且 } x \notin A\}$。

性质表示符号

$U$（全集）；$\complement_U A$ 或 $C_U A$（complement 补集）。

术语中英术语

universal set 全集 / complement 补集。

方法定理 / 公式 / 方法

互补律 $A \cup (\complement_U A) = U,\; A \cap (\complement_U A) = \varnothing$；$\complement_U(\complement_U A) = A$；德·摩根律（De Morgan's laws）$\complement_U(A \cap B) = \complement_U A \cup \complement_U B,\; \complement_U(A \cup B) = \complement_U A \cap \complement_U B$。

性质关系 / 转化

补集依赖全集；德·摩根律将交、并与补互相转化。

节2.1 必要条件与充分条件3 小节 · 18 知识点
小节2.1.1 必要条件与性质定理6 条知识点
定义概念

命题 "若 $p$ 则 $q$" 成立时，$p$ 是 $q$ 的充分条件，$q$ 是 $p$ 的必要条件。

定义定义

若 $p \Rightarrow q$（$p$ 推出 $q$），则 $p$ 是 $q$ 的充分条件（sufficient condition），$q$ 是 $p$ 的必要条件（necessary condition）。

性质表示符号

$p \Rightarrow q$（推出）；$p \to q$。

术语中英术语

proposition 命题 / sufficient condition 充分条件 / necessary condition 必要条件 / property theorem 性质定理。

方法定理 / 公式 / 方法

性质定理"若 $p$ 则 $q$"中，条件是结论的充分条件，结论是条件的必要条件。

性质关系 / 转化

充分条件与必要条件互为"另一方向"的关系。

小节2.1.2 充分条件与判定定理6 条知识点
定义概念

判定定理给出充分条件。

定义定义

判定定理"若 $p$ 则 $q$"中，$p$ 是 $q$ 的充分条件（足以判定 $q$ 成立）。

性质表示符号

$p \Rightarrow q$。

术语中英术语

criterion theorem 判定定理。

方法定理 / 公式 / 方法

判定定理提供"由因导果"的充分条件。

性质关系 / 转化

判定定理与性质定理分别从充分、必要两侧刻画同一逻辑联系。

小节2.1.3 充要条件6 条知识点
定义概念

既充分又必要的条件。

定义定义

若 $p \Rightarrow q$ 且 $q \Rightarrow p$，即 $p \Leftrightarrow q$，则 $p$ 是 $q$ 的充要条件（necessary and sufficient condition）。

性质表示符号

$p \Leftrightarrow q$（$p$ 当且仅当 $q$，iff）。

术语中英术语

necessary and sufficient condition 充要条件。

方法定理 / 公式 / 方法

充要条件用于等价转化与求解。

性质关系 / 转化

充要 $\Leftrightarrow$ 充分且必要；平行线判定与性质常互为充要条件。

节2.2 全称量词与存在量词2 小节 · 12 知识点
小节2.2.1 全称量词命题与存在量词命题6 条知识点
定义概念

含"任意/所有"或"存在/有的"的命题。

定义定义

全称量词命题（universal proposition）：$\forall x \in M,\, p(x)$；存在量词命题（existential proposition）：$\exists x \in M,\, p(x)$。

性质表示符号

$\forall$（全称量词 for all / 任意），$\exists$（存在量词 there exists / 存在）。

术语中英术语

universal quantifier 全称量词 / existential quantifier 存在量词 / universal proposition 全称量词命题 / existential proposition 存在量词命题。

方法定理 / 公式 / 方法

量词命题真假判定——全称命题需对 $M$ 中每个元素成立；存在命题只需至少一个成立。

性质关系 / 转化

全称与存在是对偶的量词。

小节2.2.2 全称量词命题与存在量词命题的否定6 条知识点
定义概念

全称命题的否定是存在命题，反之亦然。

定义定义

$\neg(\forall x \in M,\, p(x)) \Leftrightarrow \exists x \in M,\, \neg p(x)$；$\neg(\exists x \in M,\, p(x)) \Leftrightarrow \forall x \in M,\, \neg p(x)$。

性质表示符号

$\neg$（否定 not）。

术语中英术语

negation 否定。

方法定理 / 公式 / 方法

量词命题的否定 = 量词互换 + 结论否定。

性质关系 / 转化

全称 $\leftrightarrow$ 存在 在否定下相互转化。

节3.1 不等式的性质1 小节 · 6 知识点
小节3.1.1 不等式的基本性质6 条知识点
定义概念

比较两实数大小及不等式的运算规律。

定义定义

作差比较：$a - b > 0 \Leftrightarrow a > b$；$a - b = 0 \Leftrightarrow a = b$；$a - b < 0 \Leftrightarrow a < b$。

性质表示符号

$>,\; <,\; \geq,\; \leq$。

术语中英术语

inequality 不等式。

方法定理 / 公式 / 方法

性质 (1) 对称性 $a > b \Leftrightarrow b < a$；(2) 传递性 $a > b,\; b > c \Rightarrow a > c$；(3) 可加性 $a > b \Rightarrow a + c > b + c$；(4) 可乘性 $a > b,\; c > 0 \Rightarrow ac > bc$；$a > b,\; c < 0 \Rightarrow ac < bc$；(5) 同向可乘 $a > b > 0,\; c > d > 0 \Rightarrow ac > bd$；正数乘方 $a > b > 0 \Rightarrow a^n > b^n\;(n \in \mathbb{N}, n \geq 2)$。

性质关系 / 转化

比较大小以作差法为基础，导出各项运算性质。

节3.2 基本不等式2 小节 · 12 知识点
小节3.2.1 基本不等式6 条知识点
定义概念

任意两个正数的算术平均数不小于其几何平均数。

定义定义

对任意 $a > 0,\; b > 0$，$\dfrac{a+b}{2} \geq \sqrt{ab}$，当且仅当 $a = b$ 时取等号。

性质表示符号

$\dfrac{a+b}{2} \geq \sqrt{ab}$；算术平均数 $\dfrac{a+b}{2}$，几何平均数 $\sqrt{ab}$。

术语中英术语

basic inequality 基本不等式 / arithmetic mean 算术平均数 / geometric mean 几何平均数。

方法定理 / 公式 / 方法

可由 $(\sqrt a - \sqrt b)^2 \geq 0$ 推出；特别地 $ab \leq \left(\dfrac{a+b}{2}\right)^2$。

性质关系 / 转化

当且仅当 $a = b$ 取等号；是均值不等式链的基础。

小节3.2.2 基本不等式的应用6 条知识点
定义概念

用基本不等式求最值、证明不等式。

定义定义

应用时把握"一正二定三相等"——变量为正、和或积为定值、等号可取到。

性质表示符号

若 $a,b>0$ 且 $a+b$ 为定值 $S$，则 $ab \leq (S/2)^2$，当 $a=b$ 时取最大；若 $ab$ 为定值 $P$，则 $a+b \geq 2\sqrt P$，当 $a=b$ 时取最小。

术语中英术语

maximum 最大值 / minimum 最小值。

方法定理 / 公式 / 方法

最值结论——和定积最大，积定和最小。

性质关系 / 转化

基本不等式将"和"与"积"联系起来，用于最值问题。

节4.1 一元二次函数1 小节 · 6 知识点
小节4.1.1 一元二次函数的图象与性质6 条知识点
定义概念

形如 $y = ax^2 + bx + c\;(a \neq 0)$ 的函数，图象为抛物线。

定义定义

一元二次函数（quadratic function）$y = ax^2 + bx + c\;(a \neq 0)$。

性质表示符号

$a$（决定开口方向与大小）；对称轴 $x = -\dfrac{b}{2a}$；顶点 $\left(-\dfrac{b}{2a},\; \dfrac{4ac-b^2}{4a}\right)$。

术语中英术语

quadratic function 一元二次函数 / parabola 抛物线 / axis of symmetry 对称轴 / vertex 顶点。

方法定理 / 公式 / 方法

$a > 0$ 开口向上，有最小值；$a < 0$ 开口向下，有最大值；值域由顶点决定。

性质关系 / 转化

一元二次函数是联系一元二次方程与不等式的桥梁（"三个二次"）。

小节4.2.1 一元二次不等式的概念6 条知识点

性质关系 / 转化

小节4.2.2 一元二次不等式的求解方法6 条知识点
定义概念

定义定义

"三个二次"关系——二次函数、一元二次方程、一元二次不等式的对应。

性质表示符号

术语中英术语

性质关系 / 转化

节3 函数的单调性和最值2 小节 · 12 知识点
小节3.1 函数的单调性6 条知识点
定义概念

函数随自变量增大而单调增减。

定义定义
