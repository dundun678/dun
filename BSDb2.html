性质关系 / 转化

定义概念

借助单位圆把锐角三角函数推广到任意角。

定义定义

设角 $\alpha$ 终边与单位圆交于点 $P(u,v)$，则 $\sin\alpha = v,\ \cos\alpha = u$（弧度意义下 $\alpha\in\mathbb{R}$）。若终边上一点 $Q(x,y)$、$r=\sqrt{x^2+y^2}$，则 $\sin\alpha=\dfrac{y}{r},\ \cos\alpha=\dfrac{x}{r}$。

$\sin\alpha$（正弦 sine），$\cos\alpha$（余弦 cosine）；单位圆 $x^2+y^2=1$。

术语中英术语

方法定理 / 公式 / 方法

性质关系 / 转化

三角函数是"圆上点的坐标"随角度变化的函数。

定义概念

利用对称把任意角三角函数化为锐角三角函数。

定义定义

见上；统称诱导公式。

术语中英术语

方法定理 / 公式 / 方法

口诀"奇变偶不变，符号看象限"（核心为 $\tfrac{\pi}{2}$ 的整数倍旋转）。

性质关系 / 转化

对称关系 ↔ 诱导公式。

小节3.2 刻画空间点、线、面位置关系的公理6 条知识点
定义概念

作为推理基础的基本事实（公理）与推论。

定义定义
  • 基本事实 1：不共线的三点确定唯一平面。
  • 基本事实 2：直线上两点在平面内，则整条直线在该平面内（$A,B\in l$ 且 $A,B\in\alpha\Rightarrow l\subset\alpha$）。
  • 推论：一条直线与其外一点、两相交直线、两平行直线各确定一个平面。
  • 基本事实 3：两不重合平面有一公共点，则交于过该点唯一直线（$P\in\alpha,P\in\beta\Leftrightarrow\alpha\cap\beta=l,P\in l$）。
  • 基本事实 4（平行传递性）：平行于同一直线的两直线互相平行。
  • 等角定理：空间中两角的两边分别平行，则两角相等或互补。
  • 异面直线所成角：过空间任一点作 $a'\parallel a,b'\parallel b$，其不大于 $90^\circ$ 的夹角即异面直线所成角；为直角时记 $a\perp b$。
性质表示符号

确定平面、$\parallel$ 传递、$a'\parallel a$ 平移。

术语中英术语

axiom / basic fact 基本事实 / transitive property 传递性 / angle between skew lines 异面直线所成角。

方法定理 / 公式 / 方法

将空间直线位置关系归为相交、平行（共面）、异面三类；平移法是化空间为平面的基本思路。

性质关系 / 转化

共面（相交/平行）↔ 异面；空间问题 ↔ 平面问题（平移转化）。
