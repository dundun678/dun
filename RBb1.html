小节1.1.1 集合及其表示方法11 条知识点
定义概念

集合是刻画一类事物的语言与工具，是一种重要的数学语言，利用它可以简洁、准确地描述数学中的对象与关系。把一些能够确定的、不同的对象汇集在一起，就说由这些对象组成一个集合（简称集），组成集合的每个对象都是这个集合的元素。

要点元素三性

① 确定性——元素必须确定，能否判断某对象属于集合应可明确；② 互异性——集合中元素互不相同，相同对象只算一个（如 success 的字母集合只有 s,u,c,e 4 个元素）；③ 无序性——元素可任意排列。

性质表示符号

集合用大写字母 $A,B,C,\dots$；元素用小写字母 $a,b,c,\dots$；$a\in A$（读作"a 属于 A"）、$a\notin A$（读作"a 不属于 A"）。

定义定义（空集）

不含任何元素的集合称为空集，记作 $\varnothing$，是有限集。

要点集合相等

组成两个集合的元素完全相同，则 $A=B$。

性质分类

含有限个元素称有限集，含无限个元素称无限集。

要点常见的数集

非负整数组 = 自然数集 $\mathbf{N}$（注意 $0\in\mathbf{N}$）；去掉 0 = 正整数集 $\mathbf{N}_{+}$ 或 $\mathbf{N}^{*}$；整数集 $\mathbf{Z}$；有理数集 $\mathbf{Q}$（两整数之商）；实数集 $\mathbf{R}$（本书中所有字母表示的数默认指实数）。例：$0\in\mathbf{Z}$、$\pi\notin\mathbf{Q}$。

要点列举法

把元素一一列举（逗号分隔）写在大括号内，如 $\{0,1\}$、$\{1,2,3,4,6,8,12,24\}$。不考虑顺序：$\{1,2\}=\{2,1\}$；有规律时可省略，如 $\{0,1,2,3,\dots,100\}$、$\mathbf{N}=\{0,1,2,3,\dots\}$。注意 $\{a\}$（集合）与 $a$（元素）不同，$a\in\{a\}$。

性质描述法（特征性质描述法）

若属于 $A$ 的元素 $x$ 都具性质 $p(x)$、不属于 $A$ 的都不具 $p(x)$，则称 $p(x)$ 是 $A$ 的特征性质，$A=\{x\mid p(x)\}$；限定在 $I$ 中写作 $\{x\in I\mid p(x)\}$。例：$A=\{x\mid x>3\}$、$\{x\mid x=3n,\ n\in\mathbf{Z}\}$、$\{(x,y)\mid x>0,\ y>0\}$。

要点区间及其表示 （设 $a<b$）

$[a,b]=\{x\mid a\leqslant x\leqslant b\}$ 闭区间；$(a,b)=\{x\mid a<x<b\}$ 开区间；$[a,b)$、$(a,b]$ 半开半闭区间；无穷区间 $\mathbf{R}=(-\infty,+\infty)$、$[a,+\infty)$、$(a,+\infty)$、$(-\infty,a]$、$(-\infty,a)$。$a,b$ 称左、右端点，$b-a$ 称长度；数轴实心点可取、空心点不可取。例：$A=\left(\frac12,+\infty\right)$。

术语中英术语

set 集合 / element 元素 / empty set 空集 / finite set 有限集 / infinite set 无限集 / natural numbers 自然数 / integer 整数 / rational number 有理数 / real number 实数 / interval 区间 / closed interval 闭区间 / open interval 开区间。

小节1.1.2 集合的基本关系9 条知识点
定义定义（子集）

若集合 $A$ 的任意一个元素都是集合 $B$ 的元素，则 $A$ 是 $B$ 的子集，记作 $A\subseteq B$ 或 $B\supseteq A$（读作"A 包含于 B"）。

定义定义（真子集）

若 $A\subseteq B$ 且 $B$ 中至少有一个元素不属于 $A$，则 $A$ 是 $B$ 的真子集，记作 $A\subsetneqq B$ 或 $B\supsetneq A$。

性质基本事实

$A\subseteq A$（任意集合是自身子集）；$\varnothing\subseteq A$（空集是任意集合的子集）。

要点集合相等

$A\subseteq B$ 且 $B\subseteq A\iff A=B$。

性质定理 / 性质
  • 传递性：$A\subseteq B$ 且 $B\subseteq C\Rightarrow A\subseteq C$；$A\subsetneqq B$ 且 $B\subsetneqq C\Rightarrow A\subsetneqq C$；
  • 当 $A\subseteq B$ 时，要么 $A\subsetneqq B$，要么 $A=B$。
要点子集个数

含 $n$ 个元素的集合有 $2^{n}$ 个子集、$2^{n}-1$ 个真子集；可按含 $0,1,2,\dots,n$ 个元素分类枚举。

要点维恩图（Venn diagram）

用封闭曲线内部表示集合，直观表示集合关系。

术语中英术语

subset 子集 / proper subset 真子集 / Venn diagram 维恩图。

拓展拓展阅读

罗素悖论（"理发师困境"）引发第三次数学危机；通过集合论公理化解决——规定集合不能以自身为元素。

小节1.1.3 集合的基本运算8 条知识点
定义定义（交集）

由既属于 $A$ 又属于 $B$ 的元素（公共元素）组成的集合，记 $A\cap B$；无公共元素时 $A\cap B=\varnothing$。性质：$A\cap B=B\cap A$；$A\cap A=A$；$A\cap\varnothing=\varnothing$；$A\subseteq B\Rightarrow A\cap B=A$。

定义定义（并集）

由 $A$、$B$ 所有元素组成的集合，记 $A\cup B$；公共元素只出现一次。性质：$A\cup B=B\cup A$；$A\cup A=A$；$A\cup\varnothing=A$；$A\subseteq B\Rightarrow A\cup B=B$。

定义定义（全集与补集）

研究所用集合都是某给定集合的子集，则该集合称全集，记作 $U$；$A\subseteq U$ 时，$U$ 中不属于 $A$ 的元素组成 $A$ 在 $U$ 中的补集，记作 $\complement_{U}A$。性质：$A\cup(\complement_{U}A)=U$；$A\cap(\complement_{U}A)=\varnothing$；$\complement_{U}(\complement_{U}A)=A$。

性质表示符号

$A\cap B$、$A\cup B$、$\complement_{U}A$；有限集元素个数记 $\operatorname{card}(M)$，规定 $\operatorname{card}(\varnothing)=0$。

要点德摩根定律

$\complement_{U}(A\cap B)=(\complement_{U}A)\cup(\complement_{U}B)$；$\complement_{U}(A\cup B)=(\complement_{U}A)\cap(\complement_{U}B)$。

性质容斥关系

$\operatorname{card}(A\cup B)=\operatorname{card}(A)+\operatorname{card}(B)-\operatorname{card}(A\cap B)$。

性质关系 / 转化

日常用语"且"对应交集、"或"对应并集。例：$x\geqslant0=\{x\mid x>0\}\cup\{x\mid x=0\}$；菱形∩矩形=正方形。

术语中英术语

intersection 交集 / union 并集 / complement 补集 / universal set 全集 / cardinality 基数。

节1.2 常用逻辑用语3 小节 · 22 知识点
小节1.2.1 命题与量词7 条知识点
定义定义（命题）

可以判断真假的陈述语句。判断为真为真命题，为假为假命题；命题不能既真又假、也不能模棱两可。可用小写字母 $p,q,r$ 表示，也可借助符号与式子表达（如 $\sqrt{9}=3$）。

拓展猜想

至今未能判断真假的命题称为猜想，如哥德巴赫猜想。

定义定义（全称量词）

"任意""所有""每一个"表示所述事物的全体，称全称量词，用符号 $\forall$；其命题形如 $\forall x\in M,\ r(x)$。

定义定义（存在量词）

"存在""有""至少有一个"表示个体或部分，称存在量词，用符号 $\exists$；其命题形如 $\exists x\in M,\ s(x)$。

方法真假判定

全称量词命题为真须对 $M$ 中每个 $x$ 验证，为假只需举一个反例；存在量词命题为真只需举一例，为假须说明每个都不成立。

要点多变量

量词命题可含多个变量，如 $\forall a,b\in\mathbf{R},\ a^{2}-b^{2}=(a+b)(a-b)$；$\forall x\in\mathbf{R},\ \exists y\in\mathbf{R},\ y=x+1$。

术语中英术语

proposition 命题 / quantifier 量词 / universal quantifier 全称量词 / existential quantifier 存在量词 / conjecture 猜想。

小节1.2.2 全称量词命题与存在量词命题的否定6 条知识点
定义定义（命题的否定）

对命题 $p$ 加以否定得到的新命题，记 $\neg p$（读作"非 p"或"p 的否定"）。$p$ 真则 $\neg p$ 假，$p$ 假则 $\neg p$ 真。

性质表示符号

$\neg p$。

性质否定法则
  • 存在量词命题的否定是全称量词命题：$\neg(\exists x\in M,\ p(x))=\forall x\in M,\ \neg p(x)$；
  • 全称量词命题的否定是存在量词命题：$\neg(\forall x\in M,\ q(x))=\exists x\in M,\ \neg q(x)$。
例例

$\neg(\exists x\in\mathbf{Z},\ x\in\mathbf{N})=\forall x\in\mathbf{Z},\ x\notin\mathbf{N}$；$\neg(\forall x\in\mathbf{Q},\ x\in\mathbf{R})=\exists x\in\mathbf{Q},\ x\notin\mathbf{R}$。

性质关系 / 转化

对含量词命题取否定时，量词互换、结论否定、真假性互换。

术语中英术语

negation 否定 / proposition negation 命题的否定。

小节1.2.3 充分条件、必要条件9 条知识点
定义定义（推出）

形如"如果 $p$，那么 $q$"的命题中，$p$ 称条件、$q$ 称结论。为真称 $p$ 推出 $q$，记 $p\Rightarrow q$；否则记 $p\not\Rightarrow q$。

定义定义（充分 / 必要条件）

$p\Rightarrow q$ 时，$p$ 是 $q$ 的充分条件、$q$ 是 $p$ 的必要条件。

定义定义（充要条件）

$p\Rightarrow q$ 且 $q\Rightarrow p$，则 $p$ 是 $q$ 的充分必要条件，记 $p\Leftrightarrow q$，读作"p 与 q 等价"`p 当且仅当 q"。

定义定义（充分不必要 / 必要不充分）

$p\Rightarrow q$ 且 $q\not\Rightarrow p$ 为充分不必要；$p\not\Rightarrow q$ 且 $q\Rightarrow p$ 为必要不充分；两者均不成立则既不充分也不必要。

性质表示符号

$p\Rightarrow q$、$p\Leftrightarrow q$、$p\not\Rightarrow q$。

要点集合解释

$A=\{x\mid p(x)\}$、$B=\{x\mid q(x)\}$，$A\subseteq B\Rightarrow p\Rightarrow q$（充分/必要）；$A=B\Rightarrow p\Leftrightarrow q$（充要）。

性质与定理的关系

判定定理给出充分条件，性质定理给出必要条件，定义给出充要条件（数学对象常有多种等价定义）。

例例

$x=-y\Rightarrow x^{2}=y^{2}$；$x\geqslant0\Leftrightarrow\sqrt{x}$ 有意义；$\triangle ABC$ 中 $\angle B=\angle C\Leftrightarrow AC=AB$。

术语中英术语

sufficient condition 充分条件 / necessary condition 必要条件 / sufficient and necessary condition 充要条件。

章第二章 等式与不等式2 节 · 7 小节 · 54 知识点
节2.1 等式3 小节 · 23 知识点
小节2.1.1 等式的性质与方程的解集8 条知识点
性质等式的性质

① 若 $a=b$，则对任意 $c$ 有 $a+c=b+c$；② 若 $a=b$ 且 $c\neq0$，则 $ac=bc$。"加上"改为"减去"、"乘以"改为"除以"（除数非零）结论仍成立。

定义定义（恒等式）

含有字母的等式，若字母取任意实数时等式都成立，则称为恒等式（等式两边恒等）。恒等式是代数变形的依据。

要点常用恒等式（乘法公式）

$a^{2}-b^{2}=(a+b)(a-b)$（平方差）；$(x\pm y)^{2}=x^{2}\pm2xy+y^{2}$（两数和/差平方）；$(x+a)(x+b)=x^{2}+(a+b)x+ab$；$(ax+b)(cx+d)=acx^{2}+(ad+bc)x+bd$；$a^{3}\pm b^{3}=(a\pm b)(a^{2}\mp ab+b^{2})$。

方法方法（十字相乘法）

分解 $x^{2}+Cx+D$ 为 $(x+a)(x+b)$，需 $ab=D$ 且 $a+b=C$；如 $x^{2}+5x+6=(x+2)(x+3)$、$3x^{2}+11x+10=(x+2)(3x+5)$。

定义定义（方程的解集）

方程所有解组成的集合。解方程须不断使用等式性质与恒等式变形。

性质定理

$ab=0\Rightarrow a=0$ 或 $b=0$（据此解因式分解型方程）。

性质分类讨论

解关于 $x$ 的方程 $ax=2$ 时须讨论——$a\neq0$ 解集为 $\left\{\frac{2}{a}\right\}$，$a=0$ 解集为 $\varnothing$。

术语中英术语

identity 恒等式 / solution set 解集 / factorization 因式分解。

小节2.1.2 一元二次方程的解集及其根与系数的关系9 条知识点
定义定义（一元二次方程）

形如 $ax^{2}+bx+c=0$（$a,b,c$ 为常数且 $a\neq0$）的方程。

要点基础解集

$x^{2}=t$：$t>0\to\{-\sqrt t,\sqrt t\}$，$t=0\to\{0\}$，$t<0\to\varnothing$；$(x-k)^{2}=t$：$t>0\to\{k-\sqrt t,k+\sqrt t\}$，$t=0\to\{k\}$，$t<0\to\varnothing$。

方法方法（配方法）

$ax^{2}+bx+c=0$ 恒可化为 $\left(x+\frac{b}{2a}\right)^{2}=\frac{b^{2}-4ac}{4a^{2}}$。

要点判别式

$\Delta=b^{2}-4ac$。$\Delta>0$：解集 $\left\{\frac{-b\pm\sqrt{b^{2}-4ac}}{2a}\right\}$；$\Delta=0$：$\left\{-\frac{b}{2a}\right\}$；$\Delta<0$：$\varnothing$。解集情况完全由系数决定。

要点求根公式

$x=\frac{-b\pm\sqrt{b^{2}-4ac}}{2a}$。

性质定理（根与系数的关系 / 韦达定理）

解集非空时，$x_{1}+x_{2}=-\frac{b}{a}$，$x_{1}x_{2}=\frac{c}{a}$。

要点常用变形

$x_{1}^{2}+x_{2}^{2}=(x_{1}+x_{2})^{2}-2x_{1}x_{2}$；$(x_{1}-x_{2})^{2}=(x_{1}+x_{2})^{2}-4x_{1}x_{2}$。

要点换元法

如 $x-2\sqrt x-1=0$，令 $\sqrt x=y\ (y\geq0)$ 化为一元二次方程。

术语中英术语

quadratic equation 一元二次方程 / discriminant 判别式 / Vieta's formulas 韦达定理（根与系数的关系）。

小节2.1.3 方程组的解集6 条知识点
定义定义（方程组的解集）

多个方程联立得方程组；各方程解集的交集称为方程组的解集。

方法解法

代入法、消元法（加减消元），需反复使用等式性质。当未知数个数 > 方程个数时，解集常为无限集，可将某些未知数视为常数表示其他未知数。

性质表示符号

$\left\{\begin{aligned}x-y=1,\\ x+y=3\end{aligned}\right.$；解集如 $\{(2,1)\}$、$A=\{(x,y,z)\mid x=z+3,\ y=2z+2,\ z\in\mathbf{R}\}$。

拓展信息技术

GeoGebra 运算区用 solve 命令可求方程（组）解集，"{}" 表示空集。

拓展拓展阅读

《九章算术》第八章"方程"（一次方程组），"方程术"用系数排阵、遍乘直除消元；另有引进负数的"正负术"和数值解一元二次方程的"开方术"。

术语中英术语

system of equations 方程组 / elimination 消元法。

节2.2 不等式4 小节 · 31 知识点
小节2.2.1 不等式及其性质8 条知识点
定义定义（不等式）

用 $\neq,>,\geqslant,\leqslant,<$ 连接数或代数式表示不等关系。$a\geqslant b\Leftrightarrow a>b$ 或 $a=b$；$a\leqslant b\Leftrightarrow a<b$ 或 $a=b$。

要点实数大小（作差法）

$a-b<0\Leftrightarrow a<b$；$a-b=0\Leftrightarrow a=b$；$a-b>0\Leftrightarrow a>b$。

性质不等式性质
  • 性质1：$a>b\Rightarrow a+c>b+c$；
  • 性质2：$a>b,\ c>0\Rightarrow ac>bc$；
  • 性质3：$a>b,\ c<0\Rightarrow ac<bc$；
  • 性质4（传递性）：$a>b,\ b>c\Rightarrow a>c$；
  • 性质5：$a>b\Leftrightarrow b<a$。
要点推论
  • 推论1（移项法则）：$a+b>c\Rightarrow a>c-b$；
  • 推论2（同向可加）：$a>b,\ c>d\Rightarrow a+c>b+d$，有限个同向不等式相加仍同向；
  • 推论3：$a>b>0,\ c>d>0\Rightarrow ac>bd$；
  • 推论4：$a>b>0\Rightarrow a^{n}>b^{n}$（$n\in\mathbf{N},n>1$）；
  • 推论5：$a>b>0\Rightarrow\sqrt a>\sqrt b$。
要点同向不等式

不等号方向相同的不等式（如 $a>b$ 与 $c>d$）。

方法证明方法

作差法（比较两式之差符号）；综合法（$p\Rightarrow q$ 从已知推结论）；分析法（要证 $p$，只需证 $q$，即 $p\Leftarrow q$）；反证法（假设结论否定，推出矛盾）。

例例

$x^{2}-x>x-2$；$a>b,\ c<d\Rightarrow a-c>b-d$；$ab>0$ 时 $\frac1a<\frac1b$；$\sqrt3+\sqrt7<2\sqrt5$。

术语中英术语

inequality 不等式 / transitivity 传递性 / synthetic method 综合法 / analytic method 分析法 / reductio ad absurdum 反证法。

小节2.2.2 不等式的解集8 条知识点
定义定义（解集）

不等式所有解组成的集合；不等式组的解集 = 各不等式解集的交集。求解须不断使用不等式性质。

要点绝对值

$|a|$ 为正数本身、负数相反数、0 为 0。含绝对值的不等式称绝对值不等式。

方法解法

当 $m>0$ 时，$|x|>m$ 解集为 $(-\infty,-m)\cup(m,+\infty)$；$|x|\leqslant m$ 解集为 $[-m,m]$；$|a-1|\leqslant2$ 解集为 $[-1,3]$。

性质几何意义

$|a|$ 是数轴上点 $a$ 到原点的距离；$|a-b|$ 是数轴上两点 $A(a)$、$B(b)$ 间的距离。

要点数轴上两点距离公式

$AB=|a-b|$。

要点数轴中点坐标公式

线段 $AB$ 中点对应数 $x=\frac{a+b}{2}$（由 $|a-x|=|x-b|$ 得 $x-a=b-x$）。

性质关系 / 转化

解含参不等式（如 $2x+a>0$、$ax>1$）时须对参数分类讨论。

术语中英术语

solution set of inequality 不等式解集 / absolute value 绝对值 / distance formula 距离公式。

小节2.2.3 一元二次不等式的解法7 条知识点
定义定义（一元二次不等式）

形如 $ax^{2}+bx+c>0$（$a\neq0$；不等号也可为 $<,\geqslant,\leqslant$）的不等式。

性质符号法则

$ab>0\iff a,b$ 同号；$ab<0\iff a,b$ 异号。据此把因式分解型不等式化为不等式组。

性质一般结论 （设 $x_{1}<x_{2}$）

$(x-x_{1})(x-x_{2})<0$ 解集为 $(x_{1},x_{2})$；$(x-x_{1})(x-x_{2})>0$ 解集为 $(-\infty,x_{1})\cup(x_{2},+\infty)$。

方法方法（配方法）

一般一元二次不等式经配方化为 $(x-h)^{2}>k$ 或 $(x-h)^{2}<k$，再由 $k$ 的符号判断解集。

例例

$x^{2}-x-2>0\to(-\infty,-1)\cup(2,+\infty)$；$x^{2}+4x+1\geqslant0\to(-\infty,-2-\sqrt3]\cup[-2+\sqrt3,+\infty)$；$2x^{2}+4x+5>0\to\mathbf{R}$。

要点分式不等式

如 $\frac{2x+1}{x-2}\geqslant1$，利用 $(x-2)^{2}>0$ 两边同乘化为一元二次不等式并加 $x\neq2$ 限制。

术语中英术语

quadratic inequality 一元二次不等式 / completing the square 配方法。

小节2.2.4 均值不等式及其应用8 条知识点
定义定义（算术平均值）

$\frac{a+b}{2}$；（几何平均值）：$\sqrt{ab}$。

性质定理（均值不等式 / 基本不等式）

$a,b>0\Rightarrow\frac{a+b}{2}\geqslant\sqrt{ab}$，当且仅当 $a=b$ 时等号成立。证明：$\frac{a+b}{2}-\sqrt{ab}=\frac{(\sqrt a-\sqrt b)^{2}}{2}\geq0$。

性质几何意义

周长一定的矩形中，正方形面积最大；半圆中半径 $OD\geq$ 弦上线段 $CD$（垂线段最短）。

性质推广（探索）

$\frac{a+b+c}{3}\geq\sqrt[3]{abc}$（三正数乃至 $n$ 正数的算术平均不小于几何平均）。

方法应用要诀

两正数积为常数时和有最小值，和为常数时积有最大值，注意等号成立条件。

要点常用不等式

$a^{2}+b^{2}\geq2ab$（$a,b\in\mathbf{R}$，当且仅当 $a=b$ 取等）；推论 $(a+b)^{2}\geq4ab$、$2(a^{2}+b^{2})\geq(a+b)^{2}$。

例例

$x>0$ 时 $x+\frac1x\geq2$（$x=1$ 取等）；$ab>0$ 时 $\frac ba+\frac ab\geq2$；矩形面积 100 时最短周长 40；周长 36 时最大面积 81；$x\in(-1,3)$ 时 $(1+x)(3-x)\leq4$（$x=1$ 最大）。

术语中英术语

arithmetic mean 算术平均值 / geometric mean 几何平均值 / mean inequality 均值不等式 / basic inequality 基本不等式。

节3.1 函数的概念与性质3 小节 · 32 知识点
小节3.1.1 函数及其表示方法12 条知识点
定义定义（函数 / "对应说"）

给定两个非空实数集 $A$ 与 $B$ 及对应关系 $f$，如果对集合 $A$ 中的每一个实数 $x$，在 $B$ 中都有唯一确定的实数 $y$ 与之对应，则称 $f$ 为定义在 $A$ 上的一个函数，记作 $y=f(x),\ x\in A$。

性质表示符号

$x$ 称自变量，$y$ 称因变量；自变量取值范围（数集 $A$）称定义域；所有函数值 $\{y\in B\mid y=f(x),\ x\in A\}$ 称值域。对应关系也可用 $g,h$ 等字母。

要点同一个函数

两个函数定义域相同、对应关系也相同则为同一函数。如 $y=\sqrt{x^{2}}$ 与 $g(x)=|x|$（定义域均为 $\mathbf{R}$）为同一函数；$f(x)=2x+1$ 与 $y=2s+1$ 也为同一函数（字母名无关紧要）。

要点省略约定

不产生歧义时可省略定义域，约定定义域为使函数有意义的所有实数组成的集合。

定义求定义域依据

分式中分母 $\neq0$；二次（偶次）根式中被开方数 $\geq0$。

方法求值域方法

用不等式性质（如 $\frac{1}{x^{2}+1}$ 值域 $(0,1]$）；或用方程法——判断 $f(x)=t$ 是否有解。

要点三种表示法

解析法（解析式）、列表法（表格，如创新指数）、图像法。函数图像 $F=\{(x,y)\mid y=f(x),\ x\in A\}$；描点作图法。

要点分段函数

定义域内对自变量的不同取值区间有不同对应方式。例：阶梯水价 $f(x)$；狄利克雷函数 $D(x)$（定义域 $\mathbf{R}$、值域 $\{0,1\}$、无直观图像）；取整函数 $y=[x]$（定义域 $\mathbf{R}$、值域 $\mathbf{Z}$，又称高斯取整函数）；常数函数（值域仅一个元素）。

方法方法（待定系数法）

借助方程（组）确定函数解析式，如二次函数过三点可设 $y=ax^{2}+bx+c$ 解方程组。

要点f(x) 与 f(x−a)

$g(x)=f(x-1)$ 与 $f(x)$ 是不同的函数；围绕已知复合式求原解析式（配凑法）。

function 函数 / domain 定义域 / range 值域 / independent/dependent variable 自变量/因变量 / analytic method 解析法 / tabular method 列表法 / graphic method 图像法 / piecewise function 分段函数 / Dirichlet function 狄利克雷函数 / floor function 取整函数 / constant function 常数函数。

小节3.1.2 函数的单调性11 条知识点
定义定义（增函数）

设 $y=f(x)$ 定义域为 $D$，$I\subseteq D$，若对任意 $x_{1},x_{2}\in I$，当 $x_{1}<x_{2}$ 时都有 $f(x_{1})<f(x_{2})$，则称 $f(x)$ 在 $I$ 上是增函数（单调递增）。

定义定义（减函数）

若 $x_{1}<x_{2}$ 时都有 $f(x_{1})>f(x_{2})$，则称 $f(x)$ 在 $I$ 上是减函数（单调递减）。

要点单调区间

$I$ 为区间时称单调递增（递减）区间。单调性是局部性质：$y=\frac1x$ 在 $(-\infty,0)$、$(0,+\infty)$ 分别递减，不能说在整个定义域内递减。

定义定义（最值 / 最值点）

对任意 $x\in D$ 都有 $f(x)\le f(x_{0})$，则 $f(x_{0})$ 为最大值、$x_{0}$ 为最大值点；$f(x)\ge f(x_{0})$ 时为最小值。有最值且知单调性时可求之。

要点直线斜率

$k=\dfrac{y_{2}-y_{1}}{x_{2}-x_{1}}=\dfrac{\Delta y}{\Delta x}$（$x_{1}\ne x_{2}$）。三点共线 $\iff$ 斜率相等或都不存在。

要点平均变化率

$\dfrac{\Delta f}{\Delta x}=\dfrac{f(x_{2})-f(x_{1})}{x_{2}-x_{1}}$（$x_{1}\ne x_{2}$）。

要点判别充要条件

$f(x)$ 在 $I$ 上增 $\iff\dfrac{\Delta y}{\Delta x}>0$ 恒成立；减 $\iff\dfrac{\Delta y}{\Delta x}<0$ 恒成立。

要点一次函数 $y=kx+b$

$k>0$ 在 $\mathbf{R}$ 递增，$k<0$ 递减；$\dfrac{\Delta y}{\Delta x}=k$，即 $\Delta y=k\Delta x$（$\Delta y$ 与 $\Delta x$ 成正比），故又称线性函数。

要点二次函数 $f(x)=ax^{2}+bx+c$

$a>0$ 时在 $\left(-\infty,-\frac{b}{2a}\right]$ 递减、$\left[-\frac{b}{2a},+\infty\right)$ 递增，最小值 $f\left(-\frac{b}{2a}\right)=\frac{4ac-b^{2}}{4a}$；$a<0$ 时相反，有最大值。

要点物理中的变化率

速度 $v=\frac{\Delta x}{\Delta t}$，加速度 $a=\frac{\Delta v}{\Delta t}$（与函数平均变化率一致）。

术语中英术语

increasing function 增函数 / decreasing function 减函数 / monotonicity 单调性 / monotonic interval 单调区间 / maximum/minimum value 最大值/最小值 / slope 斜率 / average rate of change 平均变化率 / linear function 线性（一次）函数。

小节3.1.3 函数的奇偶性9 条知识点
定义定义（偶函数）

设 $y=f(x)$ 定义域为 $D$，若对 $D$ 内任意 $x$ 都有 $-x\in D$ 且 $f(-x)=f(x)$，则为偶函数。

定义定义（奇函数）

若对 $D$ 内任意 $x$ 都有 $-x\in D$ 且 $f(-x)=-f(x)$，则为奇函数。

要点图像特征

偶函数图像关于 $y$ 轴对称；奇函数图像关于原点对称（反之亦成立）。

要点前提

定义域必须关于原点对称，否则既非奇也非偶（非奇非偶）。

性质性质

奇函数若 $0\in D$，则 $f(0)=0$；$f(x)=x^{2n}$ 为偶函数，$f(x)=x^{2n-1}$ 为奇函数（$n$ 正整数）。

性质与单调性的关系

偶函数在 $x>0$ 与 $x<0$ 时单调性相反；奇函数在两侧单调性相同。已知函数具有奇偶性，可由其一半的性质与图像推另一半。

性质轴对称推广

证图像关于直线 $x=m$ 对称，只需证 $f(m+h)=f(m-h)$；二次函数 $f(x)=ax^{2}+bx+c$ 的对称轴为 $x=-\frac{b}{2a}$。

例例

奇函数 $f(-5)=-f(5)$；偶函数 $f(-5)=f(5)$；$y=\frac{1}{x^{2}}$ 为偶函数、在 $(0,+\infty)$ 递减、在 $(-\infty,0)$ 递增、值域 $(0,+\infty)$。

术语中英术语

even function 偶函数 / odd function 奇函数 / parity 奇偶性 / axial symmetry 轴对称 / central symmetry 中心对称。

节3.2 函数与方程、不等式之间的关系4 小节 · 17 知识点
小节3.2.1 函数的零点4 条知识点
定义定义（零点）

若函数 $y=f(x)$ 在实数 $\alpha$ 处 $f(\alpha)=0$，则称 $\alpha$ 为函数的零点。

性质等价关系

$\alpha$ 是零点 $\iff$ $(\alpha,0)$ 是函数图像与 $x$ 轴的公共点 $\iff$ $f(x)=0$ 的实根。求零点即解方程 $f(x)=0$。

性质按符号划分定义域

$A=\{x\in D\mid f(x)<0\}$，$B=\{x\in D\mid f(x)=0\}$，$C=\{x\in D\mid f(x)>0\}$，则 $A,B,C$ 两两不交且 $D=A\cup B\cup C$。据此可由图像写出 $f(x)=0$、$f(x)>0$、$f(x)\le0$ 的解集。

术语中英术语

zero point 零点 / real root 实根。

小节3.2.2 二次函数的零点及其与对应方程、不等式解集之间的关系4 条知识点
要点零点与判别式 （$f(x)=ax^{2}+bx+c,\ a\ne0$）

$\Delta>0$ 时方程有两根 $x_{1},x_{2}$，即两零点，图像与 $x$ 轴两交点；$\Delta=0$ 时唯一零点，一交点；$\Delta<0$ 时无零点、无交点。

要点用作解一元二次不等式

先求零点（解对应方程），再据抛物线开口方向判断符号区间。例：$x^{2}-x-6<0\to(-2,3)$；$x^{2}-x-6\ge0\to(-\infty,-2]\cup[3,+\infty)$；$-x^{2}-2x-3\ge0\to\varnothing$（无零点、开口向下）；$x^{2}-4x+4>0\to(-\infty,2)\cup(2,+\infty)$。

要点高次用零点分区间

如 $f(x)=(x+2)(x+1)(x-1)$ 零点为 $-2,-1,1$，将定义域分四段定符号，得 $f(x)>0$ 解集 $(-2,-1)\cup(1,+\infty)$，$f(x)\le0$ 解集 $(-\infty,-2]\cup[-1,1]$。

术语中英术语

quadratic function 二次函数 / discriminant 判别式。

小节3.2.3 零点的存在性及其近似值的求法7 条知识点
性质定理（函数零点存在定理）

若 $y=f(x)$ 在区间 $[a,b]$ 上图像连续不断，且 $f(a)f(b)<0$（两端点异号），则在 $(a,b)$ 中至少有一个零点，即 $\exists x_{0}\in(a,b),\ f(x_{0})=0$。

要点连续性

多项式函数图像连续不断；反比例函数 $y=\frac1x$ 图像不连续。

方法方法（二分法）

计算区间中点函数值，缩小零点所在区间，从而求零点的近似值。

方法二分法步骤

① 检查 $|b-a|\le2\varepsilon$ 是否成立；② 计算中点 $\frac{a+b}{2}$ 的函数值（为 0 则结束）；③ 由端点与中点异号判断零点所在半区间，更新 $a$ 或 $b$，回到①。

例例

$f(x)=x^{3}-2x+2$，因 $f(-2)f(0)<0$，零点 $x_{0}\in(-2,0)$，可用二分法取 $-\frac{15}{8}$ 为近似值（误差 $<\frac18$）。

拓展拓展阅读

二分法思想广泛用于有序数据的搜索（每次与中间元素比较，最多 4 次即可在 15 个数中定位）。

术语中英术语

zero existence theorem 零点存在定理 / bisection method 二分法 / continuous function 连续函数。

节3.4 数学建模活动：决定苹果的最佳出售时间点1 小节 · 8 知识点
小节本节知识点节内直列8 条知识点
定义概念（数学建模）

对现实问题进行数学抽象，用数学语言表达问题、用数学方法构建模型以解决问题，是连接数学与现实世界的桥梁。

方法建模过程

在实际情境中从数学视角发现问题、提出问题 $\to$ 分析问题、建立模型 $\to$ 确定参数、计算求解 $\to$ 验证结果、改进模型 $\to$ 解决实际问题。常 3–5 人分工合作（数学、计算机、写作）。

要点苹果问题建模

单价 $y=f(x)$（关于上市量 $x$ 的减函数），保鲜成本 $C=g(t)$（关于时间 $t$ 的增函数），$x=h(t)$，则收益 $z=f(h(t))-g(t)$；目标是求 $z$ 最大时的 $t$。

要点合理假设与待定系数

设 $f(x)=k_{1}x+l_{1}$、$g(t)=k_{2}t+l_{2}$、$h(t)=at^{2}+bt+c$，代入得 $z=k_{1}at^{2}+(k_{1}b-k_{2})t+k_{1}c+l_{1}-l_{2}$。由数据定参数：$y=-0.5x+5$，$C=0.01t+0.1$，$x=0.002t^{2}-0.14t+9.6$，$z=-0.001(t-30)^{2}+1$。

性质结论

$t=30$ 天时单位收益最大，为 1 元；可通过收集更多数据、不预设函数形式来优化模型。

拓展论文结构

发现问题提出问题、分析问题建立模型、确定参数计算求解、验证结果改进模型；可增作者、摘要、参考文献、附录。

拓展论文示例（凯恩斯静态模型）

$Y=C+I$，$C=C_{0}+aY$；边际消费倾向 $a=\frac{\Delta C}{\Delta Y}$；收入对消费 $\frac{\Delta Y}{\Delta C}=\frac1a$、对投资 $\frac{\Delta Y}{\Delta I}=\frac{1}{1-a}$，均 $>1$（乘数效应）。

术语中英术语

mathematical modeling 数学建模 / Keynesian static model 凯恩斯静态模型 / marginal propensity to consume 边际消费倾向 / multiplier effect 乘数效应。
