节4.1 指数与指数函数2 小节 · 16 知识点
小节4.1.1 实数指数幂及其运算10 条知识点
定义概念

指数幂、根式、方根；由整数指数幂推广到有理数指数幂，再推广到实数指数幂。

定义定义（整数指数幂）

在 $a^n$ 中，$a$ 称为底数（base），$n$ 称为指数（exponent）；运算法则 $a^ma^n=a^{m+n}$，$(a^m)^n=a^{mn}$，$(ab)^m=a^mb^m$。

定义定义（$n$ 次方根）

若 $x^n=a$，则 $x$ 称为 $a$ 的 $n$ 次方根（$n$th root）；正数 $a$ 的偶数次方根有两个且互为相反数，记为 $\pm\sqrt[n]{a}$，负的方根记为 $-\sqrt[n]{a}$；任意实数的奇数次方根唯一，记为 $\sqrt[n]{a}$。

定义定义（根式）

当 $\sqrt[n]{a}$ 有意义时称为根式（radical），$n$ 为根指数，$a$ 为被开方数；性质 $(\sqrt[n]{a})^n=a$；当 $n$ 为奇数时 $\sqrt[n]{a^n}=a$，当 $n$ 为偶数时 $\sqrt[n]{a^n}=|a|$。

定义定义（分数指数幂）

$\sqrt[n]{a}$ 有意义时规定 $a^{1/n}=\sqrt[n]{a}$；一般地 $a^{m/n}=(\sqrt[n]{a})^m=\sqrt[n]{a^m}$；负分数指数幂 $a^{-s}=1/a^s$（$s$ 为正分数且 $a^s$ 有意义、$a\neq0$）。后续默认分数指数幂的指数均为既约分数。

定义定义（实数指数幂）

当 $a>0$、$t$ 为无理数时，$a^t$ 仍是一个确定的实数；因此 $a>0$ 且 $t$ 为任意实数时 $a^t$ 都有意义。

性质表示符号

$\mathbf{R}$（实数集），$\sqrt[n]{a}$（$n$ 次根式）。

术语中英术语

base 底数 / exponent 指数 / $n$th root $n$ 次方根 / radical 根式 / rational exponent 有理数指数幂 / real exponent 实数指数幂。

方法定理 / 公式 / 方法

有理数指数幂运算法则 $a^sa^t=a^{s+t}$，$(a^s)^t=a^{st}$，$(ab)^s=a^sb^s$（$s,t$ 为有理数）。例 1：若 $a>b>0$ 且 $n>1$，则 $a^{1/n}>b^{1/n}$；进而可证 $a>b>0$ 时 $a^s>b^s$（$s$ 正有理数），$a>1$ 时 $a^s>1$、$a^{-s}<1$，$a>1,s>t>0$ 时 $a^s>a^t$。

性质关系 / 转化

整数指数幂 → 分数（有理）指数幂 → 无理（实数）指数幂逐级推广；根式与分数指数幂可互化；GeoGebra 中用符号 ^ 求实数指数幂。

小节4.1.2 指数函数的性质与图像6 条知识点
定义概念

指数函数（exponential function）。

定义定义

函数 $y=a^x$，其中常数 $a>0$ 且 $a\neq1$。

性质表示符号

定义域 $\mathbf{R}$，值域 $(0,+\infty)$，定点 $(0,1)$。

术语中英术语

exponential function 指数函数。

方法定理 / 公式 / 方法（性质）

定义域 $\mathbf{R}$；值域 $(0,+\infty)$，图像恒在 $x$ 轴上方；图像过定点 $(0,1)$；当 $a>1$ 时为增函数，当 $0<a<1$ 时为减函数；非奇非偶函数。限制 $a>0$ 且 $a\neq1$ 的原因：保证函数单调、值域为正。

性质关系 / 转化

因 $(1/2)^x=2^{-x}$，故 $y=2^x$ 与 $y=(1/2)^x$ 的图像关于 $y$ 轴对称；碳 14 衰减模型 $y=(1/2)^{x/5730}$；GeoGebra 可作图并求衰减百分比（如死亡一万年含量约 $29.8\%$）。

节4.2 对数与对数函数3 小节 · 16 知识点
小节4.2.1 对数运算6 条知识点
定义概念

对数（logarithm）——在关系式 $a^b=N$（$a>0,a\neq1,N>0$）中，已知 $a,N$ 求 $b$ 的运算。

定义定义

若 $a^b=N$，则 $b$ 称为以 $a$ 为底 $N$ 的对数，记作 $b=\log_a N$；其中 $a$ 称为底数（base），$N$ 称为真数（true number）。

性质表示符号

$\log_a N$（一般对数），$\lg N=\log_{10}N$（常用对数 common logarithm），$\ln N=\log_e N$（自然对数 natural logarithm，$e=2.71828\cdots$）。

术语中英术语

logarithm 对数 / base 底数 / true number 真数 / common logarithm 常用对数 / natural logarithm 自然对数。

方法定理 / 公式 / 方法

$\log_a N=b \Leftrightarrow a^b=N$；"负数和零没有对数"，即 $N>0$ 时 $\log_a N$ 才有意义；$\log_a 1=0$（1 的对数为 0），$\log_a a=1$（底的对数为 1）；$a^{\log_a N}=N$。例：里氏震级 $M=\lg(A/A_0)$；$\mathrm{pH}=-\lg c(\mathrm{H}^+)$；素数计数 $\pi(x)\approx x/\ln x$。

性质关系 / 转化

指数式 $a^b=N$ 与对数式 $b=\log_a N$ 等价互化；常用对数与自然对数可通过换底互相转化。

小节4.2.2 对数运算法则4 条知识点
方法定理 / 公式 / 方法（积、商、幂的对数）

当 $a>0,a\neq1,M>0,N>0,\alpha\in\mathbf{R}$ 时， $$\log_a(MN)=\log_a M+\log_a N,\quad \log_a M^\alpha=\alpha\log_a M,\quad \log_a\frac{M}{N}=\log_a M-\log_a N.$$ 推广到多个正因数：$\log_a(N_1N_2\cdots N_k)=\sum\log_a N_i$；特别地 $\log_a N^k=k\log_a N$（$k$ 正整数，可推广到任意实数 $\alpha$）。

方法定理 / 公式 / 方法（换底公式）

$\log_a b=\dfrac{\log_c b}{\log_c a}$（$a>0,a\neq1,b>0,c>0,c\neq1$）。

术语中英术语

product / quotient / power rule of logarithms 积 / 商 / 幂的对数法则 / change-of-base formula 换底公式。

性质关系 / 转化

由指数运算法则 $a^\alpha a^\beta=a^{\alpha+\beta}$ 推出对数加法法则；由 $(a^\beta)^\alpha=a^{\beta\alpha}$ 推出幂的对数法则；计算器和计算机用换底公式化为常用或自然对数计算任意对数。

小节4.2.3 对数函数的性质与图像6 条知识点
定义概念

对数函数（logarithmic function）。

定义定义

函数 $y=\log_a x$，其中常数 $a>0$ 且 $a\neq1$。

性质表示符号

定义域 $(0,+\infty)$，值域 $\mathbf{R}$，定点 $(1,0)$。

术语中英术语

logarithmic function 对数函数。

方法定理 / 公式 / 方法（性质）

定义域为 $(0,+\infty)$，图像在 $y$ 轴右侧；值域为 $\mathbf{R}$；图像过定点 $(1,0)$；当 $a>1$ 时为增函数，当 $0<a<1$ 时为减函数；非奇非偶函数。因 $\log_{1/2} x=-\log_2 x$，故 $y=\log_{1/2}x$ 与 $y=\log_2 x$ 的图像关于 $x$ 轴对称。

性质关系 / 转化

对数函数是指数函数 $y=a^x$ 的反函数；在表达式 $y=(1/2)^{x/5730}$ 中可改写为 $x=\log_{(1/2)^{1/5730}}y$，从而把 $x$ 看成 $y$ 的函数。

节4.3 指数函数与对数函数的关系1 小节 · 6 知识点
小节本节知识点节内直列6 条知识点
定义概念

反函数（inverse function）。

定义定义

若对函数 $y=f(x)$ 值域中任一 $y$ 只有唯一的 $x$ 与之对应，则 $x$ 是 $y$ 的函数，称为 $y=f(x)$ 的反函数；记 $y=f^{-1}(x)$。

性质表示符号

$y=a^x \Leftrightarrow x=\log_a y$；反函数记作 $f^{-1}(x)$。

术语中英术语

inverse function 反函数 / reflection about $y=x$ 关于直线 $y=x$ 对称。

方法定理 / 公式 / 方法

指数函数 $y=a^x$（$a>0,a\neq1$）与对数函数 $y=\log_a x$ 互为反函数；一个函数的定义域是另一个的值域，单调性相同；图像关于直线 $y=x$ 对称。若 $y=f(x)$ 单调，则其反函数一定存在，且单调性相同。$y=f(x)$ 与 $y=f^{-1}(x)$ 的定义域、值域互换，图像关于 $y=x$ 对称。

性质关系 / 转化

由 $y=2^x$ 对调 $x,y$ 得 $x=2^y$ 即 $y=\log_2 x$；判断反函数是否存在看"值到原像是否唯一"。

节4.4 幂函数1 小节 · 6 知识点
小节本节知识点节内直列6 条知识点
定义概念

幂函数（power function）。

定义定义

函数 $y=x^\alpha$，其中 $\alpha$ 为常数（如 $y=x$、$y=x^2$、$y=1/x$ 都是幂函数）。

性质表示符号

$y=x^\alpha$。

术语中英术语

power function 幂函数 / power 幂。

方法定理 / 公式 / 方法（共同特征）

所有幂函数都在 $(0,+\infty)$ 上有定义，图像过定点 $(1,1)$；若 $\alpha>0$，则过原点且在 $[0,+\infty)$ 上为增函数；若 $\alpha<0$，则在 $(0,+\infty)$ 上为减函数，且当 $x\to0^+$ 时逼近 $y$ 轴、当 $x\to+\infty$ 时逼近 $x$ 轴。

性质关系 / 转化

幂函数与指数、对数函数同源于 $N=a^b$，区别在于自变量位置不同（底数为自变量）；比较大小常用幂函数的单调性。

节4.5 增长速度的比较1 小节 · 5 知识点
小节本节知识点节内直列5 条知识点
定义概念

平均变化率（average rate of change）——刻画函数值变化的快慢。

定义定义

函数 $y=f(x)$ 在区间 $[x_1,x_2]$ 上的平均变化率为 $\dfrac{\Delta f}{\Delta x}=\dfrac{f(x_2)-f(x_1)}{x_2-x_1}$（即自变量每增 1 单位，函数值平均增减的量）。

术语中英术语

average rate of change 平均变化率 / exponential growth 指数增长（爆炸式增长）/ linear growth 线性增长（直线增长）。

方法定理 / 公式 / 方法

$f(x)=2^x$、$g(x)=x$、$h(x)=\log_2 x$ 在区间 $[a,a+1]$（$a>1$）上平均变化率分别为 $2^a$、$1$、$\log_2(1+1/a)$，故 $2^a>1>\log_2(1+1/a)$；当 $a>1$ 时 $f(x)=a^x$ 的增长速度最终远快于一次函数与对数函数。

性质关系 / 转化

指数增长（指数级增长）与线性增长对比；房价指数增长 vs 攒钱线性增长（永远买不起的实例）；GeoGebra 作图直观理解。

节4.6 函数的应用（二）1 小节 · 4 知识点
小节本节知识点节内直列4 条知识点
定义概念

用指数、对数、幂函数模型解决实际问题。

方法定理 / 公式 / 方法
  • 复利（compound interest）：本金 $a$、每期利率 $r$、存 $x$ 期后本息和 $f(x)=a(1+r)^x$（$x\in\mathbf{N}^*$）；"70 原则"——倍增期约 $\dfrac{70}{100r}$。
  • 声音强度等级（分贝 decibel, dB）：$f(x)=10\lg\dfrac{x}{1\times10^{-12}}$，其中 $x$ 为声音强度；如 90 dB 与 60 dB 强度之比为 $10^3=1000$ 倍。
  • 平均经济增长率、衰减模型、二氧化硫减排模型等。
术语中英术语

compound interest 复利 / decibel (dB) 分贝 / doubling time 倍增期。

性质关系 / 转化

把实际增长/衰减归为指数或幂函数关系，通过取对数、解方程求参数。

节4.7 数学建模活动：生长规律的描述1 小节 · 5 知识点
小节本节知识点节内直列5 条知识点
定义概念

数学建模（mathematical modeling）的一般过程。

方法定义（建模步骤）

① 发现问题、提出问题；② 分析问题、建立模型；③ 确定参数、计算求解；④ 验证结果、改进模型。

术语中英术语

mathematical modeling 数学建模 / logistic model 逻辑斯谛模型 / exponential model 指数模型。

方法定理 / 公式 / 方法（常用模型）
  • 幂型（先快后慢）：$g(x)=a\sqrt{x}+b$；
  • 指数型（先慢后快）：$h(x)=ae^{bx}$；
  • 逻辑斯谛（logistic model，先慢后快再变慢）：$f(x)=\dfrac{k}{1+ce^{-rx}}$。
性质关系 / 转化

用已知数据确定参数（代入两对数据列方程组）；用其余数据检验误差；指数函数不能描述"最终变慢"的真实生长（玉米株高实例）。

章第五章 统计与概率4 节 · 11 小节 · 57 知识点
节5.1 统计4 小节 · 20 知识点
小节5.1.1 数据的收集5 条知识点
定义概念

总体（population）、个体、样本（sample）、样本容量；普查与抽样调查。

定义定义

考察对象的全体为总体，每个对象为个体，抽取的部分对象组成样本，样本包含个体数为样本容量。对全体考察为普查（全面调查 census），只抽样本考察为抽样调查。

术语中英术语

population 总体 / individual 个体 / sample 样本 / sample size 样本容量 / census 普查 / simple random sampling 简单随机抽样 / stratified sampling 分层抽样。

方法定理 / 公式 / 方法
  • 简单随机抽样（simple random sampling，纯随机抽样）：总体中每个个体等机会被抽到；方法含抽签法、随机数表法。
  • 分层抽样（stratified sampling）：当总体由有明显差别的几部分组成时，按各层在总体中所占比例抽样，样本更具代表性。
性质关系 / 转化

普查能准确掌握总体但成本高/有破坏性或耗时，故常用抽样；用 Excel RANDBETWEEN 或 GeoGebra RandomBetween 进行抽样。

小节5.1.2 数据的数字特征6 条知识点
定义概念

用少量数值刻画一组数据的特征。

定义定义
  • 最值（max/min）：最大值与最小值。
  • 平均数（mean）：$\bar{x}=\dfrac{1}{n}\sum\limits_{i=1}^{n}x_i$（求和号 $\sum$ 读"西格玛"）。
  • 中位数（median）：奇数个取中间数，偶数个取中间两数平均。
  • 百分位数（percentile）：至少有 $p\%$ 的数据不大于该值、且至少 $(100-p)\%$ 的数据不小于该值；$25\%$ 分位数为第一四分位数，$75\%$ 为第三四分位数；中位数即 $50\%$ 分位数。
  • 众数（mode）：出现次数最多的数据。
  • 极差（range）：最大值 $-$ 最小值。
  • 方差（variance）：$s^2=\dfrac{1}{n}\sum\limits_{i=1}^{n}(x_i-\bar{x})^2$；标准差（standard deviation）为方差的算术平方根。
性质表示符号

$\bar{x}$、$\max$、$\min$、$s^2$、$\sum$。

术语中英术语

mean 平均数 / median 中位数 / percentile 百分位数 / mode 众数 / range 极差 / variance 方差 / standard deviation 标准差。

方法定理 / 公式 / 方法

$\sum$ 性质：$\sum(x_i+y_i)=\sum x_i+\sum y_i$，$\sum(kx_i)=k\sum x_i$，$\sum t=nt$；$ax_i+b$ 的平均数为 $a\bar{x}+b$、方差为 $a^2s^2$；去掉最高/最低分后求平均可减弱极端值影响。

性质关系 / 转化

平均数的线性变换、方差的伸缩规律；用数字特征对比两组数据。

小节5.1.3 数据的直观表示4 条知识点
定义概念

用统计图表形象化呈现数据。

方法定义 / 方法
  • 柱形图（bar chart，条形图）：比较各类别数量/比例，各矩形等宽。
  • 折线图（line chart）：表现随时间（或有序变量）的变化趋势。
  • 扇形图（pie chart，饼图）：表现各部分占全体的比例，圆心角与数据大小成正比。
  • 茎叶图（stem-and-leaf plot）：茎竖直、叶水平，便于看出最值、中位数、分布。
  • 频数分布直方图 / 频率分布直方图（histogram）：先求极差、分组定区间、统计频数/频率；频率直方图的纵坐标为 $\frac{\text{频率}}{\text{组距}}$，每个矩形面积等于该组频率，所有矩形面积之和为 1；连接各矩形上边中点得折线图。
术语中英术语

bar chart 柱形图 / line chart 折线图 / pie chart 扇形图 / stem-and-leaf plot 茎叶图 / histogram 直方图 / frequency 频数 / relative frequency 频率。

性质关系 / 转化

原始数据经"压缩"（分组）后作图，可显示分布态势但丢失个体值；直方图可估出平均数、中位数、百分位数、方差（与真实值有差异）。

小节5.1.4 用样本估计总体5 条知识点
定义概念

用样本特征推断总体特征（允许一定误差）。

定义定义

样本平均数（样本均值 sample mean）、样本方差估计总体对应值；大数定律保证样本量越大误差很小的可能性越大。

术语中英术语

sample mean 样本均值 / sample variance 样本方差 / big data 大数据。

方法定理 / 公式 / 方法
  • 分层抽样合并估计：设两层有 $m$ 个数（均值 $\bar{x}$、方差 $s^2$）和 $n$ 个数（均值 $\bar{y}$、方差 $t^2$），则总体均值估计 $\bar{a}=\dfrac{m\bar{x}+n\bar{y}}{m+n}$，总体方差估计 $b^2=\dfrac{1}{m+n}\left[(ms^2+nt^2)+\dfrac{mn}{m+n}(\bar{x}-\bar{y})^2\right]$。
  • 用样本的频率分布估计总体分布；频率分布直方图所有矩形面积之和为 1。
  • 大数据（big data）：文本、图像、音视频等都可"数据化"，是重要国家战略资源。
性质关系 / 转化

样本数字特征 → 总体数字特征；样本分布 → 总体分布；抽样方案不合理会导致估计失败（如 1936 年美国总统选举预测失误）。

节5.2 数学探究活动：由编号样本估计总数及其模拟1 小节 · 4 知识点
小节本节知识点节内直列4 条知识点
定义概念

由连续编号的样本估计总数 $n$。

方法定理 / 公式 / 方法
  • 最大值估计：$n\approx x_m$（$x_m$ 为样本中最大编号）。
  • 平均值估计：由 $\dfrac{1+2+\cdots+n}{n}=\dfrac{n+1}{2}\approx\bar{x}$，得 $n\approx 2\bar{x}-1$（取不小于它的最小整数）；可能出现 $n<x_m$ 时以 $x_m$ 为准。
术语中英术语

capture-recapture / mark-recapture 标记重捕（估计总数）/ simulation 模拟。

性质关系 / 转化

可借助 Excel RANDBETWEEN 模拟验证估计准确度（二战中统计学家用编号样本估计德军坦克数远优于情报估计）。

节5.3 概率5 小节 · 29 知识点
小节5.3.1 样本空间与事件6 条知识点
定义概念

随机现象（random phenomenon）vs 必然现象（确定性现象）；随机试验（random experiment）、样本点（sample point）、样本空间（sample space $\Omega$）。

定义定义

在相同条件下对随机现象的观察或实验称随机试验；每种可能出现的结果称样本点，所有样本点组成的集合称样本空间（记为 $\Omega$）；随机事件 $A$ 是 $\Omega$ 的非空真子集；$\Omega$ 为必然事件，$\varnothing$ 为不可能事件；只含一个样本点的事件称基本事件（elementary event）。

性质表示符号

$\Omega$（样本空间），$\varnothing$（空集），$P(A)$（事件 $A$ 的概率）。

术语中英术语

random phenomenon 随机现象 / random experiment 随机试验 / sample point 样本点 / sample space 样本空间 / event 事件 / elementary event 基本事件 / probability 概率。

方法定理 / 公式 / 方法

规定 $P(\varnothing)=0$，$P(\Omega)=1$；对任意事件 $A$ 有 $0\le P(A)\le 1$。

性质关系 / 转化

事件既可用集合表示，也可用自然语言描述（如掷骰子"奇数点"）；必然事件 $= \Omega$、不可能事件 $=\varnothing$。

小节5.3.2 事件之间的关系与运算5 条知识点
定义概念

基于集合对应关系描述事件关系。

方法定义 / 方法
  • 包含：$A$ 发生必致 $B$ 发生记作 $A\subseteq B$（或 $B\supseteq A$），则 $P(A)\le P(B)$；$A$ 发生是 $B$ 发生的充分条件。
  • 相等：$A=B\Leftrightarrow A\subseteq B$ 且 $B\subseteq A$；此时 $P(A)=P(B)$。
  • 和（并）：$A+B$（或 $A\cup B$），当且仅当 $A,B$ 至少一发生；$A\subseteq(A+B)$，$P(A)\le P(A+B)$。
  • 积（交）：$AB$（或 $A\cap B$），当且仅当 $A,B$ 都发生。
  • 互斥：$AB=\varnothing$（$A,B$ 不能同时发生）；互斥事件概率加法公式 $P(A+B)=P(A)+P(B)$；推广到两两互斥的多个事件。
  • 对立：$\bar{A}$ 为 $A$ 在 $\Omega$ 中的补集（complementary event），$P(A)+P(\bar{A})=1$；对立必互斥，反之不然。
  • 混合运算优先级：求积高于求和，如 $A\bar{B}+\bar{A}B$ 表示 $A,B$ 恰有一个发生。
性质表示符号

$\subseteq$、$\cup$（+）、$\cap$、$AB$、$\bar{A}$、$\varnothing$。

术语中英术语

inclusion 包含 / union 并 / intersection 交 / mutually exclusive 互斥 / complementary event 对立事件。

性质关系 / 转化

若 $A,B$ 互斥则 $P(A+B)=P(A)+P(B)$；对立事件是互斥的充分不必要条件。

小节5.3.3 古典概型6 条知识点
定义概念

古典概率模型（classical probability model）——具有有限性（样本点有限）与等可能性（各基本事件等可能）的随机试验。

定义定义

若样本空间含 $n$ 个样本点，事件 $C$ 含 $m$ 个样本点，则 $P(C)=\dfrac{m}{n}$。

性质表示符号

$P(C)=\dfrac{m}{n}$。

术语中英术语

classical probability model 古典概型 / sample point 样本点 / finite 有限性 / equally likely 等可能性。

方法定理 / 公式 / 方法

由 $P(\Omega)=1$ 与互斥加法得每个基本事件概率为 $1/n$；从而 $P(\bar{A})=1-P(A)$，$P(A+B)=P(A)+P(B)$（$A,B$ 互斥）。注意必须选取使基本事件等可能的样本空间（如例 6 基因样本空间不能用 $\{BB,Bb,bb\}$，因不等可能）。

性质关系 / 转化

抛硬币、掷骰子等可归为古典概型；并非所有试验都能归为古典概型（如抛瓶盖、种子发芽）。

小节5.3.4 频率与概率6 条知识点
定义概念

用频率估计概率（当无法用古典概型时）。

定义定义

在 $n$ 次重复试验中事件 $A$ 发生 $m$ 次，则频率为 $m/n$，当 $n$ 很大时可把 $m/n$ 作为 $P(A)$ 的估计值。

性质表示符号

频率 $\dfrac{m}{n}$。

术语中英术语

frequency 频率 / law of large numbers 大数定律 / estimate 估计。

方法定理 / 公式 / 方法

大数定律保证试验次数越多，频率越接近概率；用频率估计概率时仍有 $0\le P(A)\le1$，对立事件和为 1、互斥加法公式仍成立。用 Excel RANDBETWEEN 可模拟抛硬币、掷骰子以验证。

性质关系 / 转化

频率是概率的近似值（如抛均匀硬币正面频率≈$1/2$）；不同样本估计值可有差异，属正常现象。

小节5.3.5 随机事件的独立性6 条知识点
定义概念

相互独立（independent）的事件。

定义定义

当 $P(AB)=P(A)P(B)$ 时，称事件 $A$ 与 $B$ 相互独立（简称独立）；直观上 $A$ 是否发生不影响 $B$ 的概率，反之亦然。

性质表示符号

$P(AB)=P(A)P(B)$。

术语中英术语

independent events 相互独立 / mutually independent 相互独立（多事件）。

方法定理 / 公式 / 方法

若 $A,B$ 独立，则 $\bar{A}$ 与 $B$、$A$ 与 $\bar{B}$、$\bar{A}$ 与 $\bar{B}$ 也独立；可推广到有限个（任意有限个同时发生的概率等于各自概率之积）。实际中常依背景判断是否相互影响。

性质关系 / 转化

多个独立事件至少发生一次的概率可用对立事件求（如三题都猜错的对立为至少猜对一题）。

节5.4 统计与概率的应用1 小节 · 4 知识点
小节本节知识点节内直列4 条知识点
定义概念

综合运用统计（分位数、抽样）与概率（频率估计、独立性、古典概型）解决实际问题。

方法定理 / 公式 / 方法
  • 阶梯电价临界点：用样本的分位数（如 $75\%$ 分位数、 $95\%$ 分位数）划分阶梯。
  • 标记重捕估计总数：盒中原有 $x$ 个球，放入 $m$ 个标记球，抽样 $n$ 个中有 $k$ 个标记，则 $\dfrac{m}{x+m}\approx\dfrac{k}{n}\Rightarrow x\approx m\!\left(\dfrac{n}{k}-1\right)$。
  • 敏感问题随机化应答：抛硬币决定答"问题一/问题二"，保护隐私并反推真实比例。
  • 沃伯格游戏（三张卡片：两面绿、两面蓝、一绿一蓝，朝下与朝上同色则甲赢）：乙赢概率仅 $1/3$，游戏不公平。
  • 合格率可信度：若声称合格率 $95\%$，抽 3 件都不合格的概率仅 $0.0125\%$，极小故可疑。
  • 遗传概率（卷舌且单眼皮）：不同性状基因互不干扰则独立，概率相乘。
术语中英术语

capture-recapture 标记重捕法 / randomized response 随机化应答 / fairness 公平性。

性质关系 / 转化

把现实问题抽象为古典概型、频率估计或独立性模型后计算。

节6.1 平面向量及其线性运算5 小节 · 28 知识点
小节6.1.1 向量的概念4 条知识点
定义概念

向量（vector，矢量）既有大小又有方向；只有大小的量称标量（scalar）。

性质定义 / 表示符号
  • 用有向线段表示；始点 $A$、终点 $B$ 的向量记为 $\overrightarrow{AB}$，模（长度）为 $|\overrightarrow{AB}|$；印刷用加粗斜体 $a$，手写用 $\vec{a}$，模为 $|a|$。
  • 零向量（zero vector）$\mathbf{0}$：$|\mathbf{0}|=0$，方向不确定；模为 1 的向量称单位向量（unit vector）$e$，即 $|e|=1$。
  • 相等向量（equal vectors）：$a=b$ 表示大小相等、方向相同。
  • 平行（共线）：两非零向量方向相同或相反称平行（也称共线）；规定零向量与任意向量平行。
术语中英术语

vector 向量（矢量）/ scalar 标量 / magnitude / modulus 模 / zero vector 零向量 / unit vector 单位向量 / equal vectors 相等向量 / parallel / collinear 平行（共线）。

性质关系 / 转化

模相等、方向相同 → 相等；零向量方向与任意向量都"平行"。

小节6.1.2 向量的加法6 条知识点
定义概念

向量加法的三角形法则（triangle law）与平行四边形法则（parallelogram law）。

方法定义 / 方法
  • 三角形法则：平面内任取 $A$，作 $\overrightarrow{AB}=a$、$\overrightarrow{BC}=b$，则 $\overrightarrow{AC}=a+b$（即 $\overrightarrow{AB}+\overrightarrow{BC}=\overrightarrow{AC}$）。
  • 平行四边形法则：当 $a,b$ 不共线时，以 $AB,AC$ 为邻边作平行四边形 $ABDC$，则 $\overrightarrow{AD}=a+b$。
  • 多个向量相加：依次首尾相接，首点为始、末点为终的向量即和；满足交换律与结合律。
性质表示符号

$\overrightarrow{AB}+\overrightarrow{BC}=\overrightarrow{AC}$；$a+b=b+a$。

方法定理 / 公式 / 方法

$| |a|-|b| |\le |a+b|\le |a|+|b|$；$a+\mathbf{0}=\mathbf{0}+a=a$。

术语中英术语

triangle law 三角形法则 / parallelogram law 平行四边形法则 / commutative law 交换律 / associative law 结合律。

性质关系 / 转化

交换律 $a+b=b+a$、结合律保证有限个向量相加结果与顺序无关。

小节6.1.3 向量的减法6 条知识点
定义概念

向量减法（加法的逆运算）。

定义定义

若 $b+x=a$ 则 $x=a-b$；平面内任取 $O$，作 $\overrightarrow{OA}=a,\overrightarrow{OB}=b$，则 $\overrightarrow{OA}-\overrightarrow{OB}=\overrightarrow{BA}$。

性质表示符号

$\overrightarrow{OA}-\overrightarrow{OB}=\overrightarrow{BA}$；$a-b=a+(-b)$。

方法定理 / 公式 / 方法

相反向量（opposite vector）$-a$ 与 $a$ 方向相反、大小相等，且 $a+(-a)=\mathbf{0}$；$| |a|-|b| |\le |a-b|\le |a|+|b|$。

术语中英术语

opposite vector 相反向量 / difference of vectors 向量差。

性质关系 / 转化

减法化为加法 $a-b=a+(-b)$；平行四边形中 $\overrightarrow{AC}=a+b$、$\overrightarrow{DB}=a-b$（$a=\overrightarrow{AB},b=\overrightarrow{AD}$）。

小节6.1.4 数乘向量6 条知识点
定义概念

数乘向量（scalar multiplication）。

定义定义

实数 $\lambda$ 与向量 $a$ 的乘积 $\lambda a$ 仍是一个向量；当 $\lambda\neq0$ 且 $a\neq0$ 时 $|\lambda a|=|\lambda||a|$，$\lambda>0$ 与 $a$ 同向、$\lambda<0$ 与 $a$ 反向；当 $\lambda=0$ 或 $a=\mathbf{0}$ 时 $\lambda a=\mathbf{0}$。特别地 $-a=(-1)a$。

性质表示符号

$\lambda a$；$|\lambda a|=|\lambda||a|$。

方法定理 / 公式 / 方法

$\lambda(\mu a)=(\lambda\mu)a$；若存在 $\lambda$ 使 $b=\lambda a$ 则 $b\parallel a$；若 $\overrightarrow{AB}=\lambda\overrightarrow{AC}$ 则 $A,B,C$ 三点共线。

术语中英术语

scalar multiplication 数乘向量 / collinear 共线 / scalar 实数（标量）。

性质关系 / 转化

数乘把向量沿方向放大/缩小；三点共线可用向量数乘判定。

小节6.1.5 向量的线性运算6 条知识点
定义概念

向量加法、减法、数乘及其混合运算统称向量的线性运算（linear operations of vectors）。

方法定义 / 方法

运算优先级——先数乘，再加减（从左往右，括号优先）；去括号规则如 $-(a-2b)=-a+2b$。

性质表示符号

$\lambda a+\mu a=(\lambda+\mu)a$；$\lambda(a+b)=\lambda a+\lambda b$（分配律）。

方法定理 / 公式 / 方法
  • 中点公式（对任意点 $O$）：$\overrightarrow{OM}=\dfrac{1}{2}(\overrightarrow{OA}+\overrightarrow{OB})$ 是 $M$ 为 $AB$ 中点的充要条件。
  • 证明三点共线：构造 $\overrightarrow{AB}=\lambda\overrightarrow{AC}$。
术语中英术语

linear operations of vectors 向量的线性运算 / distributive law 分配律 / midpoint 中点。

性质关系 / 转化

线性运算可类比多项式运算拆括号、合并。

节6.2 向量基本定理与向量的坐标3 小节 · 17 知识点
小节6.2.1 向量基本定理5 条知识点
定义概念

共线向量基本定理与平面向量基本定理。

性质定义 / 定理
  • 共线向量基本定理：若 $a\neq\mathbf{0}$ 且 $b\parallel a$，则存在唯一实数 $\lambda$ 使 $b=\lambda a$（也说 $b$ 能用 $a$ 表示）；进而 $A,B,C$ 三点共线的充要条件是存在 $\lambda$ 使 $\overrightarrow{AB}=\lambda\overrightarrow{AC}$。
  • 平面向量基本定理：若平面内两向量 $a,b$ 不共线，则对平面内任意向量 $c$，存在唯一实数对 $(x,y)$ 使 $c=xa+yb$。
性质表示符号

$c=xa+yb$；基底记为 $\{a,b\}$；在基底下的表达式称分解式。

术语中英术语

collinear vectors 共线向量 / basis (of vectors) 基底 / linear combination 线性组合 / decomposition 分解式。

性质关系 / 转化

平面向量基本定理把"向量表示"推广到全平面；直线上点在直线上的充要条件是 $\overrightarrow{OP}=(1-t)\overrightarrow{OA}+t\overrightarrow{OB}$。

小节6.2.2 直线上向量的坐标及其运算6 条知识点
定义概念

直线上向量（始点、终点都在该直线上）的坐标。

定义定义

给定直线 $l$ 上单位向量 $\boldsymbol{e}$，则 $l$ 上任意向量 $a=x\boldsymbol{e}$，$x$ 称 $a$ 的坐标；$|a|=|x|$，由 $x$ 的符号定方向。等价于建立数轴后把 $a$ 的始点平移到原点，终点对应的数即坐标。

性质表示符号

$a=x\boldsymbol{e}$；$A(x)$ 表示点 $A$ 坐标为 $x$。

方法定理 / 公式 / 方法
  • 运算：$a+b$ 坐标为 $x_1+x_2$；$ua+vb$ 坐标为 $ux_1+vx_2$。
  • 两点距离：$AB=|x_2-x_1|$。
  • 中点坐标：$x=\dfrac{x_1+x_2}{2}$。
术语中英术语

coordinate 坐标 / number axis 数轴 / distance 距离 / midpoint 中点。

性质关系 / 转化

直线上向量完全由坐标确定；坐标法统一处理距离与中点。

小节6.2.3 平面向量的坐标及其运算6 条知识点
定义概念

平面向量坐标与正交基底。

定义定义
  • 两非零向量所在直线互相垂直称垂直（$a\perp b$）；零向量与任意向量垂直。基底 $\{e_1,e_2\}$ 中 $e_1\perp e_2$ 且均为单位向量称正交基底（orthogonal basis），其下分解称正交分解。
  • 若 $a=xe_1+ye_2$，则 $(x,y)$ 为 $a$ 的坐标，记作 $a=(x,y)$；建立平面直角坐标系后，$A(x,y)$ 对应 $\overrightarrow{OA}=(x,y)$。
性质表示符号

$a=(x,y)$；$|a|=\sqrt{x^2+y^2}$。

方法定理 / 公式 / 方法
  • 运算：$a+b=(x_1+x_2,\ y_1+y_2)$；$ua\pm vb=(ux_1\pm vx_2,\ uy_1\pm vy_2)$。
  • 两点距离：$AB=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}$。
  • 中点坐标：$\left(\dfrac{x_1+x_2}{2},\dfrac{y_1+y_2}{2}\right)$。
  • 向量平行的坐标表示：$a\parallel b\ \Leftrightarrow\ x_2y_1=x_1y_2$。
  • 推广：$n$ 维向量 $(a_1,\dots,a_n)$ 是平面、空间向量的推广。
术语中英术语

orthogonal basis 正交基底 / coordinate 坐标 / parallel (coordinate form) 平行的坐标表示 / $n$-dimensional vector $n$ 维向量。

性质关系 / 转化

向量坐标与几何位置一一对应；向量平行条件由共线向量基本定理推出。

节6.3 平面向量线性运算的应用1 小节 · 5 知识点
小节本节知识点节内直列5 条知识点
定义概念

用向量处理平面几何与物理问题。

方法定理 / 公式 / 方法（平面几何）
  • 三角形中位线定理（triangle midline theorem）：中位线 $MN\parallel BC$ 且 $MN=\dfrac{1}{2}BC$（由 $\overrightarrow{MN}=\dfrac{1}{2}\overrightarrow{BC}$ 推出）。
  • 平行四边形判定：由 $\overrightarrow{AE}=\overrightarrow{FC}$ 得 $AE\parallel FC$ 且相等。
  • 重心（centroid）性质：三条中线交于重心 $O$，且 $AO:OF=CO:OE=2:1$。
方法定理 / 公式 / 方法（物理）
  • 力、位移、速度、加速度均为向量；质点平衡时合力为零，即 $\boldsymbol{F}_1+\boldsymbol{F}_2+\cdots+\boldsymbol{F}_n=\mathbf{0}$；两力平衡则互为相反向量。
  • 用平行四边形法则分解力（例：两绳拉重物平衡，每绳拉力 $25\sqrt{2}\,\mathrm{N}$；斜面上物体平衡，由坐标法求摩擦力 $F_1$、弹力 $F_2$）。
术语中英术语

triangle midline theorem 三角形中位线定理 / parallelogram 平行四边形 / centroid 重心 / equilibrium 平衡 / force 力 / resultant 合力。

性质关系 / 转化

将几何中的平行、相等、相似、共线关系转化为向量线性运算或坐标运算。
