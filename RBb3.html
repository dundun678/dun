节7.1 任意角的概念与弧度制2 小节 · 12 知识点
小节7.1.1 角的推广6 条知识点
定义概念

角推广为任意角，由一条射线绕其端点旋转到另一条射线所形成（也称转角）；含正角、负角、零角。

定义定义

按逆时针方向旋转而成的角为正角；按顺时针方向旋转而成的角为负角；射线没有旋转时称零角。角的顶点与原点重合、始边落在 $x$ 轴正半轴上时，终边在第几象限就称这个角为第几象限角；终边在坐标轴上时不属于任何象限（称轴线角）。

性质表示符号

任意角 $\alpha$；终边相同的角的集合 $S = \{\beta \mid \beta = \alpha + k\cdot 360^{\circ},\, k\in\mathbf{Z}\}$（角度制）或 $S = \{\beta \mid \beta = \alpha + 2k\pi,\, k\in\mathbf{Z}\}$（弧度制）。

术语中英术语

angle 角 / initial side 始边 / terminal side 终边 / positive angle 正角 / negative angle 负角 / zero angle 零角 / quadrant angle 象限角。

方法定理·公式·方法

任意两个终边相同的角，其差必为 $360^{\circ}$（或 $2\pi$）的整数倍；象限角的判定；常见轴线角集合，如终边在 $x$ 轴上：$\{\alpha\mid \alpha = k\cdot 180^{\circ},\, k\in\mathbf{Z}\}$，终边在 $y$ 轴上：$\{\alpha\mid \alpha = 90^{\circ}+k\cdot 180^{\circ},\, k\in\mathbf{Z}\}$。

性质关系·转化

角的加减运算可由"转角"叠加给出几何意义；终边相同 $\Leftrightarrow$ 两角之差为 $360^{\circ}$ 的整数倍；某角所在象限可用来推断其一半所在象限。

小节7.1.2 弧度制及其与角度制的换算6 条知识点
定义概念

用圆弧长度与半径的比值来度量圆心角，称为弧度制（与角度制并列的另一种度量制度）。

定义定义

长度等于半径长的圆弧所对的圆心角为 1 弧度，记作 $1\,\mathrm{rad}$；以弧度为单位度量角的制度称弧度制。

性质表示符号

圆心角的弧度数 $\alpha = \dfrac{l}{r}$（$l$ 为弧长，$r$ 为半径）；弧长 $l = \alpha r$；角度制 $1^{\circ}=60'$，$1'=60''$。

术语中英术语

radian 弧度 / degree 角度 / arc length 弧长。

方法定理·公式·方法

换算关系 $360^{\circ}=2\pi\,\mathrm{rad}$，$180^{\circ}=\pi\,\mathrm{rad}$，一般 $\dfrac{n}{180}=\dfrac{\alpha}{\pi}$（$n$ 为角度数，$\alpha$ 为弧度数）；扇形面积公式 $S=\dfrac{1}{2}\alpha r^{2}=\dfrac{1}{2}lr$。

性质关系·转化

弧度制与角度制互化；弧度制下"rad"可略写（如 $\alpha=2$ 表示 $2\,\mathrm{rad}$）；引入弧度制使三角函数的定义与微积分表达更自然。

节7.2 任意角的三角函数4 小节 · 23 知识点
小节7.2.1 三角函数的定义6 条知识点
定义概念

任意角的正弦、余弦、正切统一由角 $\alpha$ 终边上点的坐标定义。

定义定义

设 $P(x,y)$ 为角 $\alpha$ 终边上异于原点的一点，$r=\sqrt{x^{2}+y^{2}}$，则 $$\sin\alpha=\frac{y}{r},\qquad \cos\alpha=\frac{x}{r},\qquad \tan\alpha=\frac{y}{x}\;(x\neq 0).$$ 当 $\alpha$ 的终边在 $y$ 轴上时 $\tan\alpha$ 无意义。正弦、余弦、正切统称 $\alpha$ 的三角函数。

性质表示符号

$\sin\alpha,\;\cos\alpha,\;\tan\alpha$。

术语中英术语

sine 正弦 / cosine 余弦 / tangent 正切 / trigonometric function 三角函数。

方法定理·公式·方法

各象限三角函数值的符号规律——$\sin\alpha$ 在第一、二象限为正，第三、四象限为负；$\cos\alpha$ 在第一、四象限为正，第二、三象限为负；$\tan\alpha$ 在第一、三象限为正，第二、四象限为负。

性质关系·转化

三角函数值只与角 $\alpha$ 终边的位置有关，与点 $P$ 在终边上的选取无关。

小节7.2.2 单位圆与三角函数线6 条知识点
定义概念

利用单位圆把三角函数直观表示为有向线段（三角函数线）。

定义定义

坐标满足 $x^{2}+y^{2}=1$ 的点集为单位圆；角 $\alpha$ 的终边与单位圆交点为 $(\cos\alpha,\sin\alpha)$。由交点向 $x$ 轴作垂线，得余弦线 $\overrightarrow{OM}$ 与正弦线 $\overrightarrow{MP}$；角 $\alpha$ 的终边（或其反向延长线）与直线 $x=1$ 的交点 $T$ 给出正切线 $\overrightarrow{AT}$。

性质表示符号

单位圆；$|\cos\beta|>|\cos\alpha|$ 等可由三角函数线直接比较。

术语中英术语

unit circle 单位圆 / trigonometric line 三角函数线。

方法定理·公式·方法

三角函数线是三角函数值的几何直观，正弦线、余弦线、正切线统称三角函数线，可用来比较大小、判断符号及推导性质。

性质关系·转化

三角函数线由三角函数的定义自然引出，是推导三角函数性质与图像的重要直观工具。

小节7.2.3 同角三角函数的基本关系式6 条知识点
定义概念

同一个角的正弦、余弦、正切之间的关系。

性质定义（基本关系式）

$$\sin^{2}\alpha+\cos^{2}\alpha=1,\qquad \tan\alpha=\frac{\sin\alpha}{\cos\alpha}.$$

性质表示符号

正割 $\sec\alpha=\dfrac{r}{x}=\dfrac{1}{\cos\alpha}$；余割 $\csc\alpha=\dfrac{r}{y}=\dfrac{1}{\sin\alpha}$；余切 $\cot\alpha=\dfrac{x}{y}=\dfrac{1}{\tan\alpha}$（$r=\sqrt{x^{2}+y^{2}}$）。

术语中英术语

secant 正割 / cosecant 余割 / cotangent 余切。

方法定理·公式·方法

由基本关系式可推导 $\tan^{2}\alpha+1=\sec^{2}\alpha$，$\cot^{2}\alpha+1=\csc^{2}\alpha$；已知一角的一个三角函数值，可结合同角关系（必要时配合象限符号或列方程组）求出其余函数值。

性质关系·转化

平方关系与商数关系可互相转化、互求；已知 $\sin\alpha$（或 $\cos\alpha$）与象限即可确定其余量。

小节7.2.4 诱导公式5 条知识点
定义概念

任意角三角函数值之间的一组特殊关系，反映角终边的对称性。

方法定理·公式·方法 （教材称公式①～⑧）
  • ① 终边相同：$\sin(\alpha+2k\pi)=\sin\alpha,\;\cos(\alpha+2k\pi)=\cos\alpha,\;\tan(\alpha+2k\pi)=\tan\alpha$；
  • ② 负角：$\sin(-\alpha)=-\sin\alpha,\;\cos(-\alpha)=\cos\alpha,\;\tan(-\alpha)=-\tan\alpha$；
  • ③ $\pi-\alpha$：$\sin(\pi-\alpha)=\sin\alpha,\;\cos(\pi-\alpha)=-\cos\alpha,\;\tan(\pi-\alpha)=-\tan\alpha$；
  • ④ $\pi+\alpha$：$\sin(\pi+\alpha)=-\sin\alpha,\;\cos(\pi+\alpha)=-\cos\alpha,\;\tan(\pi+\alpha)=\tan\alpha$；
  • ⑤ $\frac{\pi}{2}-\alpha$：$\sin(\frac{\pi}{2}-\alpha)=\cos\alpha,\;\cos(\frac{\pi}{2}-\alpha)=\sin\alpha$；
  • ⑥ $\frac{\pi}{2}+\alpha$：$\sin(\frac{\pi}{2}+\alpha)=\cos\alpha,\;\cos(\frac{\pi}{2}+\alpha)=-\sin\alpha$；
  • ⑦、⑧ 对应 $\frac{3\pi}{2}\pm\alpha$ 的关系式。
性质表示符号

$k\in\mathbf{Z}$。

术语中英术语

reduction formula 诱导公式。

性质关系·转化

可从"角终边的对称"角度理解并记忆；诱导公式可由两角差的余弦 $C_{\alpha-\beta}$ 等推得，本身也反映三角函数的奇偶性与周期性。

节7.3 三角函数的性质与图像5 小节 · 27 知识点
小节7.3.1 正弦函数的性质与图像6 条知识点
定义概念

$y=\sin x$ 称为正弦函数。

性质定义（性质）

定义域为 $\mathbf{R}$，值域 $[-1,1]$；最大值 $y_{\max}=1$（当 $x=\frac{\pi}{2}+2k\pi$），最小值 $y_{\min}=-1$（当 $x=\frac{3\pi}{2}+2k\pi$）；是奇函数；是周期函数，最小正周期为 $2\pi$；在 $[-\frac{\pi}{2}+2k\pi,\frac{\pi}{2}+2k\pi]$ 上递增，在 $[\frac{\pi}{2}+2k\pi,\frac{3\pi}{2}+2k\pi]$ 上递减；零点为 $x=k\pi$（$k\in\mathbf{Z}$）。

性质表示符号

正弦曲线（sine curve）。

术语中英术语

sine function 正弦函数 / periodic function 周期函数 / odd function 奇函数 / minimum positive period 最小正周期 / five-point method 五点法 / axis of symmetry 对称轴 / center of symmetry 对称中心。

方法定理·公式·方法

五点法作图，关键五点为 $(0,0),(\frac{\pi}{2},1),(\pi,0),(\frac{3\pi}{2},-1),(2\pi,0)$；正弦曲线对称轴 $x=\frac{\pi}{2}+k\pi$，对称中心 $(k\pi,0)$。

性质关系·转化

由单位圆中的正弦线直观得到上述性质；摩天轮高度模型 $y=r\sin x+l$ 与 $y=\sin x+1$ 性质类似。

小节7.3.2 正弦型函数的性质与图像6 条知识点
定义概念

形如 $y=A\sin(\omega x+\varphi)$（$A\neq 0,\;\omega\neq 0$）的函数称为正弦型函数，在物理与工程中频繁出现（如交流电流 $i=I_{m}\sin(\omega t+\varphi)$）。

性质定义（性质）

定义域为 $\mathbf{R}$，值域 $[-|A|,|A|]$，周期 $T=\dfrac{2\pi}{|\omega|}$。

性质表示符号

$A$ 为振幅（amplitude），$\varphi$ 为初相（initial phase），$\omega$ 为角频率；$T=\dfrac{2\pi}{|\omega|}$，频率 $f=\dfrac{1}{T}=\dfrac{|\omega|}{2\pi}$。

术语中英术语

sinusoidal function 正弦型函数 / amplitude 振幅 / initial phase 初相 / frequency 频率。

方法定理·公式·方法

其图像可通过对正弦曲线进行平移、伸缩得到（$y=A\sin x$ 纵向伸缩，$y=\sin\omega x$ 横向伸缩，$y=\sin(x+\varphi)$ 平移）；可用五点法作图；一般先取 $\omega x+\varphi$ 的一个周期区间列五点。

性质关系·转化

$y=A\sin(\omega x+\varphi)=A\sin[\omega(x+\frac{\varphi}{\omega})]$；辅助角公式 $a\sin x+b\cos x=\sqrt{a^{2}+b^{2}}\sin(x+\varphi)$，其中 $\varphi$ 满足 $\cos\varphi=\dfrac{a}{\sqrt{a^{2}+b^{2}}},\;\sin\varphi=\dfrac{b}{\sqrt{a^{2}+b^{2}}}$。

小节7.3.3 余弦函数的性质与图像5 条知识点
定义概念

$y=\cos x$ 称为余弦函数，且 $\cos x=\sin(x+\frac{\pi}{2})$。

性质定义（性质）

定义域 $\mathbf{R}$，值域 $[-1,1]$；是偶函数（$\cos(-x)=\cos x$）；是周期函数，最小正周期 $2\pi$；在 $[-\pi+2k\pi,2k\pi]$ 上递增，在 $[2k\pi,\pi+2k\pi]$ 上递减；零点为 $x=\frac{\pi}{2}+k\pi$。

性质表示符号

余弦曲线（cosine curve）；对称轴 $x=k\pi$，对称中心 $(\frac{\pi}{2}+k\pi,0)$。

术语中英术语

cosine function 余弦函数 / even function 偶函数。

性质关系·转化

由 $\cos x=\sin(x+\frac{\pi}{2})$ 知余弦曲线可由正弦曲线向左平移 $\frac{\pi}{2}$ 得到，故余弦曲线性质与正弦型函数 $y=\sin(x+\frac{\pi}{2})$ 相同。

小节7.3.4 正切函数的性质与图像5 条知识点
定义概念

$y=\tan x$ 称为正切函数（要求 $x\neq \frac{\pi}{2}+k\pi$）。

性质定义（性质）

定义域 $\{x\mid x\neq \frac{\pi}{2}+k\pi,\;k\in\mathbf{Z}\}$，值域 $\mathbf{R}$；是奇函数；最小正周期为 $\pi$；在每一个开区间 $(-\frac{\pi}{2}+k\pi,\frac{\pi}{2}+k\pi)$ 上单调递增；零点为 $x=k\pi$。

性质表示符号

正切曲线（tangent curve）；对称中心 $(\frac{k\pi}{2},0)$。

术语中英术语

tangent function 正切函数。

性质关系·转化

由正切线直观得到性质；注意正切函数在整个定义域上不是增函数，仅在每段开区间 $(-\frac{\pi}{2}+k\pi,\frac{\pi}{2}+k\pi)$ 内递增。

小节7.3.5 已知三角函数值求角5 条知识点
定义概念

已知三角函数值（或值的范围），求对应的角（或角的范围）。

性质表示符号

反三角函数记号——$\arcsin y$（$x\in[-\frac{\pi}{2},\frac{\pi}{2}]$ 内满足 $\sin x=y$），$\arccos y$（$x\in[0,\pi]$ 内满足 $\cos x=y$），$\arctan y$（$x\in(-\frac{\pi}{2},\frac{\pi}{2})$ 内满足 $\tan x=y$）。

术语中英术语

inverse sine 反正弦 / inverse cosine 反余弦 / inverse tangent 反正切。

方法定理·公式·方法

利用三角函数线（或三角函数曲线）求所有解，再补上周期；例如 $\sin x=\frac{1}{2}$ 的解为 $x=\frac{\pi}{6}+2k\pi$ 或 $x=\frac{5\pi}{6}+2k\pi$（$k\in\mathbf{Z}$）；$\tan x=-1$ 的解为 $x=-\frac{\pi}{4}+k\pi$。

性质关系·转化

已知特殊函数值可反求角；结合单调性可解三角不等式（如 $\sin x\ge \frac{1}{2}$ 的解集）。

节7.4 数学建模活动：周期现象的描述1 小节 · 5 知识点
小节本节知识点节内直列5 条知识点
定义概念

借助三角函数建立数学模型来描述日常生活与其他学科中的周期现象。

方法方法（建模过程）

完整数学建模一般经历选题、开题、做题、结题四个过程；可借助 GeoGebra、Excel、MATLAB、Maple、Mathematica、SPSS 等软件作图计算。

性质表示符号

简谐振动、音叉纯音、交变电流等均可写成 $y=A\sin(\omega x+\varphi)$ 形式（$A$ 振幅，$\frac{|\omega|}{2\pi}$ 频率，$\varphi$ 初相）。

术语中英术语

mathematical modeling 数学建模 / harmonic vibration 简谐振动 / alternating current 交变电流。

性质关系·转化

潮汐水位、单摆与弹簧振动、音叉振动、交流电流等周期现象，均可用正弦型函数近似或精确描述。

节8.1 向量的数量积3 小节 · 16 知识点
小节8.1.1 向量数量积的概念6 条知识点
定义概念

由两个向量确定出一个实数（标量的乘积关系），由物理中"功"引入。

定义定义

给定两个非零向量 $a,b$，称 $|a||b|\cos\langle a,b\rangle$ 为向量 $a$ 与 $b$ 的数量积（也称内积），记作 $a\cdot b$，即 $a\cdot b=|a||b|\cos\langle a,b\rangle$。当 $a,b$ 至少有一个为零向量时，规定 $a\cdot b=0$。

性质表示符号

向量 $a,b$ 的夹角记作 $\langle a,b\rangle\in[0,\pi]$；垂直记作 $a\perp b$；$a\cdot a=|a|^{2}$（简写为 $a^{2}$）。

术语中英术语

dot product / scalar product 数量积（内积）/ angle between vectors 夹角 / projection 投影 / orthogonal 垂直。

方法定理·公式·方法

性质 $|a\cdot b|\le |a||b|$；$\cos\langle a,b\rangle=\dfrac{a\cdot b}{|a||b|}$（非零向量）；$a\perp b\Leftrightarrow a\cdot b=0$。投影：向量 $a$ 在向量 $b$ 上的投影的数量 $=|a|\cos\langle a,b\rangle$；数量积的几何意义为"$a$ 在 $b$ 上的投影的数量与 $|b|$ 的乘积"。

性质关系·转化

由功 $W=|F||s|\cos\theta$ 抽象出数量积；零向量与任意向量垂直，故 $0\cdot a=0$。

小节8.1.2 向量数量积的运算律5 条知识点
定义概念

数量积满足的运算律，可由定义或几何意义（投影）证明。

方法定理·公式·方法
  • 交换律：$a\cdot b=b\cdot a$；
  • 数乘结合：$(\lambda a)\cdot b=\lambda(a\cdot b)=a\cdot(\lambda b)$；
  • 分配律：$(a+b)\cdot c=a\cdot c+b\cdot c$，进而 $(a-b)\cdot c=a\cdot c-b\cdot c$；
  • 展开式：$(a+b)^{2}=a^{2}+2a\cdot b+b^{2}$，$(a+b)\cdot(a-b)=a^{2}-b^{2}$，$(a-b)^{2}=a^{2}-2a\cdot b+b^{2}$。
性质表示符号

$a^{2}=|a|^{2}$。

术语中英术语

commutative law 交换律 / associative law（对实数） / distributive law 分配律。

性质关系·转化

分配律可由投影的几何意义证明（用与 $c$ 同向的单位向量）；这些运算律是把向量方法用于几何证明（如菱形对角线互相垂直、三角形三条高交于一点）的关键。

小节8.1.3 向量数量积的坐标运算5 条知识点
定义概念

在直角坐标系下用坐标计算数量积、模、夹角与垂直条件。

方法定理·公式·方法

取单位正交基底 $\{e_{1},e_{2}\}$（$e_{1}\cdot e_{1}=e_{2}\cdot e_{2}=1,\;e_{1}\cdot e_{2}=0$）。设 $a=(x_{1},y_{1}),\;b=(x_{2},y_{2})$，则 $$a\cdot b=x_{1}x_{2}+y_{1}y_{2},\qquad |a|=\sqrt{x_{1}^{2}+y_{1}^{2}},$$ $$\cos\langle a,b\rangle=\frac{x_{1}x_{2}+y_{1}y_{2}}{\sqrt{x_{1}^{2}+y_{1}^{2}}\;\sqrt{x_{2}^{2}+y_{2}^{2}}}.$$ 两点 $A(x_{1},y_{1}),B(x_{2},y_{2})$ 的距离 $|\overrightarrow{AB}|=\sqrt{(x_{2}-x_{1})^{2}+(y_{2}-y_{1})^{2}}$。

性质表示符号

垂直充要条件 $a\perp b\;\Leftrightarrow\;x_{1}x_{2}+y_{1}y_{2}=0$。

术语中英术语

coordinate 坐标 / orthogonal basis 正交基底。

性质关系·转化

由坐标与数量积表达向量垂直条件；拓展：以 $OA,OB$ 为邻边的平行四边形面积（及 $\triangle OAB$ 面积 $S=\frac{1}{2}|x_{1}y_{2}-x_{2}y_{1}|$）可用坐标通过数量积求得。

节8.2 三角恒等变换4 小节 · 20 知识点
小节8.2.1 两角和与差的余弦5 条知识点
定义概念

用 $\alpha,\beta$ 的三角函数表示 $\cos(\alpha\pm\beta)$。

方法定理·公式·方法 （用单位圆与向量数量积证明 $C_{\alpha-\beta}$）
  • $C_{\alpha-\beta}$：$\cos(\alpha-\beta)=\cos\alpha\cos\beta+\sin\alpha\sin\beta$；
  • $C_{\alpha+\beta}$：$\cos(\alpha+\beta)=\cos\alpha\cos\beta-\sin\alpha\sin\beta$。
性质表示符号

$C_{\alpha-\beta},\;C_{\alpha+\beta}$。

术语中英术语

cosine of sum/difference 两角和与差的余弦。

性质关系·转化

由 $C_{\alpha-\beta}$ 可推出诱导公式（如 $\cos(\frac{\pi}{2}-\alpha)=\sin\alpha$）；再由 $\alpha+\beta=\alpha-(-\beta)$ 推出 $C_{\alpha+\beta}$。

小节8.2.2 两角和与差的正弦、正切5 条知识点
定义概念

用 $\alpha,\beta$ 的三角函数表示 $\sin(\alpha\pm\beta)$ 与 $\tan(\alpha\pm\beta)$。

方法定理·公式·方法

（式中各角取值应使各项有意义。）

  • $S_{\alpha+\beta}$：$\sin(\alpha+\beta)=\sin\alpha\cos\beta+\cos\alpha\sin\beta$；
  • $S_{\alpha-\beta}$：$\sin(\alpha-\beta)=\sin\alpha\cos\beta-\cos\alpha\sin\beta$；
  • $T_{\alpha+\beta}$：$\tan(\alpha+\beta)=\dfrac{\tan\alpha+\tan\beta}{1-\tan\alpha\tan\beta}$；
  • $T_{\alpha-\beta}$：$\tan(\alpha-\beta)=\dfrac{\tan\alpha-\tan\beta}{1+\tan\alpha\tan\beta}$。
性质表示符号

$S_{\alpha\pm\beta},\;T_{\alpha\pm\beta}$。

术语中英术语

sine / tangent of sum and difference 两角和与差的正弦 / 正切。

性质关系·转化

由诱导公式与 $C$ 公式推出 $S$ 公式；由商数关系 $\tan=\sin/\cos$ 推出 $T$ 公式；进而得到辅助角公式 $a\sin x+b\cos x=\sqrt{a^{2}+b^{2}}\sin(x+\varphi)$，用于求 $a\sin x+b\cos x$ 型函数的周期、最值。

小节8.2.3 倍角公式5 条知识点
定义概念

由 $\alpha$ 的三角函数求 $2\alpha$ 的三角函数（令和角公式中 $\beta=\alpha$）。

方法定理·公式·方法 （倍角公式）
  • $S_{2\alpha}$：$\sin 2\alpha=2\sin\alpha\cos\alpha$；
  • $C_{2\alpha}$：$\cos 2\alpha=\cos^{2}\alpha-\sin^{2}\alpha=2\cos^{2}\alpha-1=1-2\sin^{2}\alpha$；
  • $T_{2\alpha}$：$\tan 2\alpha=\dfrac{2\tan\alpha}{1-\tan^{2}\alpha}$。
性质表示符号

$S_{2\alpha},\;C_{2\alpha},\;T_{2\alpha}$。

术语中英术语

double-angle formula 倍角公式。

性质关系·转化

倍角公式是和角公式的特例；常用于化简三角式、求函数的周期与最值（如 $2\cos^{2}x+\sin2x-1=\sqrt{2}\sin(2x+\frac{\pi}{4})$）。

小节8.2.4 三角恒等变换的应用5 条知识点
定义概念

在倍角公式基础上导出半角公式、积化和差与和差化积公式，并用于化简与求周期/最值。

方法定理·公式·方法
  • 半角（平方）：$\sin^{2}\frac{\alpha}{2}=\dfrac{1-\cos\alpha}{2},\;\cos^{2}\frac{\alpha}{2}=\dfrac{1+\cos\alpha}{2},\;\tan^{2}\frac{\alpha}{2}=\dfrac{1-\cos\alpha}{1+\cos\alpha}$；
  • 半角（带符号）：$S_{\frac{\alpha}{2}},C_{\frac{\alpha}{2}},T_{\frac{\alpha}{2}}$ 公式，根号前符号由 $\frac{\alpha}{2}$ 所在象限确定；
  • 积化和差（④⑤⑥⑦）：$\cos\alpha\cos\beta=\frac{1}{2}[\cos(\alpha+\beta)+\cos(\alpha-\beta)]$，$\sin\alpha\sin\beta=-\frac{1}{2}[\cos(\alpha+\beta)-\cos(\alpha-\beta)]$，$\sin\alpha\cos\beta=\frac{1}{2}[\sin(\alpha+\beta)+\sin(\alpha-\beta)]$，$\cos\alpha\sin\beta=\frac{1}{2}[\sin(\alpha+\beta)-\sin(\alpha-\beta)]$；
  • 和差化积：$\cos x+\cos y=2\cos\frac{x+y}{2}\cos\frac{x-y}{2}$，$\cos x-\cos y=-2\sin\frac{x+y}{2}\sin\frac{x-y}{2}$，$\sin x+\sin y=2\sin\frac{x+y}{2}\cos\frac{x-y}{2}$，$\sin x-\sin y=2\cos\frac{x+y}{2}\sin\frac{x-y}{2}$。
性质表示符号

$C_{2\alpha}$ 是导出半角公式的基础。

术语中英术语

half-angle formula 半角公式 / product-to-sum 积化和差 / sum-to-product 和差化积。

性质关系·转化

由 $C_{2\alpha}$ 推出半角公式；由和差余弦相加减推出积化和差，再令 $x=\alpha+\beta,\;y=\alpha-\beta$ 改写得到和差化积；这些公式与辅助角公式共同构成三角恒等变换的工具箱，用于化简三角函数式、求周期与最值，也为后续"正弦型函数与信号处理"等内容提供理论基础。
