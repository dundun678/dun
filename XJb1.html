小节1.1.1 集合与元素6 条知识点
定义概念

把一些对象放在一起考虑时，这些对象组成一个集合（集），其中每个对象叫作这个集合的一个元素。

定义定义

集合的基本属性：① 同一集合中的元素互不相同；② 元素确定（任一元素属于或不属于集合是确定的）；③ 元素没有顺序。

性质表示符号
  • 属于 $a \in S$；不属于 $a \notin S$（或 $a \in S$ 的否定）。
  • 数集：自然数集 $\mathbf{N}$，整数集 $\mathbf{Z}$，有理数集 $\mathbf{Q}$，实数集 $\mathbf{R}$；正实数 $\mathbf{R}_+$，负实数 $\mathbf{R}_-$，正整数 $\mathbf{Z}_+$（或 $\mathbf{N}_+$），负有理数 $\mathbf{Q}_-$ 等。
  • 有限集/无限集（或无穷集）；空集 $\varnothing$（没有元素的集合，也是有限集）。
  • 列举法：大括号内一一列出元素，如 $\{2,4,6,8\}$。
  • 描述法：大括号内写元素共有属性，或 $\{x \in \mathbf{Z} \mid x=2k,\ k\in\mathbf{Z}\}$（竖线后列条件）。
  • 区间：开区间 $(a,b)=\{x\mid a<x<b\}$；闭区间 $[a,b]=\{x\mid a\leqslant x\leqslant b\}$；半开半闭 $(a,b]$、$[a,b)$；无穷区间 $[a,+\infty)$、$(a,+\infty)$、$(-\infty,b]$、$(-\infty,b)$；实数集 $\mathbf{R}=(-\infty,+\infty)$，$\infty$ 读作"无穷大"。
术语中英术语

set 集合 / element（或 member）元素 / number set 数集 / empty set 空集 / finite set 有限集 / infinite set 无限集 / interval 区间 / universal set 全集。

方法定理 / 公式 / 方法

列举法适用于有限且元素较少或能叫出名字的集合；描述法适用于无限集或元素太多/叫不出名字的集合；区间用于连续的实数子集。

性质关系 / 转化

集合是数学语言的基础；$\in$ 表达元素对集合的归属关系；数集的包含关系 $\mathbf{N}\subsetneqq\mathbf{Z}\subsetneqq\mathbf{Q}\subsetneqq\mathbf{R}$。

小节1.1.2 子集和补集7 条知识点
定义概念

子集描述集合之间的包含关系；补集描述在全集背景下"不属于某子集"的剩余元素。

定义定义（子集）

若集合 $A$ 的每个元素都是集合 $B$ 的元素，称 $A$ 包含于 $B$，记作 $A \subseteq B$（或 $B \supseteq A$）；等价地，"若 $x\in A$ 能推出 $x\in B$，则 $A\subseteq B$"。$A$ 是 $B$ 的子集。

  • 集合相等：$A\subseteq B$ 且 $B\subseteq A$，记作 $A=B$。
  • 真子集：$A\subseteq B$ 但 $A\neq B$，记作 $A\subsetneqq B$。
  • 规定：空集包含于任一集合（是任一集合的子集）；每个集合是它自己的子集。
定义定义（补集）

若 $A$ 是全集 $U$ 的子集，$U$ 中所有不属于 $A$ 的元素组成的集合叫 $A$ 的补集，记作 $\complement_U A=\{x\mid x\in U\text{ 且 }x\notin A\}$；当 $U$ 可由上下文确知时亦可记作 $\overline{A}$。一般地，不论 $A$ 是否为 $B$ 的子集，可用 $B\setminus A$ 表示 $B$ 中不属于 $A$ 的元素组成的集合。

性质表示符号

包含于 $\subseteq$、包含 $\supseteq$、相等 $=$、真包含于 $\subsetneqq$；补集 $\complement_U A$（或 $\overline{A}$）；差集 $B\setminus A$；韦恩图（Venn 图）。

术语中英术语

subset 子集 / proper subset 真子集 / complement 补集 / difference set 差集 / Venn diagram 韦恩图。

方法定理 / 公式 / 方法

包含关系具有传递性（$A\subseteq B,B\subseteq C\Rightarrow A\subseteq C$；真子集同理）；$\complement_U(\complement_U A)=A$。

性质关系 / 转化

含于关系 $\Rightarrow$ 子集；相等 $\Leftrightarrow$ 互相包含；日常语言"红马是马"中的"是"相当于 $\subseteq$（包含于）。

小节1.1.3 集合的交与并7 条知识点
定义概念

交集取两个集合的共有元素；并集取两个集合的全部元素（重复元素只算一个）。

定义定义（交）

$A\cap B=\{x\mid x\in A\text{ 且 }x\in B\}$，读作"A 交 B"。

定义定义（并）

$A\cup B=\{x\mid x\in A\text{ 或 }x\in B\}$，读作"A 并 B"。

性质表示符号

交集 $\cap$；并集 $\cup$；韦恩图阴影表示相应区域。

术语中英术语

intersection 交集 / union 并集。

方法定理 / 公式 / 方法
  • 交：$A\cap A=A$，$A\cap\varnothing=\varnothing$，$A\cap B=B\cap A$。
  • 并：$A\cup A=A$，$A\cup\varnothing=A$，$A\cup B=B\cup A$。
  • 交集与联立方程组的解集有关；并集与"把方程一端化为零、左端分解成因式乘积"的解集有关（如 $(x^2-9)(x^2-3x+2)=0$ 的解集是两方程解集的并）。
性质关系 / 转化

交集 $\cap$ 对应逻辑"且"；并集 $\cup$ 对应逻辑"或"；交集为空集时两直线无交点、两平面平行。

小节1.2.1 命题6 条知识点
定义概念

命题是对事物作出判断的陈述句；判断可能成立也可能不成立，二者必居其一。

定义定义

作出判断的语句叫命题；成立的叫真命题，不成立的叫假命题（公理、基本事实、定理都是真命题）。暂时不知真假的叫猜想。

性质表示符号

命题的否定 $\neg p$（读作"非 $p$"）；推出关系 $p\Rightarrow q$（真）、$p\nRightarrow q$（假）；"若 $p$，则 $q$" 中 $p$ 为条件、$q$ 为结论。

术语中英术语

proposition 命题 / true proposition 真命题 / false proposition 假命题 / conjecture 猜想 / negation 否定 / converse proposition 逆命题。

方法定理 / 公式 / 方法

命题通常由条件和结论组成（"若 $p$，则 $q$" 形式）；交换条件与结论得到逆命题；判断假命题常用举反例；$\neg p$ 与 $p$ 必有一真一假。

性质关系 / 转化

条件与结论互换得到互逆命题；"若 $p$ 则 $q$" 为真记作 $p\Rightarrow q$。

小节1.2.2 充分条件和必要条件6 条知识点
定义概念

刻画条件与结论之间的推出关系。

定义定义

若 $p\Rightarrow q$，则 $p$ 是 $q$ 的充分条件，$q$ 是 $p$ 的必要条件。若既有 $p\Rightarrow q$ 又有 $q\Rightarrow p$，记作 $p\Leftrightarrow q$，称 $p$ 是 $q$ 的充分必要条件（充要条件）；此时 $p,q$ 互相等价。

性质表示符号

$\Rightarrow$（推出）、$\nRightarrow$（推不出）、$\Leftrightarrow$（等价/充要）。

术语中英术语

sufficient condition 充分条件 / necessary condition 必要条件 / necessary and sufficient condition 充要条件（或 sufficient and necessary condition）。

方法定理 / 公式 / 方法

性质定理揭示必要条件，判定定理揭示充分条件，二者综合即为充要条件。四种关系：充分而不必要、必要而不充分、充要、既不充分也不必要。

性质关系 / 转化

全等 $\Rightarrow$ 相似（全等是相似的充分条件）；实数 $a\neq 0 \Leftrightarrow a^2>0$；互相等价的命题是对同一事物的不同角度描述（如三角形全等的 SSS、SAS、ASA 互相等价）。

小节1.2.3 全称量词和存在量词7 条知识点
定义概念

量词限定命题中变量的作用范围，使含不确定变量的语句成为（有真假的）命题。

定义定义（全称量词）

"任意""所有""每一个"等，符号 $\forall$；命题 $\forall x\in M, p(x)$（对 $M$ 的任一元素 $x$ 有 $p(x)$ 成立）叫全称量词命题。

定义定义（存在量词）

"存在某个""至少有一个"等，符号 $\exists$；命题 $\exists x\in M, p(x)$（存在 $M$ 的某个元素 $x$ 使 $p(x)$ 成立）叫存在量词命题。

性质表示符号

$\forall$（全称量词）、$\exists$（存在量词）；量词作用范围（如 $\mathbf{R},\mathbf{Z},\mathbf{N}_+,(10,+\infty)$ 等）。

术语中英术语

universal quantifier 全称量词 / existential quantifier 存在量词 / universally quantified proposition 全称量词命题 / existentially quantified proposition 存在量词命题。

方法定理 / 公式 / 方法

含量词命题的否定——量词互换、肯定变否定：

  • $\neg(\forall x, p(x))\Leftrightarrow \exists x, \neg p(x)$；
  • $\neg(\exists x, p(x))\Leftrightarrow \forall x, \neg p(x)$。
  • 全称量词常被省略（如平方差公式 $a^2-b^2=(a+b)(a-b)$ 中 $a,b$ 指任意实数）。
性质关系 / 转化

全称命题与存在命题互为否定时量词互换；判断全称命题只需找到一个反例即假，判断存在命题只需找到一个实例即真。

小节2.1.1 等式与不等式6 条知识点
定义概念

相等关系刻画"静态的数量关系"，不等关系刻画"动态的数量关系"；两者对立统一、可相互转化。

性质定义（实数大小比较基本事实）

$a-b>0\Leftrightarrow a>b$；$a-b=0\Leftrightarrow a=b$；$a-b<0\Leftrightarrow a<b$。比较两实数大小只需考察它们的差。

性质表示符号

$>,\ <,\ \geqslant,\ \leqslant$；作差比较法。

术语中英术语

inequality 不等式 / equality 等式 / difference method 作差法。

方法定理 / 公式 / 方法（不等式的基本性质）
  • 性质1（对称性）：$a>b\Leftrightarrow b<a$。
  • 性质2（传递性）：$a>b,b>c\Rightarrow a>c$。
  • 性质3（可加性）：$a>b\Rightarrow a+c>b+c$；推论1（移项）：$a+b>c\Rightarrow a>c-b$；推论2（同向相加）：$a>b,c>d\Rightarrow a+c>b+d$（可推广到有限个同向不等式）。
  • 性质4（乘法）：$a>b,c>0\Rightarrow ac>bc$；$a>b,c<0\Rightarrow ac<bc$；推论3（正数同向相乘）：$a>b>0,c>d>0\Rightarrow ac>bd$；推论4：$a>b>0\Rightarrow a^n>b^n\ (n\in\mathbb{N},n\geqslant2)$；推论5：$a>b>0\Rightarrow\sqrt a>\sqrt b$。
  • 性质5（倒数）：$a>b$ 且 $ab>0\Rightarrow \frac1a<\frac1b$；$a>b$ 且 $ab<0\Rightarrow \frac1a>\frac1b$。
性质关系 / 转化

三角形"两边之和大于第三边"与"两边之差小于第三边"逻辑等价；不等式性质由作差法与正数运算规则推出。

小节2.1.2 基本不等式6 条知识点
定义概念

两个正数 $a,b$ 的算术平均数与几何平均数之间的不等式关系。

性质定义（定理）

对任意 $a,b\in\mathbf{R}$，有 $a^2+b^2\geqslant 2ab$，当且仅当 $a=b$ 时取等。当 $a,b>0$ 时，推论 $\frac{a+b}{2}\geqslant\sqrt{ab}$，当且仅当 $a=b$ 时取等，称为基本不等式（两个正数的算术平均数不小于它们的几何平均数）。

性质表示符号

算术平均数 $\frac{a+b}{2}$；几何平均数 $\sqrt{ab}$；等号成立条件"当且仅当 $a=b$"。

术语中英术语

basic inequality 基本不等式 / arithmetic mean 算术平均数 / geometric mean 几何平均数。

方法定理 / 公式 / 方法

常用变形——$a+\frac1a\geqslant2\ (a>0)$；$\frac ba+\frac ab\geqslant2\ (a,b>0)$；三个正数 $a+b+c\geqslant\sqrt{ab}+\sqrt{bc}+\sqrt{ca}$（当 $a=b=c$ 取等）。

性质关系 / 转化

基本不等式由 $a^2+b^2\geqslant2ab$ 在正数情形两边开方得到；可用于求最值（积定和最小、和定积最大）。

小节2.1.3 基本不等式的应用6 条知识点
定义概念

把"材料最省、利润最高、成本最低"等最值问题转化为基本不等式求最值。

定义定义（应用模型）

已知 $x,y>0$，

  • 若积 $xy=p$（定值），则当 $x=y$ 时和 $x+y$ 取最小值 $2\sqrt p$；
  • 若和 $x+y=s$（定值），则当 $x=y$ 时积 $xy$ 取最大值 $\frac{s^2}{4}$。
性质表示符号

定值 $p$、定值 $s$；最值 $2\sqrt p$、$\frac{s^2}{4}$。

术语中英术语

optimization 最优化 / maximum 最大值 / minimum 最小值。

方法定理 / 公式 / 方法

先列函数关系（造价、面积等），再用基本不等式求最值，遵循"一正、二定、三相等"——变量为正、和或积为定值、等号能取到。

性质关系 / 转化

实际问题→函数关系→基本不等式模型→最值（需结合定义域检验等号能否取到）。

小节2.2.1 二次函数与一元二次方程（函数的零点）6 条知识点
定义概念

一元二次方程的根、二次函数的零点、函数图象与 $x$ 轴交点的横坐标，三者一致。

定义定义（零点）

使 $ax^2+bx+c=0\ (a\neq0)$ 成立的实数 $x$ 叫二次函数 $y=ax^2+bx+c$ 的零点；零点就是图象与 $x$ 轴交点的横坐标。

性质表示符号

判别式 $\Delta=b^2-4ac$；零点。

术语中英术语

quadratic function 二次函数 / quadratic equation 一元二次方程 / zero point 零点 / discriminant 判别式。

方法定理 / 公式 / 方法（$\Delta$ 与根、交点、零点的关系，以 $a>0$ 为例）
  • $\Delta>0$：两不等实根 $x_1,x_2$，图象与 $x$ 轴两个交点 $(x_1,0),(x_2,0)$；
  • $\Delta=0$：两相等实根 $x_1=x_2=-\frac b{2a}$，图象与 $x$ 轴一个交点（顶点在轴上）；
  • $\Delta<0$：无实根，图象与 $x$ 轴无交点。
  • 根与系数关系（韦达定理）：$x_1+x_2=-\frac ba$，$x_1x_2=\frac ca$。
性质关系 / 转化

方程的根 $\Leftrightarrow$ 函数的零点 $\Leftrightarrow$ 图象与 $x$ 轴交点横坐标；数形结合体现函数、方程、不等式的统一。

小节2.2.2 十字相乘法6 条知识点
定义概念

对二次三项式 $ax^2+bx+c$ 的因式分解方法（适用于对应方程有有理根的情形）。

定义定义

若找到 $a_1,a_2,c_1,c_2$ 使 $a=a_1a_2,\ c=c_1c_2$ 且 $b=a_1c_2+a_2c_1$，则 $ax^2+bx+c=(a_1x+c_1)(a_2x+c_2)$。

性质表示符号

十字交叉图（二次项系数分解与常数项分解交叉相乘之和等于一次项系数）。

术语中英术语

cross multiplication 十字相乘法 / factorization 因式分解。

方法定理 / 公式 / 方法

先分解 $a$ 与 $c$ 的因数，再检验交叉乘积和是否等于 $b$。

性质关系 / 转化

十字相乘可快速求一元二次方程的有理根，进而求函数的零点。

节2.3 一元二次不等式2 小节 · 12 知识点
小节2.3.1 一元二次不等式及其解法6 条知识点
定义概念

只含一个未知数且最高次数为 2 的不等式；其解集与对应二次函数图象相对 $x$ 轴的位置相关。

定义定义

一元二次不等式形如 $ax^2+bx+c>0$ 或 $<0$ 等（$a\neq0$）。

性质表示符号

判别式 $\Delta=b^2-4ac$；解集用区间或集合表示。

术语中英术语

quadratic inequality in one variable 一元二次不等式。

方法定理 / 公式 / 方法（$a>0$ 的解集，由 $\Delta$ 分三种）
  • $\Delta>0$（两根 $x_1<x_2$）：$>0$ 解集 $(-\infty,x_1)\cup(x_2,+\infty)$；$<0$ 解集 $(x_1,x_2)$。
  • $\Delta=0$：$>0$ 解集 $(-\infty,-\frac b{2a})\cup(-\frac b{2a},+\infty)$；$<0$ 解集 $\varnothing$。
  • $\Delta<0$：$>0$ 解集 $\mathbf{R}$；$<0$ 解集 $\varnothing$。
  • 解题三步：求对应方程根→画二次函数大致图象→由图象得解集。$a<0$ 时先化 $a>0$。
性质关系 / 转化

方程（函数值=0）与不等式（函数值≠0）分别是二次函数的"局部"情形，都由图象得出；分式不等式可化为整式不等式（如 $\frac AB>0\Leftrightarrow AB>0$）。

小节2.3.2 一元二次不等式的应用6 条知识点
定义概念

将成本、利润、距离、速度等实际问题转化为一元二次不等式求解。

方法定义 / 方法

依题意列不等式→整理成标准二次式→用图象法或判别式法求解，并结合实际定义域取舍。

性质表示符号

恒成立（解集为 $\mathbf{R}$）对应 $a>0$ 且 $\Delta<0$；解集端点即对应方程根。

术语中英术语

application 应用 / always true 恒成立。

方法定理 / 公式 / 方法

恒成立问题常转化为 $\Delta<0$；可由已知解集反求参数（解集端点即方程根）；分式不等式等价变形后求解。

性质关系 / 转化

实际问题→数学模型（不等式）→函数观点求解→实际结论。

章第3章 函数的概念与性质2 节 · 5 小节 · 33 知识点
节3.1 函数3 小节 · 19 知识点
小节3.1.1 函数的概念与映射7 条知识点
定义概念

函数是变量与变量之间的确定性对应关系；"确定性"是函数概念的灵魂（给自变量的值能唯一确定函数值；如矩形面积不是周长的函数）。

定义定义（函数）

设 $A,B$ 是两个非空的实数集，如果按照某种确定的对应关系 $f$，对于 $A$ 中的任何一个数 $x$，在 $B$ 中都有唯一的数 $y$ 和它对应，那么称这样的对应 $f:A\to B$ 为定义于 $A$ 取值于 $B$ 的函数，记作 $y=f(x)\ (x\in A,\ y\in B)$。其中 $x$ 叫自变量，$x$ 的取值范围 $A$ 叫定义域；与 $x$ 对应的 $y$ 叫函数值，记作 $f(x)$；所有函数值组成的集合 $\{f(x)\mid x\in A\}$ 叫值域（是 $B$ 的子集）。

  • 三要素：定义域、对应关系、值域（值域由定义域和对应关系完全确定）。
  • 函数相等：定义域相同，且对其中每个 $x$ 都有 $f(x)=g(x)$。
  • 自然定义域：只给解析式而不指明定义域时，指使解析式有意义的 $x$ 的全体。
定义定义（映射）

把数集放宽为一般集合——设 $A,B$ 非空集合，若按对应关系 $f$ 对 $A$ 中任一元素 $x$，在 $B$ 中都有唯一元素 $y$ 和它对应，这样的对应 $f$ 叫 $A$ 到 $B$ 的映射，记作 $f:A\to B$。$A$ 叫定义域，$y$ 叫 $x$ 的像 $f(x)$，所有像组成的集合叫值域。函数即非空数集到非空数集的映射。

性质表示符号

$y=f(x)$；函数值 $f(x)$；定义域、值域；映射 $f:A\to B$（或 $y=f(x)$）。

术语中英术语

function 函数 / mapping 映射 / independent variable 自变量 / dependent variable 因变量 / domain 定义域 / range（或 codomain）值域 / image 像。

方法定理 / 公式 / 方法

用函数符号计算（如 $f(f(f(0)))$）；求定义域（使解析式有意义：偶次根式被开方数 $\geqslant0$、分式分母 $\neq0$）；"求平方根"的对应不是映射，"求算术平方根"是映射。

性质关系 / 转化

函数是两个数集间确定的对应（映射的特例）；初中"变化过程"语言 → 高中"集合与对应"语言。

小节3.1.2 表示函数的方法6 条知识点
定义概念

把函数的对应关系和定义域交代清楚的方法。

定义定义（三种表示法）

解析法、列表法、图象法。

  • 解析法：用解析式（解析表达式/函数关系式）表示函数，简捷明了、便于计算函数值和推导性质，是最基本最常用的方法之一。
  • 列表法：用表格列出对应值，具体易用，但不够全面、难看出数学性质。
  • 图象法：用图象直观了解性质，作图通常有"列表—描点—连线"三步。
性质表示符号

解析式（如大坝横断面面积 $S(x)=\frac{(30+30+4x)x}{2}=2x^2+30x$，定义域 $[10,50]$）。

术语中英术语

方法定理 / 公式 / 方法

求得解析式后，求函数值、画图象、列函数表都能迎刃而解；常把解析法与图象法结合；其他表示法还有标尺法、算法（程序）法、描述法（如狄利克雷函数 $D(x)$）。

性质关系 / 转化

节3.2 函数的基本性质2 小节 · 14 知识点
小节3.2.1 函数的单调性与最值7 条知识点
定义概念

刻画函数值的变化趋势（走高/下滑）和上界下界（封顶/保底）。

定义定义（最大值/最小值）

若有 $a\in D$，使不等式 $f(x)\leqslant f(a)$ 对一切 $x\in D$ 成立，就说 $f(x)$ 在 $x=a$ 处取到最大值 $M=f(a)$（$a$ 为最大值点）；最小值与最小值点定义类似。最大值和最小值统称最值。

定义定义（单调性）

若对区间 $I$ 上任意两个值 $x_1,x_2$，当 $x_1<x_2$ 时都有 $f(x_1)<f(x_2)$，称 $f(x)$ 是区间 $I$ 上的增函数（单调递增）；若都有 $f(x_1)>f(x_2)$，称减函数（单调递减）。区间 $I$ 叫单调区间。

性质表示符号

$x_1<x_2\Rightarrow f(x_1)<f(x_2)$（增）、$f(x_1)>f(x_2)$（减）；商 $\dfrac{f(x_2)-f(x_1)}{x_2-x_1}$。

术语中英术语

monotonicity 单调性 / increasing function 增函数 / decreasing function 减函数 / monotonic interval 单调区间 / maximum 最大值 / minimum 最小值 / extremum 最值。

方法定理 / 公式 / 方法
  • 判别：$x_2-x_1$ 与 $f(x_2)-f(x_1)$ 同号→增函数，异号→减函数；即看商 $\dfrac{f(x_2)-f(x_1)}{x_2-x_1}$ 的正负。
  • 例：$f(x)=x+\frac1x$ 在 $(0,1]$ 上递减、在 $[1,+\infty)$ 上递增，在 $x=1$ 处取最小值 $f(1)=2$。
  • 二次函数单调性看对称轴与开口：$f(x)=x^2+2(a-1)x+2$ 的对称轴 $x=1-a$，开口向上时在 $(-\infty,1-a]$ 上递减。
性质关系 / 转化

单调性把自变量变化方向与函数值变化方向联系起来，描述函数的变化过程和趋势，是函数最重要的特征之一。

小节3.2.2 函数的奇偶性7 条知识点
定义概念

描述函数图象的对称性（关于 $y$ 轴为轴对称，关于原点为中心对称）。

定义定义（偶函数）

如果对一切使 $F(x)$ 有定义的 $x$，$F(-x)$ 也有定义，并且 $F(-x)=F(x)$ 成立，则称 $F(x)$ 为偶函数（图象以 $y$ 轴为对称轴）。

定义定义（奇函数）

如果 $F(-x)=-F(x)$ 成立，则称 $F(x)$ 为奇函数（图象以原点为对称中心）。

性质表示符号

$F(-x)=F(x)$（偶）、$F(-x)=-F(x)$（奇）；前提是定义域关于原点对称。

术语中英术语

even function 偶函数 / odd function 奇函数 / axis of symmetry 对称轴 / central symmetry 中心对称。

方法定理 / 公式 / 方法

判断奇偶性先看定义域是否关于原点对称，再比较 $f(-x)$ 与 $\pm f(x)$。例：$f(x)=x^2+|x|$ 为偶函数；$g(x)=x+\frac{k}{x}$ 为奇函数；$h(x)=x^3(x\in[-2,5])$ 定义域不对称则非奇非偶。$f(x)=g(x)+g(-x)$ 为偶函数；$f(x)=g(x)-g(-x)$ 为奇函数。

性质关系 / 转化

偶函数满足 $f(x)=f(-x)$，可由 $[0,5]$ 上表达式得 $[-5,0]$ 上表达式；奇函数满足 $f(-x)=-f(x)$；定义域关于原点不对称必为非奇非偶函数。

小节4.1.1 有理数指数幂8 条知识点
定义概念

把整数指数幂推广到有理数指数幂。

定义定义（整数指数幂）

$a^n$ 表示 $n$ 个 $a$ 连乘；规定 $a\neq0$ 时 $a^0=1$，$a^{-n}=\frac1{a^n}\ (n\in\mathbf{N})$。

定义定义（根式）

若 $x^n=a\ (n\in\mathbf{N},n\geqslant2)$，则 $x$ 是 $a$ 的 $n$ 次方根。$n$ 为奇数时方根记作 $\sqrt[n]{a}$，符号与 $a$ 一致；$n$ 为偶数时正数 $a$ 有两个互为相反数的方根，其中正的叫算术根，记 $\sqrt[n]{a}$，负数没有偶次方根，$\sqrt[n]{0}=0$。$\sqrt[n]{a}$ 叫根式，$n$ 叫根指数，$a$ 叫被开方数。

定义定义（分数指数幂）

$a>0,\ m,n\in\mathbf{N}$ 且 $n\geqslant2$ 时，$\sqrt[n]{a^m}=a^{\frac mn}$，$\frac1{\sqrt[n]{a^m}}=a^{-\frac mn}$；0 的正分数指数幂为 0，0 没有负分数指数幂。

性质表示符号

根式 $\sqrt[n]{a}$；分数指数幂 $a^{\frac mn}$；$n$ 为奇数时 $\sqrt[n]{a^n}=a$，$n$ 为偶数时 $\sqrt[n]{a^n}=|a|$。

术语中英术语

root（或 radical）根式 / rational exponent 有理数指数 / fractional exponent 分数指数幂 / arithmetic root 算术根 / radicand 被开方数。

方法定理 / 公式 / 方法

整数（有理数）指数幂运算法则 $a^r\cdot a^s=a^{r+s}$，$(a^r)^s=a^{rs}$，$(ab)^r=a^r b^r$；用分数指数幂可大大简化根式运算。

性质关系 / 转化

根式与分数指数幂互化；分数指数幂把整数指数幂推广为有理数指数幂。

小节4.1.2 无理数指数幂6 条知识点
定义概念

用有理数次幂逼近，赋予正数 $a$ 的无理数次幂以确定意义。

定义定义

对 $a>0$，先用 $a$ 的有理数次幂逐步逼近无理指数位数，可精确到任意精度，于是 $a$ 的无理数次幂确定；从而对任意实数 $u$，$a^u$ 都有定义（$a$ 为底数，$u$ 为指数）。

性质表示符号

$a^u$；$a^r$ 与 $a^s$ 的比较。

术语中英术语

irrational exponent 无理数指数 / power with real exponent 实数指数幂。

方法定理 / 公式 / 方法（幂运算基本不等式）

对正数 $a$ 与正数（实数）$u$，$a>1$ 则 $a^u>1$，$a<1$ 则 $a^u<1$；对负数 $u$，$a>1$ 则 $a^u<1$，$a<1$ 则 $a^u>1$。推论：$a>1$ 时 $r>s\Rightarrow a^r>a^s$；$0<a<1$ 时 $r>s\Rightarrow a^r<a^s$。例：$(3^{\sqrt2})^{\sqrt2}=3^2=9$。

性质关系 / 转化

有理数指数幂是基础，无理数指数幂由逼近定义；实数指数幂统一了幂运算，为幂函数、指数函数奠基。

小节4.1.3 幂函数6 条知识点
定义概念

以自变量为底数、常数为指数的函数。

定义定义

$y=x^\alpha$（$\alpha$ 为非零实数）叫 $\alpha$ 次幂函数。

性质表示符号

正整数次 $y=x^n\ (n\in\mathbf{Z}_+)$；负整数次 $y=x^{-n}\ (n\in\mathbf{Z}_+,\ x\neq0)$；分数次 $\sqrt{x}=x^{\frac12}$、$\sqrt[3]{x}=x^{\frac13}$。

术语中英术语

power function 幂函数 / integer power function 整数次幂函数。

方法定理 / 公式 / 方法（实数次幂函数在 $x>0$ 时的性质）
  • $\alpha>0$：在 $[0,+\infty)$ 上递增，值域 $[0,+\infty)$，过 $(0,0)$、$(1,1)$；
  • $\alpha<0$：在 $(0,+\infty)$ 上递减，值域 $(0,+\infty)$，过 $(1,1)$，图象向 $y$ 轴、$x$ 轴无限接近。
  • 由 $\frac{a^r}{b^r}=\left(\frac ab\right)^r$ 得：$\alpha>0$ 时 $a>b>0\Rightarrow a^\alpha>b^\alpha$；$\alpha<0$ 时 $a^\alpha<b^\alpha$。

小节4.2.2 指数函数的图象与性质6 条知识点
定义概念

性质定义 / 性质

小节4.3.1 对数的概念6 条知识点
定义概念

由指数式反解出来的新运算（已知 $a$ 和 $N$ 求 $b$）。

定义定义

如果 $a^b=N\ (a>0$ 且 $a\neq1)$，那么 $b$ 叫以 $a$ 为底（正）数 $N$ 的对数，记作 $b=\log_a N$；$a$ 叫底数，$N$ 叫真数。

性质表示符号

$\log_a N$；常用对数 $\lg N=\log_{10}N$；自然对数 $\ln N=\log_e N$（$e=2.71828\cdots$）。

术语中英术语

logarithm 对数 / base 底数 / argument 真数 / common logarithm 常用对数 / natural logarithm 自然对数。

方法定理 / 公式 / 方法（对数基本恒等式）

$a^{\log_a N}=N$；$b=\log_a a^b$。推论：$\log_a a=1$，$\log_a 1=0$（底的对数为 1，1 的对数为 0）。

性质关系 / 转化

定义概念

性质定义（运算法则） （$a>0$ 且 $a\neq1$，$M>0,N>0$）
  • $\log_a(M\cdot N)=\log_a M+\log_a N$（化乘为加，最重要）；
  • $\log_a M^n=n\log_a M\ (n\in\mathbf{R})$；
  • $\log_a\frac{M}{N}=\log_a M-\log_a N$。
性质表示符号

术语中英术语

logarithm operation rules 对数运算法则 / change of base formula 换底公式。

性质关系 / 转化

对数运算化乘为加、除为减、幂为乘，简化大数运算。

小节4.3.3 对数函数的图象与性质7 条知识点

  • $a>1$ 时递增，$0<a<1$ 时递减（与指数函数一致）。

小节4.4.2 计算函数零点的二分法6 条知识点
定义概念

通过不断二分零点所在区间，求得零点的近似值。

定义定义（二分法）

设 $y=f(x)$ 在区间 $D$ 上图象连续。求零点 $x_0$ 的近似值 $x$，使 $|x-x_0|\leqslant\varepsilon$： 1) 在 $D$ 内取 $[a,b]\subseteq D$ 使 $f(a)$ 与 $f(b)$ 异号（$f(a)\cdot f(b)<0$）； 2) 取中点 $m=\frac12(a+b)$； 3) 若 $|m-a|<\varepsilon$，取 $m$ 为近似值，终止； 4) 若 $f(m)=0$，则 $m$ 即零点，终止； 5) 若 $f(m)$ 与 $f(a)$ 同号则令 $a=m$，否则令 $b=m$，回到步骤 2。

性质表示符号

误差 $\varepsilon$；区间长 $b-a$；中点 $m$。

术语中英术语

bisection method 二分法 / approximation 近似值 / tolerance 误差。

方法定理 / 公式 / 方法

每二分一次区间长度减半，逐步逼近零点；可画程序框图或在计算机上编程实现。

性质关系 / 转化

把"连续且两端异号"的区间不断折半逼近零点；亦可讨论按两端函数值大小比例分割以更快收敛。

节5.2 任意角的三角函数3 小节 · 18 知识点
小节5.2.1 任意角三角函数的定义6 条知识点
定义概念

用坐标比值把正弦、余弦、正切推广到任意角；因弧度制使角与实数一一对应，三角函数可看成以实数为自变量的函数。

定义定义

设 $\alpha$ 终边上不同于原点的点 $P(x,y)$，$r=\sqrt{x^2+y^2}$，则 $\sin\alpha=\frac yr$，$\cos\alpha=\frac xr$，$\tan\alpha=\frac yx$（$x\neq0$）。

性质表示符号

$y=\sin\alpha,\ y=\cos\alpha,\ y=\tan\alpha$；正弦线 $DP$、余弦线 $OD$、正切线 $AT$（统称三角函数线），$DP=y=\sin\alpha$，$OD=x=\cos\alpha$，$AT=\tan\alpha$。

术语中英术语

sine 正弦 / cosine 余弦 / tangent 正切 / unit circle 单位圆 / trigonometric line 三角函数线。

方法定理 / 公式 / 方法（定义域）

$y=\sin\alpha$、$y=\cos\alpha$ 定义域为 $\mathbf{R}$；$y=\tan\alpha$ 定义域为 $\{\alpha\mid\alpha\neq\frac\pi2+k\pi,\ k\in\mathbf{Z}\}$。三角函数值在各象限的符号：正弦一、二象限正，余弦一、四象限正，正切一、三象限正。

性质关系 / 转化

比值与终边上点的位置无关（相似三角形）；用单位圆和有向线段表示三角函数值（含符号）。

小节5.2.2 同角三角函数的基本关系6 条知识点
定义概念

同一个角的正弦、余弦、正切之间的关系，可由其中一个求另外两个。

性质定义（基本关系式）

$\sin^2\alpha+\cos^2\alpha=1$；$\tan\alpha=\frac{\sin\alpha}{\cos\alpha}$（$\cos\alpha\neq0$）。

性质表示符号

$\sin^2\alpha+\cos^2\alpha=1$；$\tan\alpha=\frac{\sin\alpha}{\cos\alpha}$；推论 $1+\tan^2\alpha=\frac1{\cos^2\alpha}$。

术语中英术语

Pythagorean identity（或 trig identity）平方关系 / quotient relationship 商数关系。

方法定理 / 公式 / 方法

已知 $\sin\alpha$ 求 $\cos\alpha$ 要结合象限定符号（如第四象限 $\cos\alpha>0$）；由 $\tan\alpha=k$ 得 $\cos\alpha=\pm\frac1{\sqrt{k^2+1}}$、$\sin\alpha=\pm\frac k{\sqrt{k^2+1}}$。

性质关系 / 转化

平方关系来自单位圆中勾股定理；商数关系来自定义；可互相代入化简与证明。

小节5.2.3 诱导公式6 条知识点
定义概念

把任意角的三角函数转化为锐角三角函数的公式，揭示终边有对称关系的两角三角函数值之间的关系。

定义定义

角 $\alpha$ 与 $2k\pi+\alpha$、$-\alpha$、$\pi\pm\alpha$、$\frac\pi2\pm\alpha$ 的三角函数的关系式统称诱导公式。

性质表示符号
  • 公式一：$\sin(\alpha+2k\pi)=\sin\alpha$，$\cos(\alpha+2k\pi)=\cos\alpha$，$\tan(\alpha+2k\pi)=\tan\alpha$；
  • 公式二：$\sin(-\alpha)=-\sin\alpha$，$\cos(-\alpha)=\cos\alpha$，$\tan(-\alpha)=-\tan\alpha$；
  • 公式三：$\sin(\pi+\alpha)=-\sin\alpha$，$\cos(\pi+\alpha)=-\cos\alpha$，$\tan(\pi+\alpha)=\tan\alpha$；
  • 公式四：$\sin(\pi-\alpha)=\sin\alpha$，$\cos(\pi-\alpha)=-\cos\alpha$，$\tan(\pi-\alpha)=-\tan\alpha$；
  • 公式五：$\sin\left(\frac\pi2-\alpha\right)=\cos\alpha$，$\cos\left(\frac\pi2-\alpha\right)=\sin\alpha$，$\sin\left(\frac\pi2+\alpha\right)=\cos\alpha$，$\cos\left(\frac\pi2+\alpha\right)=-\sin\alpha$；
  • 公式六：$\tan\left(\frac\pi2-\alpha\right)=\frac1{\tan\alpha}$，$\tan\left(\frac\pi2+\alpha\right)=-\frac1{\tan\alpha}$。
术语中英术语

induction formula 诱导公式。

方法定理 / 公式 / 方法

法则——$k\pi\pm\alpha$ 的三角函数值等于 $\alpha$ 的同名函数值，前面添上把 $\alpha$ 看成锐角时原函数值的符号；$\frac\pi2\pm\alpha$ 的正（余）弦值等于 $\alpha$ 的余（正）弦值并添相应符号。

性质关系 / 转化

总体个数 $N$；样本容量 $n$；随机数表。

术语中英术语

simple random sampling 简单随机抽样 / random sampling 随机抽样 / representativeness 代表性 / lottery method 抽签法 / random number method 随机数法。

方法定理 / 公式 / 方法

常用两种方法——抽签法（将 $N$ 个个体逐一编号、制作号签、放入容器摇匀后无放回抽 $n$ 个）；随机数法（借助计算机/计算器生成随机数表按号抽取）。简单随机抽样是最基本的方法，是其他抽样方法的基础。

性质关系 / 转化

抽签法简单直观、适合总体不大；总体个数很多时制签繁琐且可能搅拌不均，用随机数法克服。

小节6.2.2 分层抽样6 条知识点
定义概念

按某种特征把总体分成互不交叉的层，各层按其在总体中所占比例独立进行简单随机抽样。

定义定义

当总体由差异明显的几个部分组成时，将总体划分为互不交叉的层，对各层按其所占比例独立进行简单随机抽样，称分层抽样。

性质表示符号

层权 $W_i=\frac{N_i}{N}$。

术语中英术语

stratified sampling 分层抽样 / layer 层。

方法定理 / 公式 / 方法

分层抽样保证样本结构与总体结构一致，提高样本代表性，也可对各层特征进行估计。

性质关系 / 转化

选择方法视具体情况——总体个体差异不易分层用简单随机抽样；总体由差异明显的互不交叉部分组成用分层抽样。共同点：每个个体被抽到的可能性相同。历史教训（如《文学摘要》抽样排除穷人导致预测失败）说明有偏样本会致错误结论。

小节6.2.3 调查问卷的设计2 条知识点
定义概念

调查方式方法对能否获得真实数据非常重要。

方法定义 / 方法

对敏感问题要保护被调查者（匿名问卷、答卷折叠后投入封闭投票箱再统计）；提问内容要简单明确；用词确切、通俗易懂、有礼貌，不用引导性词语（如"很多人都要买汽车，您呢？"应改为"您最近打算买汽车吗？"）。

节6.3 统计图表1 小节 · 6 知识点
小节本节知识点节内直列6 条知识点
定义概念

借助统计图表对原始数据整理并简明醒目地表述（一张好的统计图表胜过冗长文字）。

定义定义

当样本量 $n$ 的观测数据中有 $n_i$ 个落入第 $i$ 组时，称 $f_i=\frac{n_i}{n}$ 是第 $i$ 组的频率。

性质表示符号

频数 $n_i$、频率 $f_i=\dfrac{n_i}{n}$；组距；组数 $=\dfrac{极差}{组距}$（经验公式 $K=1+4\lg n$）；频率分布直方图纵轴为 $\dfrac{频率}{组距}$；小矩形面积 $=$ 组距 $\times\dfrac{频率}{组距}=$ 频率，各小矩形面积之和 $=1$。

术语中英术语

frequency distribution table 频率分布表 / frequency distribution histogram 频率分布直方图 / sector chart 扇形统计图 / bar chart 条形统计图 / range 极差 / class width 组距。

方法定理 / 公式 / 方法（绘制频率分布表四步）

① 计算极差（最大值 $-$ 最小值）；② 确定组距和组数；③ 将数据分组（如 $[200,250),[250,300),\cdots$）；④ 列频率分布表。纵轴取 $\dfrac{频率}{组距}$ 即得频率分布直方图；连接相邻矩形上底边中点的线段得频率分布折线图。

性质关系 / 转化

频数分布直方图（纵轴为频数）与频率分布直方图（纵轴为频率/组距）对比；统计图表使杂乱数据条理化、形象化，为统计分析打基础。

节6.4 用样本估计总体4 小节 · 27 知识点
小节6.4.1 用样本估计总体的集中趋势8 条知识点
定义概念

用样本的数字特征（平均数、众数、中位数）估计总体的数字特征。

定义定义（平均数/均值）

样本容量为 $n$、第 $i$ 个个体为 $x_i$，样本平均数 $\overline{x}=\dfrac{x_1+x_2+\cdots+x_n}{n}$；样本容量增大时 $\overline{x}$ 向总体均值 $\mu$ 接近。若数据 $x_1,\cdots,x_n$ 的频率分别为 $f_1,\cdots,f_n$，则平均数 $=x_1f_1+x_2f_2+\cdots+x_nf_n$（分组时用各组组中值近似，前提假定组内分布均匀）。

定义定义（众数）

观测数据中出现次数最多的数，用 $M_o$ 表示（一组数据可有两个、多个众数或没有）。

定义定义（中位数）

数据按从小到大排列后处于中间位置的数，用 $M_e$ 表示（个数为奇数取中间那个，偶数取中间两个的算术平均）。

性质表示符号

总体均值（参数）$\mu$；样本均值（统计量）$\overline{x}$、众数 $M_o$、中位数 $M_e$；层权 $W_i=\dfrac{N_i}{N}$；分层抽样总体均值简单估计 $\overline{X}=W_1\overline{x}_1+W_2\overline{x}_2+\cdots+W_L\overline{x}_L$。

术语中英术语

mean/average 平均数 / arithmetic mean 算术平均数 / median 中位数 / mode 众数 / parameter 参数 / statistic 统计量 / layer weight 层权。

方法定理 / 公式 / 方法

平均数用到所有数据、应用较广，但易受极端值影响；中位数和众数不受极端值影响，但未用全部信息。根据问题需要选择合适统计量（总经理关注平均数、员工关注中位数、应聘者关注众数）。

性质关系 / 转化

样本均值带随机性；分层抽样同时得到总体和各层的均值估计。

小节6.4.2 用样本估计总体的离散程度8 条知识点
定义概念

用极差、方差、标准差描述一组数据波动（离散）的大小。

定义定义（极差）

一组数据中最大值与最小值之差，又叫全距，用 $R$ 表示；计算简单但只利用两端信息、易受极端值影响。

定义定义（方差）

总体方差 $\sigma^2=\dfrac{(y_1-\mu)^2+(y_2-\mu)^2+\cdots+(y_N-\mu)^2}{N}$；样本方差 $s^2=\dfrac1n\big[(x_1-\bar{x})^2+(x_2-\bar{x})^2+\cdots+(x_n-\bar{x})^2\big]$。方差越小表示个体向均值 $\mu$ 集中得越好、波动越小。

定义定义（标准差）

方差的算术平方根——总体标准差 $\sigma=\sqrt{\sigma^2}$，样本标准差 $s=\sqrt{s^2}$；单位与观测数据相同（$\sum$ 音"西格马"，表示求和）。

性质表示符号

极差 $R$；总体方差 $\sigma^2$、总体标准差 $\sigma$；样本方差 $s^2$、样本标准差 $s$；两分层样本方差 $s^2=\dfrac1n\{n_1[s_1^2+(\bar{x}_1-\bar{x})^2]+n_2[s_2^2+(\bar{x}_2-\bar{x})^2]\}$。

术语中英术语

variance 方差 / standard deviation 标准差 / range 极差 / stability 稳定性。

方法定理 / 公式 / 方法

方差/标准差越小越稳定（如甲射击 $s^2=0.6<$ 乙 $s^2=1.4$，甲更稳定）；工业上以平均数、标准差监测产品质量，超出规定界限即检修。

性质关系 / 转化

集中趋势（平均数、众数、中位数）与离散程度（极差、方差、标准差）共同刻画数据；用样本数字特征估计总体数字特征。

小节6.4.3 用频率分布直方图估计总体分布5 条知识点
定义概念

随机样本的频率分布直方图是总体分布的近似；样本容量越大、组距越小，越接近总体分布。

方法定义 / 方法

由直方图可估算数据落在某组的频率（概率），进而估计总体中相应数量（如 450 人中约有 $450\times28\%=126$ 人落在 $[170,175)$）。

性质表示符号

组中值与对应频率之积的和即可估计平均数；估计人数 $=$ 总体总数 $\times$ 相应频率。

术语中英术语

estimate the population distribution 估计总体分布。

性质关系 / 转化

样本频率分布→总体分布近似；由直方图还能分析中位数、众数、平均数的位置。

小节6.4.4 百分位数6 条知识点
定义概念

位于按一定顺序排列数据中某个百分位置的数值，是衡量数据位置的度量。

定义定义

百分位数 $P_r$ 将全部观测值分为两部分，至少有 $r\%$ 的观测值小于或等于它，且至少有 $(100-r)\%$ 的观测值大于或等于它；当 $r=50$ 时即中位数。$P_{25}$ 第一四分位数，$P_{50}$ 第二四分位数，$P_{75}$ 第三四分位数。

性质表示符号

$P_r$；$P_{25},P_{50},P_{75}$。

术语中英术语

percentile 百分位数 / quartile 四分位数。

方法定理 / 公式 / 方法（计算法）

设数据已按从小到大排列为 $x_1,x_2,\cdots,x_n$。① 计算 $c=n\times r\%$；② 若 $c$ 不是整数，$m$ 为比 $c$ 大的最小整数，则 $P_r=x_m$；若 $c$ 是整数，则 $P_r=\dfrac{x_c+x_{c+1}}{2}$。

性质关系 / 转化

阶梯电价/气价按 $P_{75}$、$P_{95}$ 划分档次（如 $P_{75}$ 为 75% 用户用电临界值）；$P_{25}$ 约在数据的 $\frac14$ 处、$P_{50}$ 在中间、$P_{75}$ 约在 $\frac34$ 处。
